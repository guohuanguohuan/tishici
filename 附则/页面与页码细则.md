# 页面与页码细则（附则；外移自公共规则§7 L101，2026-09-06 用户拍板外移降预算，原文逐字保留）

> 原语境注记：文中「§5/§11/§14」等内指公共规则照旧；附则《双栏首页断言》《表格规范》《节标题栏顶规则》引用不变。效力与原位相同，§7 原位留指针。

页面：**页边距上下左右必须是1.5厘米（850缇，含装订余量）**；纸张必须全是A4纸。**版面分栏（双栏制）**：内容件（讲练/衔接/清单/实验/真题/讲义/切片）正文左右两栏——w:cols w:num="2" w:space="425" w:sep="1"，每栏约8.6cm；头部单栏区＝文内开头标题及其后的章首导航要素（全件统计行、章首导航表、〔基〕/〔进〕图例行——各件按其要素有无）以连续分节符维持单栏，其后进双栏正文；**分节符落点＝头部要素全部之后、不得有头部要素落双栏区；首页成立与否按附则《双栏首页断言》断言集判定（例外件型见该附则）**；表格落位与表宽基准照附则《表格规范》通栏表款；各教材节标题栏顶起排规则照附则《节标题栏顶规则》执行；页眉页脚定义各仅一处（分节不重复引用）；册级连续页码 start 落头部节 sectPr；四类配页件全文单栏。页脚页码规范（**部分独立页码制**）：每页页脚必须有页码，当前页码用 Word 页码域生成（**一律用复杂域形态**＝w:fldChar begin/separate/end＋w:instrText；禁用 fldSimple；复杂域的缓存结果写实测值而非占位值，且 settings.xml 必须含 <w:updateFields w:val="true"/>）；页眉页脚同串，格式＝「**羿郭工作室·册名 第X章 章名·件型（共N页）·本n/共M本　当前节号节名　第X页**」（X＝PAGE 复杂域生成、N＝部分总页数 COM 实测写死，X、N 必须阿拉伯数字、禁汉字数字；n＝该件所属物理本序、M＝册内物理本总数，随装订单本划分联动、盖章写死；分层卷派生后M随之增大重盖；无节层件去节名段口径见页眉款）；**「部分」＝同一章/讲/单位的同一种产出的全部文件（讲练件拆出的全部卷同一个部分、页码跨卷连续；分层卷各按其件型各成一个部分），部分边界由各总控在册装订单〔§11〕列明；封面件、册目录页件、使用说明页件与部分封面件（合称四类配页件）不属任何部分、不计页**；**每部分页码独立从1连续：每部分首件头部节 sectPr 设 <w:pgNumType w:start="1"/>，同部分后件 start＝该件之前同部分各件累计页数＋1**；
**总页数 N 禁止用域生成（NUMPAGES 禁用），由盖章脚本按部分实测值写死**；盖章由 工具/册级连续页码.py 按册目录页目录树的装订顺序与册装订单的部分划分逐件只读实测页数后统一落盘（职责＝**部分内累计**：逐件写 X 域缓存值〔页眉页脚两处 PAGE 域缓存同步写〕、部分总页数 N、本n/共M本 与 sectPr start），**任何成品件内容发生改动后，收尾必须对该件所在册重跑盖章脚本（先内容后页码，页码最后盖）**；同串中件型章名段为写死的文字（从文件名生成）；页脚距页底边固定1.5厘米（850缇同四边，禁沿用源杂值）；不勾选「首页不同」「奇偶页不同」，首页显示页码、奇偶页位置一致；页眉页脚字号9pt（小五，18半点），文字字体宋体、数字字体 Times New Roman；页眉页脚除同串外不得有其他内容（源文件页脚的校名、网址、文件名等一律删除）。**页眉**：四类配页件外，全部成品件页眉页脚同串、左对齐单行（段落 jc=left；件型后缀与件标识对照同源；分卷不加卷次、同章各卷一致；品牌字样固定；册名、章号、章名按所在总控命名语法取该件所属章，同章各件一致、件内不随页切换；无「章」概念的件取「体系前缀＋单位编号与名称·件型」部分，同单位各件含分卷一致；单件跨章的册级内容件取「羿郭工作室·册名·学史」级；无节层概念的件及其线同串去节名段）。**节名锚机制**：每节标题段之前置一个「节名锚」段落——专用样式（1pt、白色#FFFFFF、非隐藏属性、行距固定1磅、段前后0），内容＝「节号 节名」；页眉页脚节名段以 **STYLEREF “节名锚” 复杂域**抓取（域形态同页脚款；锚挂载由工具批量实施——工具债登记看板；分层卷派生时锚随骨架随节复制；节标题挂真实Word标题样式的工程照旧保留〔本节标题真实样式挂载条款〕作结构语义载体）。**域行为口径**：锚弃用隐藏文字属性（STYLEREF 域不认）；PDF文字层含锚文字（审计工具列白名单）；换节页取「本页出现的第一个锚」（词典式跑头）。字号同页脚款（小五18半点）、无底纹无边框、页眉距页顶0.5厘米（283缇；页眉距＋单行行高必须≤上边距1.5厘米/850缇）、不得推挤正文（正文区与页数不变；同串单行放不下时允许省略「羿郭工作室·」品牌前缀，件型与章名保留）；
页眉页脚内容不属任何对账恒等式，排版自检⑤实测页眉页脚形态与内容（含节名锚域形态合规），§14 PDF校验加核逐页双断言（判据与映射源同§14校验清单）；存量件由页眉页脚同串改挂回扫轮统一实施（§5回扫纪律，欠账登记看板）。
