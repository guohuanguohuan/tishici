# 附则：dsh按需成员日费细则（自立锚点；上位条款＝公共规则L12按需成员段）
设立：2026-09-03，用户明示「每天使用deepseek-v4-flashvision不能超过5元」；三方门1轮绝对同意（kimi同意＋qwen M1-M8全采纳）。

## 一、折算式（条款与账本同引本处；K1不另立公式）
金额（元）＝（input−cached）×价1 ＋ cached×价2 ＋ output×价3，三价单位**元/百万token**。
三件套语义：cached 为 input 的**子集**（未命中输入＝input−cached，不得重复计费）。单价数值一律不入规则正文，以看板K1块「单价数值＋查证日期＋来源」为唯一载体（首次召集前查证落K1，其后季度复查）；历史账本条目不追溯重算、每条自带当期单价戳。

## 二、成本归属与归日
- 一次召集的成本＝该次召集**全程所有请求**token累加（含多轮往返与嵌套调用），记为一条。
- 归日按**召集发起时刻**（本地）：跨00:00完成的调用不回改前一日账、也不计入新日；自然日00:00重置累计。

## 三、预检（发起前必做，主体＝主会话）
- 预估基准＝**最近3次实测单次成本的最大值**（当日无记录同此；完全无历史→本次按「试探性召集」处理，当场上限降为1次）。
- 判据：当日累计 ＋ 预估×(1+20%) ≤ 5元 方可发起；不满足即不发起、如实呈报。
- 越界实测允许（预估不可能精确），但越额须在K1账本记「越额」标记。

## 四、熔断与控制流（与「单会话召集>3次」熔断并行，任一触发即停）
- 当日累计达5元 → 熔断当日一切dsh召集，**视同「到席不能」走公共规则L12既有降级路径**：②③类降级常任三方共识（登记K1）、①类停等上报；熔断首行报告必须含「今日已用X元／上限5元」字样。
- **单次预估即超日额** → 停等我三选一裁决：追加额度／拆为多次／改由常任三脑承担；禁止静默跳过该维度。
- 追加额度＝独立明示句，须含金额或「不设限」字样（语境暗示不构成，判据与①类点名同构）；追加句逐字入K1凭证；未带金额的追加视为仅放行本次一次、登记「无金额追加」。
- 本上限只约束dsh召集，不约束kimi/qwen常任门与主会话自身。
- 取数回退：token取数路径未验证前，保守预估照常计入熔断；一旦确认取数不可得，**日累计召集达4次即等同熔断**（与「单会话>3次」同族）。token取数源＝dsh会话日志（首次召集时验证路径并将验证结论写入本节）。
- 记账、预检、熔断判定主体一律＝主会话；商议体与dsh无自查义务。

## 五、账本载体（看板K1块「dsh按需成员召集登记」下）
字段：当日累计金额／最近实测单价（数值＋查证日期＋来源）与单次金额／重置日期／熔断事件（时间＋触发轨：费用轨或次数轨＋当日累计）。术语固定为「日费上限」四字、禁变体。
