## 五、接入规程（与 ZH-6 备用通道同流程）

1. 用户点名渠道 → 注册取 key → config.toml 加 `[providers.<名>]`（type=openai＋base_url＋key）＋`[models."<别名>"]`（capabilities 按实〔多模态须 image_in〕、support_efforts 按实）＋`[secondary_model.models]` 池键
2. `kimi doctor config` 校验 → 时间戳备份 → 覆盖 → 用户 `/reload`
3. **冒烟双绿**：文本探针＋读图探针（多模态臂必测）→ 正名上岗
4. 接入后即测 `/models` 名单与额度实况，回填本件"核实"列
5. 免费臂岗位＝轻量产/冒烟/替补；主臂仍 qwen/glm/Kimi K2.8/DeepSeek（ZH-10 缓存纪律照行：DeepSeek 系 resume 复用，其余新派）
6. **情报工作纪律（2026-09-12 用户逮错后立）**：情报结论前必须**逐个候选模型的官方模型卡核实能力**（参数/模态/上下文），**禁止凭模型 ID 字样或单条来源速断**；引用第三方总库时逐行核读，不跳读；已被用户指正过的错类登记于此，复发即升级为一类一门。首例：Kimi K2.6 多模态漏判（凭 vision 字样扫名单、未核 K2.6 卡）。
