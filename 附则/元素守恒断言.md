# 元素守恒断言（附则；公共规则§9守恒总原则的元素级批处理执行细则；登记日 2026-09-06，选必1成书修复轮②-F 落库）

## 起因（T5 事故实证）
修复轮早期批处理的守恒校验只数 w:t 文本一族，数学族与绘图族未入断言：T5（公式元素还原）批处理中 102 个 m:oMath 公式元素丢失而单族校验全程绿灯，事后字节比对才暴露。凡对 docx 做元素级批量改动（底纹批量、公式还原、栏顶插符、跨行保护等），守恒断言一律按本附则执行。

## 规则
- **YS-1（三族守恒）**：守恒断言必须同时覆盖三族元素并逐族登记实测值——①文本族 w:t；②数学族 m:oMath／m:t（含 m:oMathPara 单列）；③绘图族 w:drawing（wp:inline 与 wp:anchor 分记）。禁止以 w:t 单族计数充当全文守恒；禁止以「总量持平」跨族抵账，任一族不平即停线回滚。
- **YS-2（白名单先声明）**：批处理开工前先把允许改动的元素类别/属性枚举（白名单）落盘；执行后白名单外区域字节级零 diff 是强制断言（全量比对，非抽样）。
- **YS-3（撤除→字节比对→重放 三步法）**：白名单式元素改动的标准工序——①撤除：从源文档精确摘除目标元素集合（集合清单先行落盘）；②字节比对：残余文档对「源文档删目标集合」期望态字节级 diff＝0（白名单外零改动作证）；③重放：处理后的元素集合写回，再跑一遍 YS-1 三族计数守恒。三步各自落盘作证，缺步不算完成。
- **YS-4（工具口径）**：底纹批量器/公式元素还原器/节标题栏顶器等元素级工具的自检输出口径照本附则执行；新立元素级工具默认内置三族计数与 YS-2 断言，不内置不得上批量（先建后用债照进度看板登记）。

## 与其它文件的关系
公共规则§9守恒总原则管「内容级」守恒（题/条目不凭空消失）；本附则管「XML 元素级」守恒（批处理不丢元素、不越白名单），两者并立、互不替代。自检⑥图与公式核验、七类底纹计数等计数断言按本附则三族口径补齐元素族归属。
