## 一、逐条裁决

### 论断1｜导学件行距虚增（ctex 默认 1.3 与 18pt 叠乘→实发 23.4pt，直方图主峰 23pt）——**成立**（机制表述一处需修正）

- **PDF 实测（python+pymupdf，纯中文 SimSun/SimHei 10.5pt 行，按栏聚类视觉行）**：主峰 8.20mm(23.2pt)×49 处；中位 8.22mm＝**23.3pt**；18pt(6.35mm) 计数仅 2（污染）。与「23.4pt＝18×1.3」吻合，与 18pt 不符。
- **机制链（源码逐级核实）**：
  1. main.tex:19 `\documentclass[fontset=none]{ctexart}`——未传 scheme/linespread，默认 scheme＝chinese；
  2. `ctex-scheme-chinese-article.def` **L139–140**：`\fp_if_nan:nT { \l__ctex_line_spread_fp } { \fp_set:Nn \l__ctex_line_spread_fp { 1.3 } }`；
  3. `ctexart.cls` **L1527–1529**：fp 非 NaN → 执行 `\linespread{1.3}`（ctex 2.6.5，main.log:19 证实编译即用 v2.6.5 2026/08/11）；
  4. `latex.ltx` L10719–20（`\fontsize`＝`\set@fontsize\baselinestretch…`，捕获当时 `\baselinestretch`）、L12782–86（`\size@update` 中 `\baselineskip\f@linespread\baselineskip`）；
  5. main.tex:53 `\renewcommand{\normalsize}{\fontsize{10.5pt}{18pt}\selectfont}` → 18pt×1.3＝**23.4pt**。
- **修正**：报告表述「ctexart 默认 **linestretch**=1.3」不准——1.3 的来源是默认 scheme=chinese 对 **`linespread`** 选项的初始值，ctex 2.6.5 的 `linestretch` 是另一选项（管 CJK 字间 ccglue，ctexart.cls L417–425）。修复主案「main.tex L53 后加 `\linespread{1}\selectfont`」有效；四-1 备选「类选项 `linestretch=1`」**无效**，应写 `linespread=1`（类选项或 ctexset）。
- 旁证：main.log grep linestretch 无记载（exit 1）；`ctex-c5size.clo` 的五号行距 12.6pt 被 L53 覆盖，与本案无关。
