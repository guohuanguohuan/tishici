1.1.1-2．〔基〕\textbf{空间向量的表示}

【⁠编⁠注⁠】字母表示与有向线段表示贯穿全章书写，解题前先统一记号；模的记号与绝对值区分，避免混淆。

（1）字母表示法：用字母\(\overset{⃑}{a},\overset{⃑}{b},\overset{⃑}{c}, \cdot \cdot \cdot\)，表示．

1.1.1-5．〔基〕空间向量共线的充要条件

【⁠编⁠注⁠】证线线平行与求参数存在性的基础工具；易错点：与条目9共面充要条件混淆------共线用一个实数、共面用有序实数对。

1.1.1-7．〔基〕空间向量的数量积

【⁠编⁠注⁠】求空间角与距离的核心运算（支撑条目16、17、34）；注意数量积不满足结合律，零向量与任意向量的数量积为0。

（1）定义：已知两个非零向量\(\overset{⃑}{a}\)，\(\overset{⃑}{b}\)，则向量\(\overset{⃑}{b}\)的模长与\(\overset{⃑}{a}\)在向量\(\overset{⃑}{b}\)方向上的投影的乘积叫做\(\overset{⃑}{a}\)，\(\overset{⃑}{b}\)的数量积，记作\(\overset{⃑}{a} \cdot \overset{⃑}{b}\)．即\(\overset{⃑}{a} \cdot \overset{⃑}{b} =\)\(|\overset{⃑}{a}||\overset{⃑}{b}|\cos\langle\overset{⃑}{a},\overset{⃑}{b}\rangle\)．

【⁠微⁠提⁠醒⁠】零向量与任意向量的数量积为0．

（2）由数量积的定义，可以得到：\(\overset{⃑}{a}\bot\overset{⃑}{b} \Leftrightarrow\)\(\overset{⃑}{a} \cdot \overset{⃑}{b} = 0\)；\(\overset{⃑}{a} \cdot \overset{⃑}{a} = |\overset{⃑}{a}||\overset{⃑}{a}|\cos\langle\overset{⃑}{a},\overset{⃑}{a}\rangle =\)\({\overset{⃑}{a}}^{2}\)．

1.1.1-9．〔基〕空间向量共面的充要条件

【⁠编⁠注⁠】证四点共面、线共面的标准工具；易错点：定理前提是p与a、b不共线，此前提不可漏，且实数对存在唯一。

（1）共面向量：平行于同一平面的向量，叫做共面向量．

（2）空间向量共面的充要条件：向量\(\overset{⃑}{p}\)与不共线向量\(\overset{⃑}{a}\)，\(\overset{⃑}{b}\)共面的充要条件是存在唯一的有序实数对\((x,y)\)，使\(\overset{⃑}{p} =\)\(\overset{⃑}{}x\overset{⃑}{a} + y\overset{⃑}{b}\)．

\textbf{1.1.1.2 空间向量的概念辨析}

1题：-1

【⁠编⁠注⁠】题型通式：题干围绕空间向量的模、方向、零向量、单位向量、相等向量与相反向量罗列若干说法要求辨误时，判归本题型。第一步逐条对照定义核验每个说法；再对存疑条目举反例（模相等而方向不同、单位向量方向各异等）；最后排除错误项定答案。

\textbf{1.1.1.2-1．（简单）}下列说法正确的是（~~~~）

A．若\(\left| \overset{⃑}{a} \right| = \left| \overset{⃑}{b} \right|\)，则\(\overset{⃑}{a} = \overset{⃑}{b}\)或\(\overset{⃑}{a} = - \overset{⃑}{b}\)；B．若\(\overset{⃑}{a},\overset{⃑}{b}\)为相反向量，则\(\overset{⃑}{a} + \overset{⃑}{b} = \overset{⃑}{0}\)
；C．零向量是没有方向的向量；D．若\(\overset{⃑}{a},\overset{⃑}{b}\)是两个单位向量，则\(\overset{⃑}{a} = \overset{⃑}{b}\)

【⁠答⁠案⁠】

B　

【⁠知⁠识⁠点⁠】

1.1.1 向量的模、零向量与单位向量、相等向量、相反向量

【⁠分⁠析⁠】根据零向量、单位向量、向量的模、相等向量、相反向量等概念逐一分析即可得出答案.

【⁠详⁠解⁠】解：若\(\left| \overset{⃑}{a} \right| = \left| \overset{⃑}{b} \right|\)，则它们的方向相同时是相等向量，方向相反时是相反向量，还有可能方向既不相同，也不相反，A错；

若\(\overset{⃑}{a},\overset{⃑}{b}\)为相反向量，则它们的和为零向量，B对；

零向量的方向是任意的，C错；

两个单位向量只是模都为1，方向不一定相同，D错.故选：B.

\textbf{1.1.1.3 空间向量的线性运算}

1题：-2

【⁠编⁠注⁠】题型通式：题干在几何体中给出若干已知向量、要求用它们表示指定向量时，判归本题型。第一步为目标向量选一条首尾相接的路径写出加减链；再把链中各段用相等或共线的已知向量替换；最后合并化简得表达式。

\textbf{1.1.1.3-2．（简单）}在直三棱柱\(ABC - A_{1}B_{1}C_{1}\)中，若\(\overrightarrow{CA} = \overrightarrow{a},\overrightarrow{CB} = \overrightarrow{b},\overrightarrow{CC_{1}} = \overrightarrow{c},\)，则\(\overrightarrow{A_{1}B}\)=\_\_\_\_\_\_\_\_\_\_\_\_.(用\(\overrightarrow{a},\overrightarrow{b},\overrightarrow{c}\)表示)

【⁠答⁠案⁠】\(\overrightarrow{b} - \overrightarrow{a} - \overrightarrow{c}\)

【⁠知⁠识⁠点⁠】

1.1.1 棱柱的结构特征和分类、空间向量加减运算的几何表示

【⁠分⁠析⁠】连接\(CA_{1},\)根据直三棱柱的结构特征及空间向量减法的几何意义可得\(\overrightarrow{A_{1}B} = \overrightarrow{CB} - \overrightarrow{CA} - \overrightarrow{CC_{1}}\)，结合已知即可求表达式.

【⁠详⁠解⁠】连接\(CA_{1},\)则\(\overrightarrow{A_{1}B} = \overrightarrow{CB} - \overrightarrow{CA_{1}} = \overrightarrow{CB} - \overrightarrow{CA} - \overrightarrow{CC_{1}} =\)
\(\overrightarrow{b} - \overrightarrow{a} - \overrightarrow{c}\).

【⁠分⁠析⁠】过点\(B\)，\(D\)分别向\(AC\)作垂线，垂足分别为\(M\)，\(N\)，由\(\overset{⃑}{BD} = \overset{⃑}{BM} + \overset{⃑}{MN} + \overset{⃑}{ND}\)，平方后结合长度和垂直关系可得解.

【⁠详⁠解⁠】\includegraphics[width=2.15169in,height=1.60713in,alt={@@@e34e5148-bca3-440e-84b1-3cbf33fe2cc1}]{media/media/image5.png}~~过点\(B\)，\(D\)分别向\(AC\)作垂线，垂足分别为\(M\)，\(N\)，则可得\(AM = \frac{1}{2}\)，\(BM = \frac{\sqrt{3}}{2}\)，\(CN = \frac{1}{2}\)，\(DN = \frac{\sqrt{3}}{2}\)，\(MN = 1\)．由于\(\overset{⃑}{BD} = \overset{⃑}{BM} + \overset{⃑}{MN} + \overset{⃑}{ND}\)，所以\(|\overset{⃑}{BD}|^{2} = {(\overset{⃑}{BM} + \overset{⃑}{MN} + \overset{⃑}{ND})}^{2}\)\(= |\overset{⃑}{BM}|^{2} + |\overset{⃑}{MN}|^{2} + |\overset{⃑}{ND}|^{2} + 2(\overset{⃑}{BM} \cdot \overset{⃑}{MN} + \overset{⃑}{MN} \cdot \overset{⃑}{ND} + \overset{⃑}{BM} \cdot \overset{⃑}{ND})\)\(= \left( \frac{\sqrt{3}}{2} \right)^{2} + 1^{2} + \left( \frac{\sqrt{3}}{2} \right)^{2} + 2 \times (0 + 0 + 0) = \frac{5}{2}\)，所以\(|\overset{⃑}{BD}| = \frac{\sqrt{10}}{2}\)．故选:\emph{A}．
