# image5（矩形沿 AC 折起图）逐要素核对表

- 源位图：`工作区/字替对照-0909/variantF/media/media/image5.png`　1798×1350 px，源排印宽 **54.7mm**
- 折算：**1 px = 54.7/1798 = 0.0304227 mm**（= 32.867 px/mm），两轴同尺（源图无纵横压缩）
- 重绘件：`fig-image5-fold-body.tex`（图形本体，仅依赖 tikz）＋`fig-image5-fold.tex`（独立壳）＋`fig-image5-fold.pdf`
- 核对方法：重绘 PDF 按 **835dpi**（与源图同尺 1px=1px）光栅化，与源图按「A/B/C/D 顶点重心」对齐后逐要素量测
  （量测脚本 `image5_metrics.py`/`image5_verify.py`；顶点、边、线宽用垂直于方向剖面的质心最小二乘拟合）

## 四、偏差清单（3 条，均不改几何）

1. **源图 C 标签右端被画布裁掉**（源图墨迹 x 到 1797 仍在延伸，源 C 字形右缘缺约 7px）。重绘按完整字形落位，
   故重绘墨迹右缘比源图宽约 8px（0.24mm），重绘整体墨迹宽 55.06mm vs 源 54.66mm。左缘对齐差 2px。
2. **虚线相位**：源图各虚线的「实段起点」比其起端点早约 4.3px，重绘（pgf）从端点起画，二者相位差 ≤8px＝0.24mm
   （≤1 个周期的 13%），节距与空档长度完全一致，目视无差。
3. **字号替代风险**：图形本体声明 14.4pt 属 CM 定档，换任何宿主都不产生字号替代告警；若宿主后续加载
   fix-cm／可伸缩数学字体并想更贴源（14.6pt 折算），可将 `\fontsize{14.4pt}` 改 13.6pt。

## 五、集成提示（交给集成代理）

- 图形本体 `fig-image5-fold-body.tex` **仅依赖 tikz**，无 `\usetikzlibrary`；直接 `\input` 到宿主 tikzpicture 位置即可。
- 坐标系统为 `x=1mm,y=1mm`，**按自然尺寸排版**（顶点 A→C 水平距离 46.48mm＝源图同值）；
  切勿用 `\includegraphics[width=54.7mm]` 缩放独立壳 PDF（壳的自然宽 56.56mm，含标签外扩，缩放会把几何缩小 3.3%）。
- 若宿主需整体缩放到某个栏宽，请用 `scale=` 同时作用于坐标与线宽，或整体 `\scalebox`（保持线宽/字号同比）。
- 线宽、虚线节距、字号均已按源图折算为绝对尺寸（见文件头注释），缩放后需按比例重算。
