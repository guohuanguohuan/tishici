=== A 拓展册·拓36（48 讲题1·无穷大导体平面感应，答案 B）===
 q 单独贡献        E_q  = 9*k*q/(4*h**2) = 9/4 *kq/h^2
 感应（像电荷）贡献 E_ind= 9*k*q/(16*h**2) = 9/16 *kq/h^2
 合场强            E    = 45*k*q/(16*h**2) ；源件答案 B = 45kq/16h^2 → 一致
 源链：E1 = 9*k*q/(16*h**2)  E3 = 9*k*q/(4*h**2)  E1+E3 = 45*k*q/(16*h**2) → 与镜像法同值 = True

=== B 拓展册·拓34（48 讲题9·双正四面体，◐删原B→印面 B＝原C）===

=== E 测评卷·题13（47 讲题1 双空，答案 < ；kg·m^3·s^-4·A^-2）===
 环轴线场强 E = Q_r*k*x/(R_r**2 + x**2)**(3/2)
 E < kQ/x^2 ? → -Q_r*k*x/(R_r**2 + x**2)**(3/2) + Q_r*k/x**2 > 0 （差值 = -Q_r*k*(-R_r**2*sqrt(R_r**2 + x**2) + x**3 - x**2*sqrt(R_r**2 + x**2))/(x**2*(R_r**2 + x**2)**(3/2)) ）
 k 单位＝N·m^2/C^2 → kg*m**3/(A**2*s**4) ＝kg·m^3·s^-4·A^-2 → True

=== F 测评卷·题19（冲刺卷 冲4·球壳双层割补，答案 |3kq/8R^2 - 2E|）===
 完整球壳总电荷 = 3*q/2 ；在 M/N（距心 2R）处场强 = 3*k*q/(8*R**2) ＝3kq/8R^2 → True
 修正片电荷 = -q/2 - (+q/2) = -q ＝ 1/3 面 A1B1(+q/2) 的 -2 倍
 ⇒ 修正片在 N 的场强大小 = 2E（对称位），方向与 3kq/8R^2 相反
 N 点合场强 = Abs(2*E - 3*k*q/(8*R**2)) → 与选项 C 同式 = True
