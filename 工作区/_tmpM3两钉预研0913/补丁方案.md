## 一 机理实证（本轮新钉死：为什么六宏活、qp-m3 死）

`\AtBeginDocument`（新内核＝`\AddToHook{begindocument}`）的块按**标签**定序执行：包内注册得包名标签、`\input` 文件注册得 `top-level` 标签；实测序＝类别→包（按装载序）→**top-level 殿后**。据此四组探针读数：

| 探针面 | 钩块标签 | 结果（`\meaning\parallel`@begindocument 末） | log 证据 |
|---|---|---|---|
| orig（qp-m3 原样） | `(qp-m3)`（:105 注册） | `the character ∥`——:105 钩先跑（HOOK105-POST 已是 TikZ）、unicode-math-xetex 的 4 个 begindocument 块（其装载序在后）后跑覆盖 | `orig/p-stages.log`＋dbg 轨迹：Add(qp-m3)@749 行 < Add(unicode-math-xetex)@1024 行 |
| mech（:105 注桩） | 同上 | HOOK105-PRE=`\mathchar"326B` → POST=TikZ → LATE=∥：覆盖确发生在钩后、同阶段后段 | `mech/p-stages.log` |
| mech2（钩块移 :117 `\setmathfont` 后，仍 `\AtBeginDocument`） | 仍 `(qp-m3)`（:60 的 \cha 钩已让 qp-m3 标签先行入册） | **仍 ∥——sty 内移位不救** | `mech2/p-stages.log` |
| six（六宏 `\input`） | `(top-level)` | TikZ 存活——top-level 殿后于 unicode-math-xetex，覆盖反被盖回 | `six/p-stages-six.log` |
| patch（补丁稿 begindocument/end） | 独立后段钩 | BEGINDOCEND 与 BODY 恒 TikZ | `patch/p-stages.log` |

推论三条：**(a)** 试迁报告 §九R2 的「移到 unicode-math 之后（AtEndPreamble 或末位 AtBeginDocument）」两案在 sty 内均不可行（mech2 负结果＋ENDPRE 探针显示 AtEndPreamble 时点尚是 `\mathchar"326B`、其后仍被覆盖）；**(b)** 已实证有效的 sty 外修法只有件面导言末 top-level 再注册（`main-ctl-parprobe` 像素归零先例）；**(c)** sty 内唯一可落位＝`begindocument/end`（全部 begindocument 块执行完后运行，探针全绿）。`\cha`（:60）非 unicode-math 符号，无此病，不动。

## 二 补丁① `\extrarowheight` 复刻行（卷末速查表行高回落，像素差 0.28–0.36%）

**点位**：qp-m3.sty **:162 `\setlength{\arrayrulewidth}{0.4pt}` 之后、:163 `\newcount\rowmax` 之前**（对齐 M2 qp-layout.tex:118→:130 的注释流位序；全局 dimen，导言任意位皆生效，取此处为叙事同序）。

**diff 草案**（已落于 `负测/patch/qp-m3.sty`）：

```latex
\setlength{\arrayrulewidth}{0.4pt}
+ % 【补丁①·复刻六宏 qp-layout.tex:130】全局行高垫 1.7mm——v4.3 首版 4.1mm 直译超 3.2mm、0908 修
+ %   0.6/0.4/1.0mm 三轮回填，F 片B #30 甲案标定终值 1.7mm（E=1.7 时 padT 3.4–3.5 落窗、表头行高
+ %   9.18≈全品 9.03；E≥1.8 表头出窗）。漏复刻实证：件面速查表行高回落 0.28–0.36%（试迁报告 §四.1，
+ %   测评卷 p3 表首行 y0 196.0→190.9＝−5.1pt）。生效域＝全局 dimen（array.sty 分配），导言一设
+ %   全件生效，与 M2 六宏口径一致；须全局设、不入分组。
+ \setlength{\extrarowheight}{1.7mm}
```

**生效域**：与 M2 同律——包内一设、全件所有 tabular 行高 +1.7mm/行（`arraystretch`=1.05 下首行上沿实发 +5.08pt，与试迁移位 −5.1pt 互验）；个别 M3 件型若要免垫须局部组内置 0，纪律同 M2。

**负测设计＋读数**（复现旧病→病愈）：`orig/p-eh` vs `patch/p-eh`＋`orig/p-stages` vs `patch/p-stages`——旧病 `EH-VALUE: 0.0pt`、表盒高 22.18758pt；病愈 `EH-VALUE: 4.83694pt`（=1.7mm）、表盒高 27.26637pt（Δ=+5.07879pt）。终验仍以试迁既有像素门为准：对照件补此钉后测评本三件该页 0.0000%（试迁报告 §四已证）。

## 三 补丁② `\parallel` 件面末位再注册的最稳位（滚A p1 矢量框 10→0）

**点位**：qp-m3.sty **:104-108 整块替换**（注释行＋4 行 `\AtBeginDocument` 钩块）；TikZ 几何体逐字不动。

**diff 草案**（已落于 `负测/patch/qp-m3.sty`）：

```latex
- % \parallel 复刻全品 ∥ 几何（TikZ 双平行四边形，M2 variantF 标定档）
- \AtBeginDocument{\renewcommand{\parallel}{\mathrel{\begin{tikzpicture}[x=1em,y=1em,baseline={(0,0)}]
-   \fill (-0.412,-0.016) -- (-0.375,-0.016) -- (0.114,0.956) -- (0.077,0.956) -- cycle;
-   \fill (-0.115,-0.016) -- (-0.078,-0.016) -- (0.411,0.956) -- (0.374,0.956) -- cycle;
- \end{tikzpicture}}}}
+ % 【补丁②·改挂 begindocument/end】机理见补丁方案 §一：\AtBeginDocument 在包内注册得 (qp-m3)
+ %   标签，槽位必先于 (unicode-math-xetex) 的 begindocument 块而被覆盖（sty 内移位不救，mech2 实锤；
+ %   AtEndPreamble 亦不救）。begindocument/end＝独立后段钩，晚于全部 begindocument 块（含件面
+ %   导言 top-level 后补注册），为 sty 内最稳位。保底（sty 外）＝件面导言末位 top-level 再注册
+ %   （main-ctl-parprobe 先例）。kernel 依赖 \AddToHook ≥2020-10-01（现 TinyTeX xelatex 通过）。
+ \AddToHook{begindocument/end}{\renewcommand{\parallel}{\mathrel{\begin{tikzpicture}[x=1em,y=1em,baseline={(0,0)}]
+   \fill (-0.412,-0.016) -- (-0.375,-0.016) -- (0.114,0.956) -- (0.077,0.956) -- cycle;
+   \fill (-0.115,-0.016) -- (-0.078,-0.016) -- (0.411,0.956) -- (0.374,0.956) -- cycle;
+ \end{tikzpicture}}}}
```

**残余风险登记**：若未来件面导言在 begindocument/end 阶段又有后手注册（如再挂数学宏包同槽覆盖），后注册者胜——未见解先例，登记备查；量产门的 `\meaning` 断言（下）可兜底。

**负测设计＋读数**：五面谱（orig 旧病 ∥／mech 机理钉 HOOK105-POST=TikZ 而后段=∥／mech2 移位不救＝∥／patch 病愈 BEGINDOCEND+BODY=TikZ／six 对照存活）＋dbg 轨迹面；机器断言＝`\meaning\parallel` 须为 `macro:->\mathrel{\begin{tikzpicture}…`。终验：滚A 对照件+parprobe 两页 0.0000%（试迁已证）。

## 四 补丁③ 三栏 linewidth 挂点（括线 1082.8pt 跨三栏反例）

**结论**：主落点＝**件面 `\jpcol` 补 2 行**（试迁 §五 实证必需、补后 0.0000%），**qp-m3.sty 本轮不动**。落位例（测评本三件面，滚B/main.tex:119-121 同型）：

```latex
  \newcommand{\jpcol}[1]{\raisebox{0pt}[0pt][0pt]{\vtop{\hsize\jpcolw\parskip0pt\parindent0pt
+   \setlength\linewidth{\jpcolw}\setlength\columnwidth{\jpcolw}% 换装补钉：qp-m3 括线盒按 \linewidth 取宽
    \fontsize{10.5pt}{17.7pt}\selectfont\relax#1}}}
```

**sty 侧观望位**（不采纳、登记待裁）：`\ansruledopen/:537`、`\ansruledclose/:540`、`\ansgrayopen/:531`（minipage 宽参）、`\tailfill/:579,588` 的 `\linewidth` 改按 `\hsize` 取宽——可让一切固定栏器件免件面补钉，但灰底模在零声明高 `\vtop` 内的取宽/换行行为**未跑对照档**（试迁 §八.4），采纳前必须先过灰底对照＋像素对勘。

**负测设计＋读数**（8 开三栏几何＋括线模最小件）：`orig/p-linewidth` ansblock 内 `\linewidth`=**1086.90pt（382.0mm 页宽＝旧病）**；`patch/p-linewidth`（件面补钉）＝**341.43306pt（=120.0mm 栏宽）**、vtop 外 `\linewidth` 保持 1086.90pt 不受扰。（试迁实测墨宽 1082.8/340.2pt 为 PDF 墨迹口径，与本 log 读数同病同愈。）机器断言＝ansblock 内 `\ifdim\linewidth=\jpcolw`。配套静态门建议：DE 审计族扩一条「`\vtop{\hsize` 固定栏器＋qp-m3 ⇒ `\jpcol` 体必含 `\setlength\linewidth{\jpcolw}`」扫描。
