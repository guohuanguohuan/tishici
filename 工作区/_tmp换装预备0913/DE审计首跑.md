## 一、[D] 静默溢出审计.py 口径

三层读数（承件族判定→编译 log→印面提取），默认逐件自动发现同目录同名 .log/.pdf：

1. **静态扫描（tex＋\input/\include 链）**：零高固定栏＝`\raisebox{0pt}[0pt][0pt]{\vtop…}` 定义式（逮 \jpcol 宏名与 \jpthree 排布行数）；手工固定栏（\hbox to＋\vtop）亦承件；multicols 判「可回流非静默族」（其出栏 TeX 报 Overfull \vbox，非本门命门）。几何自 `\geometry`＋`\jpcolw/\jpgap` 解析推栏带（缺省回退 8 开横放三栏 house 值 399.8×284.2／left 8.9／120＋11）。键账＝`% ans:` 注释锚 ↔ `\begin{ansblock}[键]` 编译锚**对集合**；档向自 `\showanstrue/false`、`\def\mthreepure{}`、`[pure]` 包选项。
2. **log 解析**：Error／Overfull h·vbox／Missing char／页数／M3-ANSKEY 键集；**tex 有块而 log 无键＝编译层吞块红旗**（比印面丢块更早一层，A 案实测两档恒发 19 故不拦 A——分层定位用）。
3. **印面提取**：逐页逐栏内容底边（文本∪无限裁剪文本∪图∪矢量线）；**越纸绝对红**＝任何栏内墨条底＞纸边（页高）硬线，页脚签名带豁免逻辑**不可遮蔽**此路径（越纸条先入账再判豁免）；触页脚带（纸边−7.2mm 起）＝零误报档 WARN 登记／严档 FAIL；双取文（常规 vs 无限裁剪）分型答案区缺失：「印在纸外」vs「内容流整块丢失」；**tex 有 ansblock 而 PDF 对应区无文本＝静默丢块红旗**（附 TeX Error 0 定性＝军师钉的静默失效类）。
- 档位：`--grade zero-fp`（默认，冒烟/正装门：出纸/丢块/吞块红、触带警告不判死——P1 基线 p1 栏2 底 280.5mm 触带系 PL1 冻结卷式固有，判死即误报）；`--grade strict` 触带亦死。退出码 0 全过／1 红旗／2 用法错。
- **负测/正测（--selftest 内置，实测读数）**：N1 印面静默丢块（4/5 印面）拦＝红旗1✓；N2 出纸越界拦＝红旗3✓；N3 log 吞块拦＝红旗1✓；P0 健康 true 档、P1 纯题档零答案、P2 非承件无键 放行＝红旗0✓✓✓。——**6/6 全过（负测真拦·正测真放行）**。

## 二、[E] 答案印面计数.py 口径

印面答案区＝`N. [答案]` 数号集合＋`[答案]` 总现数（[详解]/[点睛] \ansnote 形单列不并计）；键账三源＝`--keys`（答案册 body.tex `\ansitem{N}{…}` 或试迁键账 json）＞`--pct`（件 tex 双锚）＞`--log`（M3-ANSKEY，两档恒发⇒可断**true/false 键账恒等**）。判定全走**对集合不对数**：B-true 档＝键数号集合↔印面答案区集合双向 diff（计数相等但号集不同也红，防挪号假对平）；false 档＝印面答案区须 0（泄答红）。--selftest＝对平正例＋true 丢块负例＋false 泄答负例，3/3 全过。退出码 0/1/2。
