## 一、病灶根因（机制级取证）

旧卷件三栏＝件型层 E `\jpthree{c1}{c2}{c3}`（测评卷 main.tex:121-125）：

```
\jpcol{#1} := \raisebox{0pt}[0pt][0pt]{\vtop{\hsize\jpcolw …#1}}   三栏以 \hspace{\jpgap} 手拼
```

吞块机理链（三环，缺一不吞）：

1. **零高申报**：`\raisebox{0pt}[0pt][0pt]` 向页构建器申报**高 0 深 0** 的整栏盒——`\pagegoal` 永不被满足，页内永不触发断页与容量核算；TeX 只见「一个零高的点」，栏内实际排了多少、排到纸边没有，页构建器无从知晓。
2. **冻结栏容**：每栏＝单个 `\vtop` 盒，栏内不可断、栏间不可流——三栏内容量在作者手分时就冻结；题后插入 ansblock 只能使**本栏**内容向下生长（不会挤入次栏）。
3. **静默越纸**：生长越过纸边时，因盒高申报为零，TeX 不产生 `Overfull \vbox`（盒体只是向页面坐标系下方延伸出纸），log 三零、印面丢块——题6（p1 栏3）、题12（p2 栏2）实证。

课时件为何不病：qp-m3.sty 既载 multicol（`\multicolsep=0pt`＋`\raggedcolumns`＋切栏容差旋钮），ansblock 括线模为**流内可断块**（块前 `\addvspace{1.4mm minus 1.4mm}` 可断胶＋括线 nobreak 链），multicol 按真实高度切栏——课时件题后紧跟正常，正说明病在卷件排布器、不在答案环境。

## 二、新机制设计：卷件三栏回流制（`\juancols`＝multicols 三栏）

**唯一改造点＝件型层 E′**（试排件 `试排-测评卷p1/main.tex:186-196`）：

```latex
\setlength{\columnsep}{\jpgap}      % 栏距 11mm＝旧 \hspace{\jpgap}
\setlength{\columnseprule}{0pt}     % 无栏线＝旧手拼三栏
\newenvironment{juancols}
  {\begin{multicols}{3}\fontsize{10.5pt}{17.7pt}\selectfont}%
  {\end{multicols}}
```

观感参数逐项对照（全保持）：

| 参数 | 旧 \jpthree | 新 \juancols | 等形 |
|---|---|---|---|
| 栏宽 | `\jpcolw`=120mm（\hsize 手设） | multicol 列宽＝(382−2×11)/3＝120mm | ✓ 逐位等宽 |
| 栏距 | `\hspace{\jpgap}`=11mm | `\columnsep`=11mm | ✓ |
| 栏线 | 无 | `\columnseprule`=0pt | ✓ |
| 字号 | \vtop 内 10.5/17.7 | 流首同值 | ✓ |
| 卷头/页脚/角饰 | 件型层 A~D | **零改动照抄** | ✓ |
| 换装补钉 | `\jpcol` 内 `\setlength\linewidth{\jpcolw}` | **退役**（multicol 逐栏自更新 \linewidth） | − |

**「答案块为何不再被吞」机理**：题面与 ansblock 写入**同一垂直流**，不再手分三栏。multicol 列构建器以每盒真实高度对 `\vsize` 核算：栏满即在**合法切点**（ansblock 前可断胶／括线 nobreak 链）切栏，余料自动入次栏、页满自动翻页（multicols 跨页续流，原 `\newpage` 手分页撤除）；任何装不下的盒必报 `Overfull \vbox` 进 log——**静默丢失在机制上不存在**（要么排出、要么可见红）。零高盒消失后，[D] 门的「零高固定栏承件族」判定自然失配，卷件回归与课时件同一严档。

**断点行为实证**（试排 p1）：Q2、Q5 的答案块在栏尾被合法切断、块首随次栏顶续排（`main-p1.png` 栏2 顶「2. [答案] C」）——即课时件同款「可断栏流内块」行为；灰底模注记：`\ansblockgraytrue`（lrbox minipage）为不可断盒，multicols 下整块移次栏、不丢但可能留栏尾空；测评/滚动既有口径 `\ansblockgrayfalse`（括线模）不受影响。
