## §一 盲解记录（独立逐步，先于读详解锁定）

### 命制-P1-9.1-简-1（单选）

- 物理链：摩擦起电实质＝核外束缚较弱电子在物体间转移（书3）；得电子带负电、失电子带正电；电荷守恒（书4）不创生；感应中不接触则无电荷跨体转移。
- 逐选项：**A ✓**（玻璃棒带正电＝失电子→电子转移到丝绸，丝绸得电子带负电，方向与电性自洽）；B ✗（"得到电子而带正电"自相矛盾，转移方向也说反）；C ✗（摩擦只是电子转移，不创造电荷，违书4）；D ✗（"靠近被吸引"＝静电感应极化，未接触，无电荷从玻璃棒转移到小球，"吸引≠电荷转移"）。
- **盲解答案：A**｜步数：四选项各一步直判，零计算、零讨论。

### 命制-P1-9.1-简-2（单选）

- 逐步：比荷＝电荷量/质量＝e/mₑ＝1.60×10⁻¹⁹÷9.11×10⁻³¹＝0.1756×10¹²＝**1.76×10¹¹ C/kg**。
- 逐选项：A ✓；B ✗（指数 −11，数量级错）；C ✗（5.69×10⁻¹² 系 mₑ/e 倒数值、单位 kg/C，是"质荷比"非比荷）；D ✗（倒数＋数量级双错）。
- **盲解答案：A**｜步数：一步除法。

### 命制-P1-9.1-简-3（单选）

- 逐步：代数和＝(+3.0−5.0)×10⁻⁹ C＝−2.0×10⁻⁹ C（先中和）；完全相同球均分→各 **−1.0×10⁻⁹ C**。
- 逐选项：A ✓；B ✗（−4.0＝绝对值直接平均，漏"异号先中和"）；C ✗（绝对值对但符号配反）；D ✗（中和≠电荷消失，违守恒）。
- **盲解答案：A**｜步数：代数和＋除 2（1~2 步）。

### 命制-P1-9.1-中-1（解答）

- (1) 丙原不带电、与甲完全相同，接触后平分：丙＝q甲/2＝+2.5×10⁻⁹ C ⇒ 甲在分开瞬间 q甲＝**+5.0×10⁻⁹ C**。甲、乙起初接触且整体不带电，感应分离只使电荷在两球间转移、系统代数和恒为 0 ⇒ q乙＝**−5.0×10⁻⁹ C**（此步只依赖守恒，不依赖对称假设）。校验：+5.0−5.0＝0 ✓。
- (2) 甲为靠近 P 的近端且带正电；感应"近端异号、远端同号"⇒ **P 带负电**；互证：远端乙＝−5.0×10⁻⁹ C 与 P 同号，自洽 ✓。
- **盲解：(1) 甲 +5.0×10⁻⁹ C、乙 −5.0×10⁻⁹ C；(2) P 负电**｜定位：一层逆向（末值×2 反推初值）＋守恒＋方向语反用，无分类分支。

### 命制-P1-9.1-难-1（解答·分类支逐支走完）

- (1) 玻璃棒（丝绸摩擦）带正电→金属球内自由电子被吸引，**由乙侧向近端甲侧移动**；分开瞬间甲有多余电子带**负电**、乙缺电子带**正电**；甲乙系统始总电荷 0、感应只是内部转移（书4）⇒ 等量异号，**q₁＝q₂**（依据＝电荷守恒）。
- (2) 链算：乙(+q)与丙(0)接触→乙＝丙＝+q/2；甲(−q)与丙(+q/2)接触→各得 (−q＋q/2)/2＝−q/4。由丙末 −1.0×10⁻⁹ C：−q/4＝−1.0×10⁻⁹ ⇒ **q₁＝q＝4.0×10⁻⁹ C**；末态甲＝丙＝−1.0×10⁻⁹ C、乙＝+2.0×10⁻⁹ C；校验代数和 0 ✓。
- (3) 分类支：**支一（丙末取 −1.0）**＝物理链锁定支——甲丙接触前二者总电荷 −q＋q/2＝−q/2＜0，均分后丙必为负，丙末≡−q/4；**支二（丙末取 +1.0）**⇒ q＝−4.0×10⁻⁹ C，与 q 表"电荷量大小"矛盾，且与(1)"甲负乙正"的感应判定矛盾→**舍**。结论：**仍能唯一确定，q₁＝4.0×10⁻⁹ C**（只测大小不测电性，符号由感应链定，大小关系 |丙|＝q₁/4 与电性测定无关）。
- **盲解：如上三问**｜分类支：±两支并存、按物理约束取舍一支＝真分类。

### 命制-P1-9.1-难-2（解答·全枚举）

- (1) A、B 接触时整体不带电，感应分离只转移不增减（书4）⇒ 等量异号 ⇒ **B＝−8.0×10⁻⁹ C**；依据＝电荷守恒（代数和恒 0）。电性互证：橡胶棒（毛皮摩擦）带负电→近端 A 异号带正，与题给 A＝+8.0×10⁻⁹ C 相符 ✓。
- (2) 初态 A＝+8、B＝−8、C＝0（×10⁻⁹ C）。球对三选二、有序、不重复共 6 序，逐序算末态 (A,B,C)：

| 操作序 | 末态 (A,B,C)×10⁻⁹ C | C 末值 |
|---|---|---|
| AB→AC | (0, 0, 0) | **0** |
| AB→BC | (0, 0, 0) | **0** |
| AC→AB | (−2, −2, +4) | **+4.0** |
| AC→BC | (+4, −2, −2) | **−2.0** |
| BC→AB | (+2, +2, −4) | **−4.0** |
| BC→AC | (+2, −4, +2) | **+2.0** |

  ⇒ C 可能值 **5 个**：0（AB 先行的两序共用）、+2.0、−2.0、+4.0、−4.0（×10⁻⁹ C）；每序末态代数和均 0 ✓。
- (3) **不能**。系统与外界无电荷交换，总电荷代数和恒为 0（分开瞬间 +q−q+0＝0）；若三球都带同种电荷且均带电，则总和必非零（同正＞0／同负＜0），违守恒——无论何种顺序、多少次均不可。三球"完全相同"只能是全 0（先令 A、B 接触即得），但"都不带电"≠"都带同种电荷"。
- **盲解：如上三问**｜分类支：六序穷举＋守恒反证＝真分类。
