## 一、工序与验收实证

编译（丝带走 remember picture，必须两遍）：

```
xelatex -interaction=nonstopmode -halt-on-error main.tex     # 第 1 遍
xelatex -interaction=nonstopmode -halt-on-error main.tex     # 第 2 遍
```

| 验收项 | 命令／手段 | 结果 |
|---|---|---|
| error 0 | `grep -c '^!' main.log` | **0** |
| Overfull 0 | `grep -c Overfull main.log` | **0**（Underfull 亦 0） |
| Missing character 0 | `grep -c 'Missing character' main.log` | **0** |
| 恰 2 页 | `grep -o "Output written on main.pdf ([0-9]* pages" main.log` | `2 pages` |
| 页面尺寸 | PyMuPDF `page.rect` | 两页均 **399.7995 × 284.2013 mm** |
| 关键词 | PyMuPDF 取文本＋去空白匹配 | `班级`/`姓名`/`得分` ✓、`单元素养测评卷（一）` ✓、`第一章` ✓、`（时间：120分钟` ✓、`分值：150分）` ✓、`卷01` ✓、`02卷` ✓、`【答案】`/`【详解】` ✓、丝带白字 `数学` ✓ |
| png 目视 | ReadMediaFile 看 page1/2 ＋ 丝带 26px/mm 等比并排裁片 vs p01 | 已过，见 §四、§五 |

关键词一处坑：文本层里是「120 分钟」带一个空格＝xeCJK 中西文间自动空隙（`\CJKecglue`）。扫描页同一位置实测墨隙 1.71mm 确有此隙，属形制正确，故关键词自检须**去空白**匹配，逐字 `grep` 会假失败。

收尾复现：删完临时件（§六.10）后再走两遍编译，`err/Overfull/Underfull/Missing character` 仍全 0、`2 pages`、两页 399.7995×284.2013mm，png 重渲后目视与上表一致 —— 即 `main.tex` 不依赖任何临时件，自包含成立。

## 五、丝带角饰（JT-01）复刻说明

### 5.1 取数与坐标约定

全部几何取自 `p01.png` 逐像素实测（÷14.062px/mm），写成**页面绝对坐标**（x 向右、y 向下，单位 mm）。`main.tex` 里 tikzpicture 走 `overlay,remember picture`，先 `\path (current page.north west) coordinate (O);`，再 `\begin{scope}[shift={(O)}]`，单位 `x=1mm,y=1mm`，页面 y 值一律写成负数 `(X,-Y)`。

**为什么不镜像**：曾试 `y=-1mm` 直写正数，形状落位正确但 45° 白字被镜像轴翻成与斜带**垂直**（实测轴长 8.38／垂直厚 9.82，与扫描页 12.32／4.98 恰好互换），故弃。
**为什么不用 picture 环境**：`\begin{picture}(0,0)` 会裁切越界内容，丝带只剩一角（非白面积 126.6mm²，实测应为 588mm²）。

## 六、其他差异与遗留

1. **材料截排**：样张只排 §1.1 的 6 题，栏3 全空；扫描页三栏满排。三栏框架（栏宽 120／栏距 11／无栏线／栏顶齐平）已落位并按 §四 复核，但"满排观感"未复刻。
2. **组行文案按卷型拼装**，与扫描页逐字不完全一致。p01 组行一已对齐（行2 墨缘 70.37 对 70.13）；p02 组行二按扫描页**删去**「全部选对的得…分」句（原件无此句，样张首行换行点因此与原件一致）。
3. **题号序与组行不严格对应**（截排所致）：Q4 落「二、选择题」、Q5 落「三、填空题」、Q6 落「四、解答题」，区组对应成立；分值 40＋18＋15＋77＝150 与卷名「分值：150分」自洽。
4. **【答案】/【详解】内联**：全品真身答案另册，本样张按任务书要求内联排在题下，属形制差异（非零件缺失）。
5. **选项行距取 19pt**（variantF 选项档）。扫描页题干→首选项墨顶距 7.18mm≈20.4pt 为下限（选项含向量上箭头时墨顶再抬高），正文主峰 17.7pt；未单独标定测评卷选项档。
6. **填写行整行宽 +3.42mm**（样张 63.16 对扫描页 59.74）：右缘已按扫描页齐栏右（128.62 对 128.94），差在标签字号与冒号全/半角——登记 11pt 全角冒号，原件该行字心距与冒号占位略紧。
7. **零件库字号登记值系统性偏大**（本件三处反推证据）：卷名 22→20.5pt、页脚余字 8.5→7.5pt、丝带白字 26→17pt；正文 10.5pt（五号）与页码 14pt 复核无误。疑登记值按墨高反推且取整到 Word 标准字号，建议零件库按"字心距"复核一遍。
8. **`\headwidth` 坑（多机复用须记）**：fancyhdr 在 `qp-layout.tex` 首次 `\geometry`（a4）时把 `\headwidth` 定成 175.6mm，件型层二次 `\geometry` 换 8 开横放**不会**回头改它 → 页脚整串落在页面中段。样张在件型层 D 显式 `\setlength{\headwidth}{\textwidth}` 钉回。
9. **`\vtop` 首行锚点坑**：`\topskip=0pt` 时 `\jpcol` 的 `\vtop` 首行基线被顶在版心顶上，墨顶反而高出约 3.1mm。件型层加 `\jplead`（零高锚空行＋`\nointerlineskip`）后，首行墨顶 11.89 对扫描页 11.98 ✓。卷头页栏1 首件是丝带零高 hbox，天然自带该锚，不需另加。
10. 临时件收尾已删净：本目录内 `_cal.py`、`_rib*.py`、`_probe.*`、`_*.png`、`texput.log`、`__pycache__/`，以及前序步骤误写到 `C:/tmp/` 的 `crop_tl.png`、`crop_right.png`。目录现存文件＝`main.tex`／`main.pdf`／`main.log`／`main.aux`（后两件留作三 0 实证）／六个 `qp-*.tex`／`png/page1-2.png`／本文件。
