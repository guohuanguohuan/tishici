## 二、宏用法（件面速查）

| 宏 | 形 | 用 |
|---|---|---|
| `\liB{变式\textbf{N}}{难度}{\duoxuan\hspace{0.6em}|空}{题面}` | 四参 | 练习变式题干；多选第三参填 `\duoxuan\hspace{0.6em}`（多选全件恒 ≤2 道） |
| `\tjdnr{点}{名}{例\textbf{N}}{难度}{题面}` | 五参 | 探究点例题 |
| `\xiexwei{12mm}` | 一参 | 题后书写位（\underline 下划线域） |
| `\kongbai{}` | — | 填空空位（预习/填空题干内） |
| `\begin{ansblock}[键]\end{ansblock}` | 环境 | 答案块；`[键]` 锚两档恒发射（对号门）；**纯题档整块吞零印面** |
| `\ansitem{N}{值}` | 两参 | 题号[答案]条；N＝印面号（连号 1–23），值≡答案侧「值：」行逐字 |
| `\ansnote{详解}{文}` | 两参 | [详解]行；悬挂 `\qpind` 自动 |
| `{\ansblockgrayfalse \begin{ansblock}…\end{ansblock}}` | 包装 | 括线模（上下 hairline，可跨栏断）；缺省灰底盒（**不可跨栏断**） |
| `\tailfill` | 无参 | 件尾「笔记与错题整理」框，吃尾空 |

## 四、常见坑（血泪清单，逐条实测）

1. **catcode 雷（本片新发现，最重）**：本件 CJK 字 catcode＝**11（字母）**——控制词直连
   CJK 会被吸入**单一 csname**：`\noindent所以` 报 `! Undefined control sequence`，错误
   上下文显示的 csname 即 `noindent所以`（log 字节所见 print_cs 尾随空格是铁证）。修法：
   控制词后**带空格**（`\noindent 所以`，空格被 reader 吞、零视觉差）或隔 `{}`。
   全文审计器：`rg '\\[a-zA-Z]+\p{Han}' main.tex`（命中 0 才放行，回流门可并入）。
2. **禁 bash-python heredoc 写 tex**：工具链吃反斜杠（`\\par`→`\p`），曾致 main.tex 损伤。
   改 tex 一律 Edit/Write 工具；python 处理须落盘脚本文件执行，反斜杠用 `chr(92)` 拼。
3. **编译 cwd＝片目录**：qp-m3.sty 本地挂载，中文路径下绝对路径 `\input` 不可靠。
4. **Underfull 治理三招**（三零门承重）：① `\frac`/`\left(\right)` 线性化（`a/b`、`( )`，
   贴近批A 详解源且恢复断行）；② 公式密集详解（E8 类）**每式独立成段**——`\par\noindent `
   分行，行末 parfillskip 吸收，永不 underfull；③ `\xeCJKsetup` CJKglue 微调（见上）。
5. **灰底 vs 括线判模**：灰底盒不可跨栏断；括线（grayfalse 包装）可断。判据＝块内容估高
   （全角1·ASCII0.5，剔`\命令`；÷23 栏宽字）**top-5** → 括线（本片 T2/E2/E3/E14/T1），
   第 5/6 名估高间隔 ≥1 行；渲染面硬计数复核：灰底大矩形 18、ansrule 长线 12（5块×2＋尾框2）。
6. **印面连号制**：号 1–23＝探究 1—18＋课堂评价 19—23 连号；`\ansitem` 首参＝印面号，
   例/变式标签同号连排。键↔号映射见 值台账-课时01.json。
7. **键型两档**：值型 17 键（`\ansitem` 值≡答案侧「值：」行**字节级**）；过程型 6 键
   （E8/E11/E13/E14＝「证明见详解．」；T1/T2 换算：⟺→`$\iff$`、x₁→`x_1` 数学下标，
   首锚`(1)见详解；`＋末锚、长度带 0.8–2.0×）。
8. **清洗注记**（回嵌答案侧值时）：E6 批A 答案栏检验 ✓ 句剔除；▱→`\pxparallelogram`
   子块路由；E15/E16 详解句号照录批A「。」。
9. **多选 ≤4 选项**（`\lxopt` A–D），全件多选恒 ≤2 道（本片 E2/E3）；`\tailfill` 无参
   置 `\end{multicols}` 前；ketang 环境内 G5 恒 5。
10. **PDF 文本层目验口径**：true「N. [答案]」号序 1–23（`(\d+)\.\s*\[答案\]`，20+ 无空格
    形也匹配）；false 泄答词（[答案]/[详解]/证明见详解）＝0；尾块「笔记与错题整理」两档恰 1。
