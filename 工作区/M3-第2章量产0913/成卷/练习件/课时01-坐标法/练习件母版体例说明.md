## 二、宏用法（件面速查·练习件增量）

| 宏 | 形 | 用 |
|---|---|---|
| `\tihao{N}` | 一参 | 悬挂题号（1~9 挂 5.75mm／10~16 挂 7.6mm，\lxhang 随动） |
| `\zu{题型名×槽型}` | 一参 | 组名栏；题型名照题面库头第 3 字段主干（§十二 canonical 名），槽型照第 2 字段 |
| `\tieside{难度(知识点N)}` | 一参 | 难度照头标第 4 字段简/中档词；知识点 N 照导学件知识导学分册映射 |
| `\duoxuan` | 无参 | 多选标，题号行后附（`\tihao{N}\duoxuan\hspace{0.6em}\zu{…}`）；每件 ≤4 |
| 选项四连排 | — | `\bindopt {\fontsize{10.5pt}{\qpTJgLeadLiti}\selectfont \makebox[\dimexpr0.25\linewidth-0.25\lxhang\relax][l]{A．…}×4\par}` |
| 选项两连排（降档一档） | — | 同上而 `\makebox[\dimexpr0.5\linewidth-0.5\lxhang-0.25em\relax][l]{…}` ×2 |
| 选项单列（降档底档） | — | `\lxopt{A．…}` 逐行（可自然折行悬挂） |
| `\liubai[高]{解答书写区}` | 两参(参1可选) | 解答题题面后、ansblock 前置；默认 16mm，两问 24mm，三问及以上 32mm，cap 40mm；纯题档吞 ansblock 不吞 \liubai（作业本形态自动成立） |
| `\kongda{值}` | 一参 | 填空题空位印答（详解版印值、纯题版退定宽空线，两档等形） |
| `\kongbai{}` | 无参 | 题面固定空位（本件未用，预留） |
| `\begin{ansblock}[键]…\end{ansblock}` | 环境 | 题后紧跟答案块；`[键]` 锚两档恒发射 M3-ANSKEY（对号门）；体内行首 `% ans:键` 源层注释锚照留 |
| `\ansitem{N}{值}` | 两参 | 题号[答案]条；N＝印面号（＝\tihao 号），值≡答案侧「值：」行**字节级** |
| `\ansnote{详解}{文}` | 两参 | [详解]行；悬挂 `\qpind` 自动 |
| `\tailfill` | 无参 | 件尾「笔记与错题整理」框，吃尾空，每件恰 1 |

**全线括线模（练习件特有，§四.3 钉死）**：导言 `\ansblockgrayfalse` 一次置定、件内不切换、
零逐块包装——灰底 lrbox 盒不可跨栏断，题后长详解（尤 E15/E16 类）不宜；渲染面断言
ansbg 灰底大矩形＝0。「>8 行→括线模」口径在全线括线下自然满足。

**符号路由 preamble（逐字照抄导学件母版；无 ▱/− 用件的片可整块保留，零副作用）**
＋`\xeCJKsetup{CJKglue={\hskip 0.10em plus 0.08em minus 0.05em}}` 断行微调，同 S2 实测档。

    --expect manifest练键序=工作区/_tmpM3S3母版0914/门谱/键表-课时01-练E16.txt  # 三源六腿 PASS

## 四、常见坑（承 S2 血泪清单＋本片新增）

1. **CJK catcode 雷（承 S2 #1，最重）**：件内 CJK 字 catcode＝11——控制词直连 CJK 会被吸入
   单一 csname（`\noindent所以` 报 Undefined）。修法：控制词后**带空格**或隔 `{}`。
   审计器：`rg '\\[a-zA-Z]+\p{Han}' main.tex`（命中 0 放行）。
2. **禁 bash-python heredoc 写 tex（承 S2 #2）**：改 tex 一律 Write/Edit 工具；python 处理
   落盘脚本执行。
3. **编译 cwd＝片目录（承 S2 #3）**：qp-m3.sty 本地挂载，绝对路径 \input 不可靠。
4. **值快照键域过滤（本片新增）**：值台账底稿 vals 系答案侧全集（23 键），gen台账 滤练键序
   E1~E16 后才入台账——不过滤则对平门三源红（导/拓 7 键浮账）。
5. **尾框线断言（本片修正）**：练习件括线块可跨栏，末页 ansrule 长线＞2 根属常态；断言改
   「尾框对＝末页绘图序最后两根（同列纵列）」＋全局 34 根＝16块×2＋尾框2 钉死。
6. **Underfull 治理三招（承 S2 #4）**：\frac/\left(\right) 线性化；公式密集详解（E8 类）
   `\par\noindent` 每式独立成段；CJKglue 微调。本片首编即三零，未再调参。
7. **印面清洗（承 S2 #8）**：E6 详解 ✓ 记号剔除（检验句文句保留）；E15/E16 句号照录批A「。」；
   ▱→\pxparallelogram。【注】行不入印面。
8. **多选 ≤4**：本件 2（E2/E3）＝manifest 期望值；\duoxuan 题号行后附，答案多字母按答案侧
   规范化值照录（禁件内重排）。
9. **降档梯实录**：五道选择题四连排全不可行（真算读数见值台账「降档登记」），两连排/单列
   落位后槽宽门双档 0 旗；禁缩字号/负 kern/删标点凑宽。

## 五、练习件与导学件差异要点（波次推广必读）

| 维 | 导学件（S2 母版） | 练习件（本母版） |
|---|---|---|
| 节序 | 章头→课前预习→知识导学→课时探究→课堂评价 ketang→尾块 | \keshi 课时标题→三档 dangbadge→16 题→尾块（零章头零预习零 ketang） |
| 键域 | 23 键＝G5＋E16＋T2 | 16 键＝E1~E16（拓/测/滚/G 全隔离） |
| 题型宏 | \tjdnr 例＋\liB 变式交替 | \tihao＋\zu 组名栏连排（M2 同构） |
| ansblock 选档 | 判模制：估高 top-5 括线、余灰底（逐块 {\ansblockgrayfalse 包装） | **全线括线**：导言 \ansblockgrayfalse 一次置定，零逐块包装，灰底禁用 |
| 答案块落点 | 例/变式题后 | 每题（含选择/填空）题后紧跟；选择/填空亦有 \ansitem 值行 |
| 书写区 | \xiexwei{…}（例/变式位） | \liubai[16~40mm]{解答书写区}（按小问数；纯题档保留） |
| 填空印答 | \kongbai（预习位两档等形空线） | \kongda{值}（详解版印答开关宏） |
| 页数 | true 6／false 3 | true 4／false 2（false≤true 门同） |
| 尾块断言 | 末页 ansrule 恰 2 | 尾框对＝末页绘图序最后两根＋全局 34 根钉死 |
