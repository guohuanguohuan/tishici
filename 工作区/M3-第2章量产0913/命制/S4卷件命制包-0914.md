## 三、定钉题 3｜K5-a→2章-测-5（2.4 曲线与方程·单选·中 0.85·5分）

A．x²＋y²−3x−3y＋4＝0　　B．x²＋y²−3x−3y−4＝0
C．x²＋y²＋3x＋3y＋4＝0　　D．x²＋y²−3x−3y＋10＝0

**【答案】** A

**【详解】** 设 P(x,y)。|PA|²＝(x−3)²＋y²，|PB|²＝x²＋(y−3)²。由条件：

## 四、定钉题 4｜K5-b→2章-滚B-4（2.4 曲线与方程·单选·中 0.85·5分）

**题面**：已知曲线 C 的方程为 F(x,y)＝0，则下列说法正确的是（　）
A．若曲线 C 上点的坐标都是方程 F(x,y)＝0 的解，则以方程 F(x,y)＝0 的解为坐标的点也都在曲线 C 上
B．若以方程 F(x,y)＝0 的解为坐标的点都在曲线 C 上，则方程 F(x,y)＝0 是曲线 C 的方程
C．若曲线 C 上点的坐标都是方程 F(x,y)＝0 的解，且以方程 F(x,y)＝0 的解为坐标的点都在曲线 C 上，则方程 F(x,y)＝0 是曲线 C 的方程
D．若曲线 C 关于 y 轴对称，则 F(−x,y)＝−F(x,y) 对一切实数 x、y 成立

**【答案】** C

**【详解】** 曲线与方程的对应须同时满足两个关系：**纯粹性**（曲线上的点的坐标都是方程的解）与**完备性**（以方程的解为坐标的点都在曲线上），缺一不可。A 只有纯粹性，推不出完备性，反例：C 为直线 y＝x，F(x,y)＝y²−x²，C 上每点满足方程，但解 (1,−1) 不在 C 上；B 只有完备性，反例：C 为两直线 y＝x 与 y＝−x，F(x,y)＝y−x，方程的解都在 C 上，但 C 上点 (1,−1) 的坐标不是方程的解，F＝0 不是 C 的方程；C 两个关系兼备，由曲线与方程的定义，方程 F(x,y)＝0 是曲线 C 的方程，正确；D 对称性不强制奇形式，反例：F(x,y)＝x²＋y²−1，曲线为单位圆，关于 y 轴对称，但 F(−x,y)＝F(x,y)，取 (2,0) 得 F(−2,0)＝3≠−3＝−F(2,0)，结论不成立。故选 C。

**【亲算自证】** C 正向证明：若 (x,y)∈C 则 F(x,y)＝0；由 F(−x,y)＝F(x,y)＝0 得 (−x,y)∈C；反之同法可逆，故 C 关于 y 轴对称外还满足「方程是曲线的方程」的两翼定义，C 正确 ✓。A 反例数值验：点 (1,1)∈C（直线 y＝x）：1²−1²＝0 ✓ 是解；解 (1,−1)：(−1)²−1²＝0 ✓ 是解但 (1,−1)∉C ✓ 推断破。B 反例数值验：解 (1,1)：1−1＝0 且 (1,1)∈C ✓ 完备成立；C 上点 (1,−1)：−1−1＝−2≠0，坐标非解 ✓ 纯粹破，故「F 是 C 的方程」假。D 反例数值验：F(2,0)＝4＋0−1＝3，F(−2,0)＝(−2)²＋0−1＝3，−F(2,0)＝−3，3≠−3 ✓「对一切实数成立」被证伪（注意在曲线上 F＝0 时 0＝−0 平凡成立，证伪点必须取非曲线点，(2,0) 不在单位圆上 ✓）。

**【域内自查】** §2.4 曲线的方程与方程的曲线定义正用＋对称性的方程刻画（换元 F(−x,y) 判对称，2.4 域内方法）；「充要条件」用语为必修既有常识；零前引 ✓。滚B 为全章复习卷（蓝图 §三：2.1~2.8＋衔接四知识点），概念回归题锚 §2.4 ✓。
