## 一 导学件 G5

### G1（单选）
【题面】圆 x²+y²=4 被直线 y=√3x+2 截得的劣弧所对的圆心角的大小为（　）
A．30°　B．60°　C．90°　D．120°
【题型名】直线与圆的位置关系（弦与圆心角）
【难度】0.65（中档）
【归属】成品C卷 2.3.3.2-1
【答案】D
【亲算】圆心 O(0,0)，r=2。O 到直线距离 d = |2|/√(3+1) = 1。弦心距 OM = 1，|AM| = √(r²−d²) = √3，故 sin∠AOM = √3/2，∠AOM = 60°，圆心角 ∠AOB = 120°，选D。

### G2（单选）
【题面】直线 xsinθ+y−1=0 (θ∈R, θ≠kπ+π/2, k∈Z) 与圆 x²+y²=1/2 的位置关系是（　）
A．相切　B．相离　C．相交　D．不确定
【题型名】直线与圆的位置关系（含参判定）
【难度】0.85
【归属】富矿 件8-#4
【答案】B
【亲算】d = |−1|/√(sin²θ+1)。由 θ≠kπ+π/2 知 sinθ≠±1，故 0≤sin²θ<1，d = 1/√(1+sin²θ) ∈ (1/√2, 1]，恒大于 r = √2/2 = 1/√2，故相离，选B。

### G3（单选）
【题面】直线 l 过点 (√3, 3) 且与圆 C: x²+(y−2)²=4 相切，则直线 l 的倾斜角的大小为（　）
A．30°或120°　B．60°或150°　C．120°　D．30°
【题型名】圆的切线方程（切线倾斜角）
【难度】0.85
【归属】富矿 件9-#3
【答案】C
【亲算】(√3)²+(3−2)² = 4，点在圆上，切线唯一。圆心 (0,2)，k_OC = (3−2)/(√3−0) = √3/3，切线斜率 k = −√3，倾斜角 120°，选C。

### G4（填空）
【题面】若直线 x−y+1=0 与圆 (x−a)²+y²=4 有公共点，则实数 a 的取值范围为___________.
【题型名】直线与圆的位置关系（求参）
【难度】0.65（中档）
【归属】成品C卷 2.3.3.4-4
【答案】[−1−2√2, −1+2√2]
【亲算】圆心 (a,0)，r=2。有公共点 ⇔ d = |a−0+1|/√2 ≤ 2 ⇒ |a+1| ≤ 2√2 ⇒ −1−2√2 ≤ a ≤ −1+2√2。

### G5（填空）
【题面】若点 P(2,−1) 为圆 (x−1)²+y²=25 的弦 AB 的中点，则直线 AB 的方程是_____．
【题型名】圆的弦长问题（中点弦）
【难度】0.65（中档）
【归属】成品C卷 2.3.3.5-6
【答案】x−y−3=0
【亲算】圆心 C(1,0)。k_CP = (−1−0)/(2−1) = −1。CP⊥AB ⇒ k_AB = 1。y+1 = 1·(x−2)，即 x−y−3=0。

## 二 练习件

### T1（单选）
【题面】直线 l: 3x+4y−1=0 被圆 C: x²+y²−2x−4y−4=0 所截得的弦长为（　）
A．2√5　B．4　C．2√3　D．2√2
【题型名】圆的弦长问题（弦长公式）
【难度】0.85
【归属】富矿 件10-#1
【答案】A
【亲算】(x−1)²+(y−2)² = 9，圆心 (1,2)，r=3。d = |3+8−1|/5 = 2。弦长 = 2√(9−4) = 2√5，选A。

### T2（单选）
【题面】已知圆 x²+y²=9 的弦过点 P(1,2)，当弦长最短时，该弦所在直线方程为（　）
A．x+2y−5=0　B．y−2=0　C．2x−y=0　D．x−1=0
【题型名】圆的弦长问题（圆内点最短弦）
【难度】0.65
【归属】富矿 件10-#3
【答案】A
【亲算】过圆内点的弦以垂直于 OP 的弦最短。k_OP = 2，故所求斜率 −1/2：y−2 = −(1/2)(x−1)，即 x+2y−5=0，选A。

### T3（单选）
【题面】若圆 x²+y²−2x+4y+m=0 截直线 x+y−3=0 所得弦长为 2，则实数 m 的值为（　）
A．−1　B．−2　C．−4　D．−31
【题型名】圆的弦长问题（弦长逆求参）
【难度】0.85
【归属】富矿 件10-#6
【答案】C
【亲算】圆心 (1,−2)，r² = 5−m。d = |1−2−3|/√2 = 2√2。(弦/2)² = r²−d² ⇒ 1 = 5−m−8 ⇒ m = −4，选C。

### T4（单选）
【题面】直线 l: y=x+m 与圆 x²+y²=4 相交于 A，B 两点，若 |AB|≥2√3，则实数 m 的取值范围为（　）
A．[−2,2]　B．[−√2,√2]　C．[−1,1]　D．[−√2/2, √2/2]
【题型名】圆的弦长问题（弦长范围求参）
【难度】0.65
【归属】富矿 件10-#8
【答案】B
【亲算】|AB| ≥ 2√3 ⇔ d = √(r²−(|AB|/2)²) ≤ √(4−3) = 1。又 d = |m|/√2 ⇒ |m| ≤ √2，选B。

### T5（单选）
【题面】直线 l: y=k(x−1)+1 和圆 x²+y²−2y=0 的位置关系为（　）
A．相交　B．相切或相交　C．相离　D．相切
【题型名】直线与圆的位置关系（过定点直线）
【难度】0.85
【归属】富矿 件8-#5
【答案】A
【亲算】圆 x²+(y−1)²=1，圆心 (0,1)。直线 y=k(x−1)+1 过定点 (1,1)（x=1 时 y=1），恰为圆心，故 d=0<r，恒相交，选A。

### T6（单选）
【题面】与圆 x²+y²−4x+3=0 相切，且在 x、y 轴上截距相等的直线共有（　）
A．1条　B．2条　C．3条　D．4条
【题型名】圆的切线方程（截距相等·分类计数）
【难度】0.85
【归属】富矿 件8-#9
【答案】D
【亲算】圆 (x−2)²+y²=1，圆心 (2,0)，r=1。①过原点（两截距同为0）：y=kx，d = |2k|/√(1+k²) = 1 ⇒ k² = 1/3 ⇒ 2条；②不过原点：x/a+y/a=1 即 x+y=a，d = |2−a|/√2 = 1 ⇒ a = 2±√2（均非0）⇒ 2条。共4条，选D。

### T7（单选）
【题面】若过点 (2,1) 的圆与两坐标轴都相切，则圆心到直线 2x−y−3=0 的距离为（　）
A．√5/5　B．2√5/5　C．3√5/5　D．4√5/5
【题型名】圆的切线方程（切两轴定圆·教材p128习题2-3B①同族异求）
【难度】0.85
【归属】富矿 件8-#12
【答案】B
【亲算】圆与两轴都切且过 (2,1)（第一象限）⇒ 圆心 (a,a)，r=a，a>0。(2−a)²+(1−a)² = a² ⇒ a²−6a+5=0 ⇒ a=1 或 5。a=1：圆心 (1,1)，d = |2−1−3|/√5 = 2/√5 = 2√5/5；a=5：圆心 (5,5)，d = |10−5−3|/√5 = 2/√5，相同。故 d = 2√5/5，选B。

### T8（单选）
【题面】已知集合 A = {(x,y)|x²+y²=1}，集合 B = {(x,y)|y=|x|−1}，则集合 A∩B 的真子集的个数为（　）
A．3　B．4　C．7　D．8
【题型名】直线与圆的位置关系（集合语言·交点计数）
【难度】0.85
【归属】富矿 件8-#17
【答案】C
【亲算】x≥0：y=x−1，x²+(x−1)²=1 ⇒ 2x²−2x=0 ⇒ x=0（y=−1）或 x=1（y=0）；x<0：y=−x−1，x²+(x+1)²=1 ⇒ 2x²+2x=0 ⇒ x=−1（y=0）（x=0 不在此段）。交点 (0,−1), (1,0), (−1,0) 共3个，真子集 2³−1 = 7 个，选C。

### T9（单选）
【题面】过直线 y=2x−3 上的点作圆 C: x²+y²−4x+6y+12=0 的切线，则切线长的最小值为（　）
A．√55/5　B．√19　C．2√5　D．√21
【题型名】圆的切线方程（切线长最小值）
【难度】0.65
【归属】富矿 件9-#10
【答案】A
【亲算】圆 (x−2)²+(y+3)²=1，圆心 C(2,−3)，r=1。切线长 = √(|PC|²−r²)，最小 ⇔ |PC| 最小 = C 到直线距离 = |4+3−3|/√5 = 4/√5。最小切线长 = √(16/5−1) = √(11/5) = √55/5，选A。

### T10（单选）
【题面】已知直线 l: x+ay−1=0 是圆 C: x²+y²−6x−2y+1=0 的对称轴，过点 A(−1,a) 作圆 C 的一条切线，切点为 B，则 |AB|=（　）
A．1　B．2　C．4　D．8
【题型名】圆的切线方程（对称轴＋切线长；同族取一：件9-#12未取）
【难度】0.85
【归属】富矿 件9-#17
【答案】C
【亲算】圆 (x−3)²+(y−1)²=9，圆心 (3,1)，r=3。对称轴过圆心：3+a−1 = 0 ⇒ a=−2，A(−1,−2)。|AC| = √(16+9) = 5，切线长 |AB| = √(25−9) = 4，选C。

### T11（填空）
【题面】直线 xcosθ+ysinθ=r 和 x²+y²=r² 的位置关系是______．
【题型名】直线与圆的位置关系（含参恒判定）
【难度】0.94
【归属】富矿 件8-#3
【答案】相切
【亲算】圆心 (0,0)，半径 r。d = |−r|/√(cos²θ+sin²θ) = r，恒相切。

### T12（填空）
【题面】若圆 C: x²+y²−2mx+2√m·y+2=0 与 x 轴有公共点，则实数 m 的取值范围是______．
【题型名】直线与圆的位置关系（含参与坐标轴公共点）
【难度】0.65
【归属】富矿 件8-#7
【答案】[√2, +∞)
【亲算】表圆：√m 有意义 ⇒ m≥0，r² = m²+m−2 > 0 ⇒（m≥0 下）m>1。与 x 轴有公共点 ⇔ |√m| ≤ r ⇔ m ≤ m²+m−2 ⇔ m² ≥ 2 ⇒ m ≥ √2。故 m ∈ [√2, +∞)。

### T13（填空）
【题面】已知圆 C: (x−1)²+y²=1，点 A(−2,0) 及点 B(3,a)，从点 A 处观察点 B，要使视线不被圆 C 挡住，则实数 a 的取值范围为___________.
【题型名】直线与圆的位置关系（视线应用·相离条件）
【难度】0.85
【归属】富矿 件8-#8
【答案】(−∞, −5√2/4)∪(5√2/4, +∞)
【亲算】视线不被挡 ⇔ 直线 AB 与圆相离。k_AB = a/5，直线：ax−5y+2a=0。d = |3a|/√(a²+25) > 1 ⇒ 9a² > a²+25 ⇒ 8a² > 25 ⇒ |a| > 5/(2√2) = 5√2/4。

### T14（填空）
【题面】若斜率为 √3 的直线与 y 轴交于点 A，与圆 x²+(y−1)²=1 相切于点 B，则 |AB|=____________．
【题型名】圆的切线方程（切线长）
【难度】0.85
【归属】富矿 件9-#11
【答案】√3
【亲算】设直线 y=√3x+b，A(0,b)。相切：d = |b−1|/2 = 1 ⇒ b=3 或 −1，|AC| = 2（C(0,1)）。|AB| = √(|AC|²−r²) = √(4−1) = √3。

### T15（解答）
【题面】已知点 M(3,1)，直线 ax−y+4=0 及圆 C: (x−1)²+(y−2)²=4.
(1) 求过点 M 的圆 C 的切线方程；
(2) 若直线 ax−y+4=0 与圆 C 相切，求实数 a 的值；
(3) 若直线 ax−y+4=0 与圆 C 相交于 A、B 两点，且弦 AB 的长为 2√3，求 a 的值.
【题型名】圆的切线方程＋弦长综合（三问）
【难度】0.65
【归属】富矿 件10-#9
【答案】(1) x=3 或 3x−4y−5=0；(2) a=0 或 a=4/3；(3) a=−3/4
【亲算】C(1,2)，r=2；|MC| = √(4+1) = √5 > 2，M 在圆外。
(1) 斜率不存在时 x=3：d = |3−1| = 2 = r ✓ 是切线。斜率存在时设 y−1=k(x−3)，即 kx−y−3k+1=0：d = |k−2−3k+1|/√(k²+1) = |2k+1|/√(k²+1) = 2 ⇒ 4k²+4k+1 = 4k²+4 ⇒ k = 3/4，切线 3x−4y−5=0。
(2) d = |a−2+4|/√(a²+1) = |a+2|/√(a²+1) = 2 ⇒ a²+4a+4 = 4a²+4 ⇒ 3a²−4a = 0 ⇒ a=0 或 4/3。
(3) 弦长 2√3 ⇒ 半弦 √3 ⇒ d = √(4−3) = 1：|a+2|/√(a²+1) = 1 ⇒ a²+4a+4 = a²+1 ⇒ a = −3/4。

### T16（解答）
【题面】为了保证我国东海油气田海域的海上平台的生产安全，海事部门在某平台 O 的正东方向设立了两个观测站 A、B（点 A 在点 O、点 B 之间），它们到平台 O 的距离分别为 3 海里和 12 海里，记海平面上到两观测站距离 PA、PB 之比为 1/2 的点 P 的轨迹为曲线 E，规定曲线 E 及其内部区域为安全预警区．
(1) 以 O 为坐标原点，AB 所在直线为 x 轴建立平面直角坐标系，求曲线 E 的方程；
(2) 某日在观测站 B 处发现，在该海上平台正南 2√11 海里的 C 处，有一艘轮船正以每小时 10 海里的速度向北偏东 30° 方向航行，如果航向不变，该轮船是否会进入安全预警区？如果不进入，说明理由；如果进入，则它在安全预警区中的航行时间是几小时．
【题型名】阿波罗尼斯圆问题（实际应用·进入时间）
【难度】0.65
【归属】富矿 件11-#8（阿氏圆撞族4取一；源题面含示意图，印面题面已去「（如图）」引用与【图】占位，全部数学信息在文字中，无信息损失——台账同注）
【答案】(1) x²+y²=36；(2) 一定进入，航行时间 1 小时
【亲算】(1) O 为原点，A(3,0)，B(12,0)。|PA|/|PB| = 1/2 ⇒ 4[(x−3)²+y²] = (x−12)²+y² ⇒ 4x²−24x+36+4y² = x²−24x+144+y² ⇒ 3x²+3y² = 108 ⇒ x²+y² = 36。
(2) C(0,−2√11)。北偏东30° ⇒ 航线倾角60°，斜率 √3，航线：y+2√11 = √3x，即 √3x−y−2√11=0。d = |2√11|/√(3+1) = √11 < 6，相交，必进入。弦长 = 2√(36−11) = 10，t = 10/10 = 1（小时）。
