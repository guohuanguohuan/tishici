## 一 导学件 G5

### G1（单选）
【题面】设圆 C₁: x²+y²−2x+4y=4，圆 C₂: x²+y²+6x−8y=0，则圆 C₁，C₂ 的公切线有（　）
A．1条　B．2条　C．3条　D．4条
【题型名】圆与圆的位置关系（公切线条数）
【难度】0.65（中档）
【归属】成品C卷 2.3.4.5-7
【答案】B
【亲算】C₁: (x−1)²+(y+2)²=9，圆心 (1,−2)，r₁=3；C₂: (x+3)²+(y−4)²=25，圆心 (−3,4)，r₂=5。d = √(16+36) = 2√13 ≈ 7.2，5−3 < 2√13 < 5+3，相交，公切线2条，选B。

### G2（单选）
【题面】已知圆 C₁: x²+y²−2x+my+1=0 (m∈R) 的面积被直线 x+2y+1=0 平分，圆 C₂: (x+2)²+(y−3)²=25，则圆 C₁ 与圆 C₂ 的位置关系是（　）
A．外离　B．相交　C．内切　D．外切
【题型名】圆与圆的位置关系（对称性＋判定）
【难度】0.85
【归属】富矿 件12-#3
【答案】B
【亲算】面积被直线平分 ⇒ 直线过圆心：1−m+1 = 0 ⇒ m=2。C₁: (x−1)²+(y+1)²=1，圆心 (1,−1)，r₁=1；C₂ 圆心 (−2,3)，r₂=5。d = √(9+16) = 5，4 < 5 < 6，相交，选B。

### G3（单选）
【题面】圆心为 C(2,0) 的圆 C 与圆 x²+y²+4x−6y+4=0 相外切，则圆 C 的方程为（　）
A．x²+y²−4x=0　B．x²+y²−4x+2=0　C．x²+y²+4x+2=0　D．x²+y²+4x=0
【题型名】圆与圆的位置关系（外切逆求圆）
【难度】0.85
【归属】富矿 件12-#14
【答案】A
【亲算】(x+2)²+(y−3)²=9，圆心 (−2,3)，r=3。|AC| = √(16+9) = 5 = r+R ⇒ R=2。圆 C: (x−2)²+y²=4，即 x²+y²−4x=0，选A。

### G4（填空）
【题面】圆 C₁: x²+y²=1 与圆 C₂: x²+y²+2x+2y+1=0 的交点坐标为___________.
【题型名】圆与圆的位置关系（交点坐标）
【难度】0.85（简单）
【归属】成品C卷 2.3.4.4-6
【答案】(0,−1)、(−1,0)
【亲算】两式相减：2x+2y+1 = 1−... 即 x+y+1=0（公共弦）。代入 x²+y²=1：x²+(−x−1)² = 1 ⇒ 2x²+2x = 0 ⇒ x=0 或 −1，交点 (0,−1)、(−1,0)。

### G5（填空·判断三组）
【题面】判断下列各组中两个圆的位置关系：
(1) (x+3)²+(y−2)²=1 与 x²+(y+2)²=36；(2) (x−1)²+(y+2)²=4 与 (x+3)²+(y−1)²=9；(3) x²+y²+2x−4y=4 与 x²+y²−2x=0．
【题型名】圆与圆的位置关系（判定组）
【难度】0.65（中档）
【归属】成品C卷 2.3.4.2-1
【答案】(1) 内切；(2) 外切；(3) 相交
【亲算】(1) 圆心距 |C₁C₂| = √(9+16) = 5 = 6−1，内切。(2) d = √(16+9) = 5 = 2+3，外切。(3) 化一般式：x²+y²+2x−4y−4=0 与 x²+y²−2x=0，圆心 (−1,2)、(1,0)，d = √(4+4) = 2√2，半径 3 与 1，1 < 2√2 < 4，相交。

### T14（填空）
【题面】已知 ⊙C：x²+y²−2x−2y−2=0，直线 l：x+2y+2=0，M 为直线 l 上的动点，过点 M 作 ⊙C 的切线 MA，MB，切点为 A，B，当四边形 MACB 的面积取最小值时，直线 AB 的方程为 ____．
【题型名】圆的切线方程（切点弦·面积最小）
【难度】0.65
【归属】富矿 件12-#39（与件9-#15同族取一，件9-#15未取）

### T15（解答）
【题面】某同学发现了一个现象：在求圆的公共弦 AB（即两个圆相交时，两个交点的连线）所在直线的方程恰好与两个圆的方程相减消掉二次项 x²，y² 后所得的方程一样．由此，他提出了一个猜想：对于两个圆 C₁: x²+y²+D₁x+E₁y+F₁=0 与 C₂: x²+y²+D₂x+E₂y+F₂=0，直线 (D₁−D₂)x+(E₁−E₂)y+(F₁−F₂)=0 就是两个圆的公共弦所在直线的方程．你认为他的猜想对吗？请说明理由．
【题型名】两圆公共弦与根轴（猜想探究证明）
【难度】0.85
【归属】富矿 件12-#19
【答案】猜想正确，理由见解析
【亲算】设交点 A(x₁,y₁)、B(x₂,y₂)。则 xᵢ²+yᵢ²+D₁xᵢ+E₁yᵢ+F₁ = 0 且 xᵢ²+yᵢ²+D₂xᵢ+E₂yᵢ+F₂ = 0（i=1,2）。两式相减：(D₁−D₂)xᵢ+(E₁−E₂)yᵢ+(F₁−F₂) = 0，即 A、B 都在直线 (D₁−D₂)x+(E₁−E₂)y+(F₁−F₂)=0 上。又 D₁≠D₂ 或 E₁≠E₂（否则两圆方程相同），该直线的系数不全为零，而过两个不同交点的直线有且仅有一条，故它就是公共弦 AB 所在直线的方程，猜想正确。

### T16（解答）
【题面】求过点 A(1,−1) 且与圆 C: x²+y²=100 相切于点 B(8,6) 的圆的方程．
【题型名】圆与圆的位置关系（过切点定圆）
【难度】0.85
【归属】富矿 件12-#15
【答案】(x−4)²+(y−3)²=25
【亲算】设圆心 D(a,b)。切点 B 在两圆连心线上（连心线过切点且与公切线垂直）：k_CB = k_DB ⇒ b/a = 6/8 = 3/4，即 b = 3a/4。又 |DA| = |DB|：(a−1)²+(b+1)² = (a−8)²+(b−6)²，展开：a²−2a+1+b²+2b+1 = a²−16a+64+b²−12b+36 ⇒ 14a+14b = 98 ⇒ a+b = 7。联立 b = 3a/4：7a/4 = 7 ⇒ a=4，b=3。r = |DB| = √(16+9) = 5。故圆的方程 (x−4)²+(y−3)²=25。（验：|DA| = √(9+16) = 5 ✓；|DC| = 10 = 大圆半径，所求圆与大圆内切于 B ✓。）
