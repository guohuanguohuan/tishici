## 一 导学件 G5

### G1（单选）
【题面】圆心在 y 轴上，半径为1，且过点 (1,2) 的圆的方程是（　）
A．x²+(y−2)²=1　B．x²+(y+2)²=1　C．(x−1)²+(y−3)²=1　D．x²+(y−3)²=1
【题型名】圆的标准方程求法
【难度】0.85（简单）
【归属】成品C卷 2.3.1.2-1
【答案】A
【亲算】圆心 (0,b)：x²+(y−b)²=1。代入 (1,2)：1+(2−b)²=1 ⇒ b=2。圆的方程 x²+(y−2)²=1，选A。

### G2（单选）
【题面】已知圆的方程是 (x−2)²+(y−3)²=4，则点 P(3,2)（　）
A．在圆心；B．在圆上；C．在圆内；D．在圆外
【题型名】圆的标准方程求法（点与圆位置关系）
【难度】0.85（简单）
【归属】成品C卷 2.3.1.4-4
【答案】C
【亲算】(3−2)²+(2−3)² = 1+1 = 2 < 4 = r²，点在圆内，选C。

### G3（单选）
【题面】圆 x²+y²+2x−4y−6=0 的圆心和半径分别是（　）
A．(−1,−2)，11　B．(−1,2)，11　C．(−1,−2)，√11　D．(−1,2)，√11
【题型名】圆的一般方程与表圆条件（互化）
【难度】0.85（简单）
【归属】成品C卷 2.3.2.2-1
【答案】D
【亲算】配方：(x+1)²+(y−2)² = 6+1+4 = 11。圆心 (−1,2)，半径 √11，选D。

### G4（填空·两空）
【题面】已知圆 C: 2x²+2y²+4x−2y−1=0，则圆心的坐标为______，半径为______．
【题型名】圆的一般方程与表圆条件（互化）
【难度】0.94
【归属】富矿 件6-#19
【答案】(−1, 1/2)；√7/2
【亲算】两端除以2：x²+y²+2x−y−1/2=0，配方 (x+1)²+(y−1/2)² = 1/2+1+1/4 = 7/4。圆心 (−1, 1/2)，半径 √7/2。

### G5（填空）
【题面】已知圆 C: x²+y²+2x+ay−3=0 (a为实数) 上任意一点关于直线 l: x−y+2=0 的对称点都在圆 C 上，则 a=____．
【题型名】圆的标准方程求法（对称性）
【难度】0.65（中档）
【归属】成品C卷 2.3.1.5-5
【答案】−2
【亲算】圆上任意点关于 l 的对称点仍在圆上 ⇔ 圆关于 l 对称 ⇔ l 过圆心。圆心 (−1, −a/2) 代入 l：−1+a/2+2 = 0 ⇒ a = −2。（此时 r² = 1+a²/4+3 = 5 > 0 ✓ 表圆。）

## 二 练习件

### T1（单选）
【题面】若点 (5a+1, 12a) 在圆 (x−1)²+y²=1 的内部，则实数 a 的取值范围是（　）
A．−1<a<1　B．−1/3<a<1/3　C．−1/5<a<1/5　D．−1/13<a<1/13
【题型名】圆的标准方程求法（点在圆内求参）
【难度】0.94
【归属】富矿 件6-#15
【答案】D
【亲算】(5a+1−1)²+(12a)² = 25a²+144a² = 169a² < 1 ⇒ |a| < 1/13，选D。

### T2（单选）
【题面】若点 (4a−1, 3a+2) 不在圆 (x+1)²+(y−2)²=25 的外部，则 a 的取值范围是（　）
A．−√5/5<a<√5/5　B．−1<a<1　C．−√5/5≤a≤√5/5　D．−1≤a≤1
【题型名】圆的标准方程求法（点不在圆外求参）
【难度】0.94
【归属】富矿 件6-#16
【答案】D
【亲算】(4a−1+1)²+(3a+2−2)² = 16a²+9a² = 25a² ≤ 25 ⇒ a²≤1 ⇒ −1≤a≤1，选D。

### T3（单选）
【题面】若原点在圆 (x−3)²+(y+4)²=m 的外部，则实数 m 的取值范围是（　）
A．m>25　B．m>5　C．0<m<25　D．0<m<5
【题型名】圆的标准方程求法（点在圆外求参）
【难度】0.85
【归属】富矿 件6-#17
【答案】C
【亲算】表圆需 m>0。原点在圆外 ⇔ (0−3)²+(0+4)² = 25 > m。故 0<m<25，选C。

### T4（单选）
【题面】若曲线 C: x²+y²+2ax−4ay−10a=0 表示圆，则实数 a 的取值范围为（　）
A．(−2,0)　B．(−∞,−2)∪(0,+∞)　C．[−2,0]　D．(−∞,−2]∪[0,+∞)
【题型名】圆的一般方程与表圆条件
【难度】0.94
【归属】富矿 件6-#21
【答案】B
【亲算】x² 与 y² 系数均为1 ✓。D²+E²−4F = 4a²+16a²+40a = 20a(a+2) > 0 ⇒ a>0 或 a<−2，选B。

### T5（单选）
【题面】已知点 A(1,2) 在圆 C: x²+y²+mx−2y+2=0 外，则实数 m 的取值范围为（　）
A．(−3,−2)∪(2,+∞)　B．(−3,−2)∪(3,+∞)　C．(−2,+∞)　D．(−3,+∞)
【题型名】圆的一般方程与表圆条件（表圆＋点圆位置双条件）
【难度】0.65
【归属】富矿 件6-#22
【答案】A
【亲算】表圆：m²+(−2)²−4·2 > 0 ⇒ m²>4 ⇒ m>2 或 m<−2。点在圆外：1+4+m−4+2 = m+3 > 0 ⇒ m>−3。取交：(−3,−2)∪(2,+∞)，选A。

### T6（单选）
【题面】若圆 C: x²+y²−2(m−1)x+2(m−1)y+2m²−6m+4=0 过坐标原点，则实数 m 的值为（　）
A．2或1　B．−2或−1　C．2　D．−1
【题型名】圆的一般方程与表圆条件（过定点求参）
【难度】0.85
【归属】富矿 件6-#23
【答案】C
【亲算】过原点 ⇔ F = 2m²−6m+4 = 0 ⇒ m=1 或 2。表圆条件：D²+E²−4F = 4(m−1)²+4(m−1)²−4(2m²−6m+4) = 8(m²−2m+1)−8m²+24m−16 = 8m−8 > 0 ⇒ m>1。舍 m=1，得 m=2，选C。

### T7（多选）
【题面】圆 (x−2)²+y²=5，则（　）
A．关于点 (2,0) 对称　B．关于直线 y=0 对称
C．关于直线 x+3y−2=0 对称　D．关于直线 x−y+2=0 对称
【题型名】圆的标准方程求法（对称性·多选）
【难度】0.85
【归属】富矿 件7-#1
【答案】ABC
【亲算】圆心 (2,0)。圆关于圆心中心对称（A对）；圆心在 x 轴上 ⇒ 关于 y=0 对称（B对）；x+3y−2=0 过 (2,0)（2+0−2=0 ✓）⇒ 过圆心的直线是圆的对称轴（C对）；x−y+2=0：2−0+2=4≠0 不过圆心，D错。选ABC。

### T8（单选）
【题面】已知圆 C: x²+y²+2x−2my−4−4m=0 (m∈R)，则当圆 C 的面积最小时，圆上的点到坐标原点的距离的最大值为（　）
A．√5　B．6　C．√5−1　D．√5+1
【题型名】圆的一般方程与表圆条件（含参面积最小＋点圆最值）
【难度】0.94
【归属】富矿 件7-#8
【答案】D
【亲算】配方：(x+1)²+(y−m)² = m²+4m+5 = (m+2)²+1。r_min = 1 当 m=−2，此时圆心 (−1,−2)。|OC| = √5 > r，圆上点到 O 距离最大 = |OC|+r = √5+1，选D。

### T9（单选）
【题面】若圆 (x−3)²+(y+5)²=r² 上的点到直线 4x−3y−2=0 的最短距离为1，则圆的半径 r 为（　）
A．4　B．5　C．6　D．9
【题型名】圆的标准方程求法（圆上点到直线最值）
【难度】0.85
【归属】富矿 件7-#10
【答案】A
【亲算】圆心 (3,−5)。d = |12+15−2|/5 = 25/5 = 5。圆上点到直线最短距离 = d−r（d>r 时）= 1 ⇒ r = 4，选A。

### T10（多选）
【题面】若直线 l 将圆 x²+y²−2x+4y−4=0 平分，且在两坐标轴上的截距相等，则直线 l 的方程为（　）
A．x−y+1=0　B．x−2y=0　C．x+y+1=0　D．2x+y=0
【题型名】圆的标准方程求法（对称性＋截距条件）
【难度】0.65（中档）
【归属】成品C卷 2.3.1.7-7
【答案】CD
【亲算】圆心 (1,−2)。l 平分圆 ⇔ l 过圆心。截距相等分两类：①截距均为0：l 过原点，k = −2/1 = −2，l: 2x+y=0（D对）；②截距 a≠0：x/a+y/a=1，代入 (1,−2)：(1−2)/a = 1 ⇒ a=−1，l: x+y+1=0（C对）。检验：A 过 (1,−2)? 1+2+1=4≠0；B 过 (1,−2)? 1+4=5≠0，均不过圆心。选CD。

### T11（填空）
【题面】圆心在直线 2x−y−7=0 上的圆 C 与 y 轴交于 A(0,−4)，B(0,−2) 两点，则圆 C 的一般方程为___________.
【题型名】圆的一般方程与表圆条件（待定系数）
【难度】0.65
【归属】富矿 件6-#26
【答案】x²+y²−4x+6y+8=0
【亲算】圆心在 AB 中垂线 y=−3 上，又在 2x−y−7=0 上：2x+3−7=0 ⇒ x=2，圆心 (2,−3)。r² = 4+(−3+4)² = 5。标准方程 (x−2)²+(y+3)²=5，展开：x²+y²−4x+6y+8=0。
（验：A(0,−4)：16−24+8=0 ✓；B(0,−2)：4−12+8=0 ✓。）

### T12（填空·开放）
【题面】圆心在 x 轴上且过点 (1,3) 的一个圆的标准方程可以是______．（写出一个即可）
【题型名】圆的标准方程求法（开放性作答）
【难度】0.94
【归属】富矿 件13-#21
【答案】(x−1)²+y²=9（答案不唯一）
【亲算】圆心 (a,0)，r² = (1−a)²+9。取 a=1：r=3，得 (x−1)²+y²=9。（一般形式 (x−a)²+y²=(1−a)²+9，a∈R 均合。）

### T13（填空·三空）
【题面】已知点 P(m,n) 在圆 C: (x−2)²+(y−2)²=9 上运动，则 (m+2)²+(n+1)² 的最大值为______，最小值为_______，√(m²+n²) 的范围为________．
【题型名】圆的标准方程求法（代数式几何化·圆上点最值）
【难度】0.65（中档）
【归属】成品C卷 2.3.1.6.1-8
【答案】64；4；[3−2√2, 3+2√2]
【亲算】(m+2)²+(n+1)² = |P−(−2,−1)|²。圆心 C(2,2)，r=3；|C−(−2,−1)| = √(16+9) = 5。距离范围 [5−3, 5+3] = [2,8]，平方范围 [4,64]，最大64、最小4。
√(m²+n²) = |PO|，|OC| = 2√2 < 3，故范围 [3−2√2, 3+2√2]。

### T14（填空）
【题面】已知 a∈R，方程 a²x²+(a+2)y²+4x+8y+5a=0 表示圆，则圆心坐标是_____，半径是______．
【题型名】圆的一般方程与表圆条件（表圆条件＋检验）
【难度】0.65（中档）
【归属】成品C卷 2.3.2.2-2
【答案】(−2,−4)；5

### T15（解答）
【题面】已知曲线 C: (1+a)x²+(1+a)y²−4x+8ay=0．
(1) 当 a 取何值时，方程表示圆？(2) 求证：不论 a 为何值，曲线 C 必过两定点．(3) 当曲线 C 表示圆时，求圆面积最小时 a 的值．
【题型名】圆的一般方程与表圆条件（含参曲线·定点·最值）
【难度】0.65（中档）
【归属】成品C卷 2.3.2.3.1-4（与富矿件7-#23同题；成品版为准，件7-#23未另取）
【答案】(1) a≠−1；(2) 恒过 (0,0) 与 (16/5, −8/5)；(3) a=1/4
【亲算】(1) a≠−1 时 x²、y² 系数同为 1+a≠0，两边除以 (1+a) 化一般式，D²+E²−4F = (16+64a²)/(1+a)² > 0 恒成立，表圆；a=−1 时二次项消失，方程退化为直线 −4x−8y=0，不合。故 a≠−1。
(2) 方程按 a 整理：(x²+y²−4x)+a(x²+y²+8y)=0。两定点须对一切 a 成立 ⇔ x²+y²−4x=0 且 x²+y²+8y=0。相减：4x+8y=0，x=−2y。代入 x²+y²−4x=0：5y²=0 得 (0,0)；代入 x²+y²+8y=0：5y²+8y=0 ⇒ y=0（已得）或 y=−8/5，x=16/5。定点 (0,0) 与 (16/5, −8/5)。（验 (16/5,−8/5)：x²+y² = 256/25+64/25 = 320/25；4x = 64/5 = 320/25 ✓；8y = −64/5 ✓ 两式皆零。）
(3) 表圆时 r² = [4+16a²]/(1+a)²。令 f(a) = (4+16a²)/(1+a)²（a≠−1），f′(a) = [32a(1+a)−2(4+16a²)]/(1+a)³ = (32a−8)/(1+a)³，驻点 a=1/4。符号按分支定号：①a>1/4：分子 32a−8>0、分母 (1+a)³>0，f′>0；②−1<a<1/4：分子<0、分母>0，f′<0；③a<−1：分子<0，但分母 (1+a)³<0，f′>0——该支 f 单调递增且 a→−1⁻ 时 f→+∞、f 恒大于16>16/5，不产生最小值。故 f 仅在 a=1/4 处取得最小值（16/5）。（几何：定点弦 (0,0)—(16/5,−8/5) 为公共弦，圆族中过两定点的圆以该弦为直径时半径最小，与上互证。）故 a=1/4。

### T16（解答）
【题面】已知圆 C: x²+y²+Dx+Ey+3=0，圆心在直线 x+y−1=0 上，且圆心在第二象限，半径长为 √2，求圆的一般方程．
【题型名】圆的一般方程与表圆条件（待定系数＋象限筛选）
【难度】0.65
【归属】富矿 件6-#27
【答案】x²+y²+2x−4y+3=0
【亲算】圆心 (−D/2, −E/2) 在 x+y−1=0 上：−D/2−E/2−1 = 0 ⇒ D+E = −2。r² = (D²+E²−4F)/4 = (D²+E²−12)/4 = 2 ⇒ D²+E² = 20。由 E = −2−D：D²+(D+2)² = 20 ⇒ 2D²+4D−16=0 ⇒ D²+2D−8=0 ⇒ D=2 或 −4。D=2 ⇒ E=−4，圆心 (−1,2) 第二象限 ✓；D=−4 ⇒ E=2，圆心 (2,−1) 第四象限，舍。故 D=2，E=−4，圆的一般方程 x²+y²+2x−4y+3=0。（验 r² = (4+16−12)/4 = 2 ✓）
