## 二、组合对照与判别特征句

| 组合 | 题型库状态 | 判别特征句 |
|---|---|---|
| G1 双曲线基本量直读 | 库内「双曲线渐近线与共渐近线系」邻近条目可覆盖基本量项，不立新名 | 题干给标准方程（或先化标准形），要求写出实轴/虚轴/顶点/焦点/渐近线中的若干项 |
| G2 渐近线方程与距离 | 库内「双曲线渐近线与共渐近线系」 | 由方程读 a、b 写渐近线，或求焦点到渐近线的距离 |
| G3 渐近线与离心率互求 | 库内「双曲线离心率」 | 给渐近线求 e，或给 e/离心率条件反求渐近线（b/a↔e²=1+(b/a)²） |
| G4 依条件（实轴+渐近线）求方程 | 库内「双曲线渐近线与共渐近线系」 | 给实轴（或顶点）与渐近线等独立条件，待定系数求标准方程 |
| G5 共渐近线系方程 | 库内「双曲线渐近线与共渐近线系」 | 渐近线相同（或含 λ 系），设 x²/a²−y²/b²=λ（或齐比式）代点/条件定 λ |
| G6 焦点到构造线距离求渐近线 | 库内「双曲线离心率」扩展槽，不立新名 | 给焦点到「顶点—虚轴端点连线」型构造直线的距离，齐次化解 b/a |
| G7 第三定义斜率积求e | 库内「双曲线离心率」扩展槽（第三定义结论小题可用、大题不可引） | 中心对称两点+曲线上动点连线斜率积/和最值 → k₁k₂=e²−1 |
| G8 焦半径最值 | 库内「圆锥曲线面积/最值与范围」 | 求双曲线上点到焦点（定点）距离最值，消元后按 x 范围取端点（同支 min=c−a） |
| G9 焦点到渐近线距离恒等式 | 库内「双曲线渐近线与共渐近线系」，证明题槽位 | 「求证：焦点到渐近线距离=半虚轴长」型恒等证明 |
| G10 定点定值压轴（双曲线） | 库内「定值与定点」 | 韦达+恒等式分解证直线/曲线系过定点，压轴两问结构 |

【14-09｜课时14·G5 共渐近线系方程｜3章件10-32（0.85，新增）｜简】
已知双曲线 x²/a²−y²/b²=1（a>0，b>0）的渐近线为 y=±(√3/3)x，原点到过点 P(0,b) 及 Q(a,0) 的直线 l 的距离为 √3/2，求双曲线的方程。
【答案】x²/3−y²=1
【详解】由渐近线 y=±(√3/3)x 得 b/a=√3/3，即 a=√3b。

联立 a=√3b 与 4a²b²=3(a²+b²)：4·3b⁴=3(3b²+b²) → 12b⁴=12b² → b²=1（b>0），a²=3。
故双曲线方程为 x²/3−y²=1。
验算：a=√3、b=1 时 ab/√(a²+b²)=√3/2 ✓，渐近线 y=±x/√3 ✓。

【14-11｜课时14·G6 焦点到构造线距离求渐近线｜卷③§2.6.2.4-4（中档）｜中】

【14-12｜课时14·G7 第三定义斜率积求e｜卷③§2.6.2.9-10（中档）｜中】
已知双曲线 x²/a²−y²/b²=1（a>0，b>0），M，N 是双曲线上关于原点对称的两点，P 是双曲线上的动点，直线 PM，PN 的斜率分别为 k₁，k₂（k₁k₂≠0），若 |k₁|+|k₂| 的最小值为2，则双曲线的离心率为（　　）

【答案】A
【详解】设 M(x₀,y₀)，则 N(−x₀,−y₀)，P(x,y)（x≠±x₀）。
k₁k₂=[(y−y₀)/(x−x₀)]·[(y+y₀)/(x+x₀)]=(y²−y₀²)/(x²−x₀²)。

故 k₁k₂=b²/a²（定值，坐标点差法）。
于是 |k₁|+|k₂|≥2√|k₁k₂|=2√(b²/a²)=2b/a（b/a>0，当 |k₁|=|k₂|=b/a 时取等，且 P 可取到），
由最小值2得 2b/a=2 → b/a=1 → e=√(1+(b/a)²)=√2，故选A。
（卷③答案照录、详解按坐标点差法书写校订——不引第三定义名目，结论同 e²−1=b²/a²；验算 b=a 时 e=√2 ✓。）

【14-G1｜导学｜新命（离心率定参求渐近线·14-命A·0914命制入槽）｜简】
已知双曲线 C: x²/9−y²/m=1（m>0）的离心率为 √13/3，则 C 的渐近线方程为（　　）
A．y=±(2/3)x　　B．y=±(3/2)x　　C．y=±√3x　　D．y=±(√13/3)x
【答案】A
【详解】e²=1+b²/a²=1+m/9=13/9，得 m/9=4/9，m=4。故 C: x²/9−y²/4=1，a=3、b=2，渐近线 y=±(b/a)x=±(2/3)x，选 A。
【亲算落账】回代：e=√(1+4/9)=√(13/9)=√13/3 ✓。干扰项成因：B 系 b/a 倒置；C 系误套「e=2↔b/a=√3」熟对（即 m=9）；D 系把离心率误当渐近线斜率。

【14-G2｜导学｜新命（按渐近线与焦点位置选标准方程·14-命B·0914命制入槽）｜简】
渐近线方程为 y=±(√2/2)x，且焦点在 x 轴上的双曲线的标准方程可以是（　　）
A．x²/4−y²/2=1　　B．y²/2−x²/4=1　　C．x²/2−y²/4=1　　D．y²/4−x²/16=1
【答案】A
【详解】逐项核两条件：A：a²=4、b²=2，渐近线 y=±(b/a)x=±(√2/2)x，c²=4+2=6，焦点 (±√6,0) 在 x 轴，两条件皆合；B：渐近线 y=±(a/b)x=±(√2/2)x 与 A 相同，但实轴在 y 轴上，焦点 (0,±√6)，不合「焦点在 x 轴」；C：渐近线 y=±(b/a)x=±√2x，不合；D：渐近线 y=±(a/b)x=±(1/2)x 且焦点 (0,±2√5) 在 y 轴，两条件皆不合。故选 A。
【亲算落账】B 与 A 渐近线相同而焦轴相反（实、虚半轴互换），系「渐近线同、焦点位置异」陷阱项；标准方程不唯一（凡 b/a=√2/2 的 x 轴型双曲线皆合题设），单选之下 A 为唯一合条件的选项。

【14-G3｜导学｜新命（离心率范围定 b/a 范围·14-命C·0914命制入槽）｜中】
已知双曲线 C: x²/a²−y²/b²=1（a>0，b>0）的离心率 e∈[√3,2]，则 b/a 的取值范围为（　　）
A．[√2,√3]　　B．[1,√3]　　C．[√3,2]　　D．[2,3]
【答案】A
【详解】由 e²=1+(b/a)² 得 (b/a)²=e²−1。e∈[√3,2] ⟹ e²∈[3,4] ⟹ (b/a)²∈[2,3]；又 b/a>0，故 b/a∈[√2,√3]，选 A。
【亲算落账】e²=1+(b/a)² 关于 b/a（>0）单调递增，两端点可取：e=√3 时 b/a=√2；e=2 时 b/a=√3 ✓。干扰项成因：C 系照抄 e 的范围；D 系漏开平方（把 (b/a)² 的范围当作 b/a）；B 系下界误取 1（漏「e≥√3」之平方）。

【14-G4｜导学｜新命（虚轴长＋渐近线定标准方程·14-命D·0914命制入槽）｜简】
已知双曲线的焦点在 x 轴上，虚轴长为 4，渐近线方程为 y=±(1/2)x，则该双曲线的标准方程为___________。
【答案】x²/16−y²/4=1
【详解】虚轴长 2b=4，得 b=2；焦点在 x 轴时渐近线为 y=±(b/a)x，由 b/a=1/2 得 a=2b=4。故标准方程为 x²/16−y²/4=1。
【亲算落账】回验：a²=16、b²=4 ⟹ 渐近线 y=±(2/4)x=±(1/2)x ✓，虚轴 2b=4 ✓，c²=20，焦点 (±2√5,0) 在 x 轴 ✓。「焦点在 x 轴」这一条件不可省：否则按 y 轴型读渐近线 y=±(a/b)x 将得另一解 y²−x²/4=1，答案不唯一。

【14-G5｜导学｜新命（渐近线相同定参并求离心率·14-命E·0914命制入槽）｜中】
已知双曲线 C₁: x²/2−y²/m=1（m>0）与双曲线 C₂: x²−y²/7=1 的渐近线相同，则 m=___________，C₁ 的离心率为___________。
【答案】m=14；e=2√2
【详解】C₂（a²=1、b²=7）的渐近线为 y=±√7x。C₁（a²=2、b²=m，焦点同在 x 轴）的渐近线为 y=±(√m/√2)x。渐近线相同 ⟺ √m/√2=√7，得 √m=√14，m=14。此时 e²=1+b²/a²=1+14/2=8，故 e=2√2。
【亲算落账】回代 m=14：C₁ 渐近线 y=±(√14/√2)x=±√7x ✓；e=√8=2√2 ✓。焦点均在 x 轴，渐近线相同即 b/a 相等，无共轭方向歧义。
