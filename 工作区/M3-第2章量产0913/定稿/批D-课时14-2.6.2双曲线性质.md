## 二、组合对照与判别特征句

| 组合 | 题型库状态 | 判别特征句 |
|---|---|---|
| G1 双曲线基本量直读 | 库内「双曲线渐近线与共渐近线系」邻近条目可覆盖基本量项，不立新名 | 题干给标准方程（或先化标准形），要求写出实轴/虚轴/顶点/焦点/渐近线中的若干项 |
| G2 渐近线方程与距离 | 库内「双曲线渐近线与共渐近线系」 | 由方程读 a、b 写渐近线，或求焦点到渐近线的距离 |
| G3 渐近线与离心率互求 | 库内「双曲线离心率」 | 给渐近线求 e，或给 e/离心率条件反求渐近线（b/a↔e²=1+(b/a)²） |
| G4 依条件（实轴+渐近线）求方程 | 库内「双曲线渐近线与共渐近线系」 | 给实轴（或顶点）与渐近线等独立条件，待定系数求标准方程 |
| G5 共渐近线系方程 | 库内「双曲线渐近线与共渐近线系」 | 渐近线相同（或含 λ 系），设 x²/a²−y²/b²=λ（或齐比式）代点/条件定 λ |
| G6 焦点到构造线距离求渐近线 | 库内「双曲线离心率」扩展槽，不立新名 | 给焦点到「顶点—虚轴端点连线」型构造直线的距离，齐次化解 b/a |
| G7 第三定义斜率积求e | 库内「双曲线离心率」扩展槽（第三定义结论小题可用、大题不可引） | 中心对称两点+曲线上动点连线斜率积/和最值 → k₁k₂=e²−1 |
| G8 焦半径最值 | 库内「圆锥曲线面积/最值与范围」 | 求双曲线上点到焦点（定点）距离最值，消元后按 x 范围取端点（同支 min=c−a） |
| G9 焦点到渐近线距离恒等式 | 库内「双曲线渐近线与共渐近线系」，证明题槽位 | 「求证：焦点到渐近线距离=半虚轴长」型恒等证明 |
| G10 定点定值压轴（双曲线） | 库内「定值与定点」 | 韦达+恒等式分解证直线/曲线系过定点，压轴两问结构 |
