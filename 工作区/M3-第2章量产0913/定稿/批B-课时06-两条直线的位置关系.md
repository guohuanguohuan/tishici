## 一 导学件 G5

### G1（单选）
【题面】若直线 l₁ 的倾斜角为135°，直线 l₂ 经过点 P(−2,−1)，Q(3,−6)，则直线 l₁ 与 l₂ 的位置关系是（　）
A．垂直　B．平行　C．重合　D．平行或重合
【题型名】两直线位置关系的判定（斜率法）
【难度】0.85（中档）
【归属】成品C卷 2.2.3.2-1
【答案】D
【亲算】k₁ = tan135° = −1；k₂ = (−6−(−1))/(3−(−2)) = −5/5 = −1。两斜率相等，但仅凭斜率相等不能排除重合（题面未给两点异于 l₁ 的信息），故 l₁ 与 l₂ 平行或重合，选D。

### G2（单选）
【题面】直线 l₁: ax+2y−1=0 与 l₂: x+(a−1)y+a²=0 平行，则 a=（　）
A．−1　B．2　C．−1或2　D．0或1
【题型名】两直线位置关系的判定（平行求参）
【难度】0.85（中档）
【归属】成品C卷 2.2.3.2-2
【答案】B
【亲算】平行 ⇔ a(a−1)−2·1=0，即 a²−a−2=0，a=2 或 a=−1。检验：a=−1 时两直线分别为 −x+2y−1=0 与 x−2y+1=0，系数成比例，重合，舍；a=2 时两直线 2x+2y−1=0 与 x+y+4=0 平行不重合。故 a=2，选B。

### G3（单选）
【题面】若直线 y=2x+10，y=x+1，y=ax−2 交于一点，则 a 的值为（　）
A．1/2　B．−1/2　C．2/3　D．−2/3
【题型名】两直线位置关系的判定（三线共点）
【难度】0.94（简单）
【归属】成品C卷 2.2.3.8-10
【答案】C
【亲算】联立 y=2x+10 与 y=x+1：x=−9，y=−8，交点 (−9,−8)。代入 y=ax−2：−8=−9a−2，得 a=2/3，选C。

### G4（填空）
【题面】若直线 x=1−2y 与 2x+4y+m=0 重合，则 m=______。
【题型名】两直线位置关系的判定（重合求参）
【难度】0.94（简单）
【归属】富矿 件4-#6
【答案】−2
【亲算】x=1−2y 即 x+2y−1=0；2x+4y+m=0 即 x+2y+m/2=0。重合 ⇔ 两方程完全相同，故 m/2=−1，m=−2。

### G5（填空）
【题面】已知直线 l₁: 2x+y+2=0 与 l₂: 4x+by+c=0 关于点 P(1,0) 对称，则 b+c=______。
【题型名】点（线）关于直线的对称（直线关于点对称）
【难度】0.85（中档）
【归属】富矿 件4-#19
【答案】−10
【亲算】在 l₁ 上取 M(−1,0)（−2+0+2=0 ✓）与 N(0,−2)（0−2+2=0 ✓）。M、N 关于 P(1,0) 的对称点分别为 M₁(3,0)、N₁(2,2)。代入 l₂：12+c=0 得 c=−12；8+2b+c=0 得 b=2。故 b+c=−10。（验：l₂: 2x+y−6=0 与 l₁ 平行，且 l₁ 上点 (−1,0) 关于 P 的对称点 (3,0) 在 l₂ 上，成立。）

## 二 练习件

### T1（单选）
【题面】直线 l₁: 2ax+y−2=0 与直线 l₂: x−(a+1)y+2=0 互相垂直，则这两条直线的交点坐标为（　）
A．(−2/5, −6/5)　B．(2/5, 6/5)　C．(2/5, −6/5)　D．(−2/5, 6/5)
【题型名】两直线位置关系的判定（垂直求交点）
【难度】0.85
【归属】富矿 件5-#1
【答案】B
【亲算】A₁A₂+B₁B₂ = 2a·1 + 1·(−(a+1)) = a−1 = 0，得 a=1（a=−1 时 l₂:x+2=0 铅直而 l₁ 斜率2，不垂直，已排除）。此时 l₁: 2x+y−2=0，l₂: x−2y+2=0。由 y=2−2x 代入：x−2(2−2x)+2=0，5x=2，x=2/5，y=6/5。交点 (2/5, 6/5)，选B。

### T2（单选）
【题面】满足下列条件的直线 l₁ 与 l₂，其中 l₁∥l₂ 的是（　）
①l₁ 的斜率为2，l₂ 过点 A(1,2)、B(4,8)；
②l₁ 经过点 P(3,3)、Q(−5,3)，l₂ 平行于 x 轴，但不经过 P 点；
③l₁ 经过点 M(−1,0)、N(−5,−2)，l₂ 经过点 R(−4,3)、S(0,5)．
A．①②　B．②③　C．①③　D．①②③
【题型名】两直线位置关系的判定（斜率判平行）
【难度】0.85
【归属】富矿 件2-#29
【答案】B
【亲算】①k_AB = (8−2)/(4−1) = 2 = k₁，但只知斜率相等，l₁ 与 l₂ 可能重合，①不入选。②k_PQ = 0，l₁ 为水平线；l₂ 平行于 x 轴且不过 P，两水平线不重合，平行，②入选。③k₁ = (−2−0)/(−5+1) = 1/2，k₂ = (5−3)/(0+4) = 1/2；检验 M(−1,0) 不在 l₂（l₂: y=x/2+5，x=−1 时 y=9/2）上，故平行，③入选。选B。

### T3（单选）
【题面】已知四边形 MNPQ 的顶点 M(1,1)，N(3,−1)，P(4,0)，Q(2,2)，则四边形 MNPQ 的形状为（　）
A．平行四边形　B．菱形　C．梯形　D．矩形
【题型名】两直线位置关系的判定（四边形形状）
【难度】0.85
【归属】富矿 件2-#38
【答案】D
【亲算】k_MN = −1 = k_PQ ⇒ MN∥PQ；k_MQ = 1 = k_NP ⇒ MQ∥NP，故为平行四边形。又 k_MN·k_MQ = −1 ⇒ MN⊥MQ，故为矩形。（|MN|=√8≠|MQ|=√2，非菱形。）选D。

### T4（单选）
【题面】在平面直角坐标系内有两个点 A(4,2)，B(1,−2)，若在 x 轴上存在点 C，使 ∠ACB=π/2，则点 C 的坐标是（　）
A．(3,0)　B．(0,0)　C．(5,0)　D．(0,0)或(5,0)
【题型名】两直线位置关系的判定（垂直构造方程）
【难度】0.85
【归属】富矿 件2-#40
【答案】D
【亲算】设 C(x₀,0)。k_AC = 2/(4−x₀)，k_BC = −2/(1−x₀) = 2/(x₀−1)（x₀≠1,4，恰舍去与 A、B 重合情形）。∠ACB=90° ⇔ [2/(4−x₀)]·[2/(x₀−1)] = −1 ⇔ (4−x₀)(x₀−1) = −4 ⇔ x₀²−5x₀ = 0 ⇔ x₀=0 或 5。C(0,0) 或 (5,0)，选D。

A．(−19,−62)　B．(19,−62)　C．(−19,62)　D．(19,62)

### T6（单选）
【题面】若直线 kx+(1−k)y−3=0 和直线 (k−1)x+(2k+3)y−2=0 互相垂直，则 k=（　）
A．−3或−1　B．3或1　C．−3或1　D．−1或3
【题型名】两直线位置关系的判定（垂直求参）
【难度】0.85
【归属】富矿 件4-#11

### T7（单选）
【题面】已知 a≠0，直线 ax+(b+2)y+4=0 与直线 ax+(b−2)y−3=0 互相垂直，则 ab 的最大值为（　）
A．0　B．2　C．4　D．√2
【题型名】两直线位置关系的判定（垂直＋基本不等式）
【难度】0.65
【归属】富矿 件4-#16
【答案】B
【亲算】垂直 ⇔ a·a+(b+2)(b−2) = 0，即 a²+b² = 4。由 a²+b² ≥ 2|ab| 得 |ab| ≤ 2；取 a=b=√2（满足 a²+b²=4，两直线 −√2x−(2+√2)y... 系数检验：直线分别为 √2x+(2+√2)y+4=0 与 √2x+(√2−2)y−3=0，A₁A₂+B₁B₂ = 2+(2+√2)(√2−2) = 2+(2−4) = 0 ✓ 垂直）时 ab=2。故 ab 的最大值为2，选B。

### T8（多选）
【题面】已知直线 l₁: x+ay−a=0 和直线 l₂: ax−(2a−3)y−1=0，下列说法正确的是（　）
A．l₂ 始终过定点 (2/3, 1/3)
B．若 l₁∥l₂，则 a=1 或 −3
C．若 l₁⊥l₂，则 a=0 或 2
D．当 a>0 时，l₁ 始终不过第三象限
【题型名】两直线位置关系的判定（含参直线综合）
【难度】0.85
【归属】富矿 件4-#17
【答案】ACD
【亲算】A：l₂ 按 a 整理：a(x−2y)+(3y−1)=0，令 x−2y=0 且 3y−1=0 得 (2/3, 1/3)，恒过，A对。
B：a=1 时 l₁: x+y−1=0，l₂: x+y−1=0，重合非平行；a=−3 时 k₁ = −1/3，l₂: −3x+9y−1=0 的斜率为 1/3，不平行，B错。

### T10（多选）
【题面】瑞士数学家欧拉1765年提出：任意三角形的外心、重心、垂心在同一条直线上，后人称这条直线为欧拉线。若已知 △ABC 的顶点 A(−4,0)，B(0,4)，其欧拉线方程为 x−y+2=0，则下列正确的是（　）
A．△ABC 重心的坐标为 (−1/3, 2/3) 或 (−2/3, 1/3)
B．△ABC 垂心的坐标为 (0,2) 或 (−2,0)
C．△ABC 顶点 C 的坐标为 (2,0) 或 (0,−2)
D．欧拉线将 △ABC 分成的两部分的面积之比为 4/5
【题型名】两直线位置关系的判定（欧拉线综合）
【难度】0.65（中档）
【归属】成品C卷 2.2.3.4-5
【答案】BCD
【亲算】AB 中点 (−2,2)，k_AB = 1，中垂线 y−2 = −(x+2)，即 x+y=0。与欧拉线联立：x=−1，y=1，外心 O′(−1,1)，R² = 9+1 = 10。
设 C(m,n)：重心 ((m−4)/3, (n+4)/3) 在欧拉线上 ⇒ m−n−2=0；|O′C|²=10 ⇒ (m+1)²+(n−1)²=10，即 m²+n²+2m−2n=8。代入 n=m−2：2m²−4m=0 ⇒ m=0 或 2，C(2,0) 或 (0,−2)，C对。
重心为 (−2/3, 4/3) 或 (−4/3, 2/3)，A给的数值错，A错。
垂心：由欧拉关系 H = 3G−2O′（G 为重心）：C(2,0) 时 H = 3(−2/3,4/3)−2(−1,1) = (−2,4)−(−2,2) = (0,2)；C(0,−2) 时 H = 3(−4/3,2/3)−2(−1,1) = (−4,2)−(−2,2) = (−2,0)。（直接验证 C(2,0) 情形：AC 水平 ⇒ 过 B 的高为 x=0；过 C 垂直 AB 的高 y=−x+2；交点 (0,2) ✓。）B对。
面积比：AB: x−y+4=0 与欧拉线平行。C(2,0) 到欧拉线距离 4/√2，到 AB 距离 6/√2，相似比 2/3，小三角形与大三角形面积比 4/9，故两部分之比 4:5，即 4/5，D对。选BCD。

### T13（填空·两空）
【题面】已知点 P(−2,0) 和直线 l: (1+3λ)x+(1+2λ)y−(2+5λ)=0 (λ∈R)，该直线 l 过定点__________，点 P 到直线 l 的距离 d 的最大值为____________．
【题型名】直线方程形式与互化（含参直线系过定点＋距离最值）
【难度】0.65
【归属】富矿 件5-#36
【答案】(1,1)；√10
【亲算】按 λ 整理：(x+y−2)+λ(3x+2y−5)=0，令两式同零：x+y−2=0 且 3x+2y−5=0，解得 x=y=1，定点 Q(1,1)。λ 变化时 l 绕 Q 转动（斜率可取除 −3/2 外的一切值，且 λ=−1/2 时为铅直线 x=1，故方向覆盖齐全）。d 最大 ⟺ l⊥PQ，max d = |PQ| = √((−2−1)²+(0−1)²) = √10。

### T14（填空·两问）
【题面】已知直线 l₁ 经过点 A(3,m)，B(m−1,2)，直线 l₂ 经过点 C(1,2)，D(−2,m+2)．
(1) 若 l₁∥l₂，求实数 m 的值；(2) 若 l₁⊥l₂，求实数 m 的值．
【题型名】两直线位置关系的判定（平行垂直求参两问）
【难度】0.65
【归属】富矿 件2-#46（白名单注：与件2-#32同族取一，#32未取）
【答案】(1) m=1 或 6；(2) m=3 或 −4
【亲算】k₂ = (m+2−2)/(−2−1) = −m/3；k₁ = (2−m)/(m−1−3) = (2−m)/(m−4)。
(1) k₁=k₂：(2−m)/(m−4) = −m/3 ⇒ 3(2−m) = −m(m−4) ⇒ m²−7m+6=0 ⇒ m=1 或 6。检验不重合：m=1 时 l₁ 过 (3,1),(0,2) 斜率 −1/3，l₂ 过 (1,2),(−2,3)，C 不在 l₁ 上 ✓；m=6 时 l₁: y=−2x+12，C(1,2) 不在其上 ✓。故 m=1 或 6。
(2) m=0 时 k₂=0（水平），需 l₁ 铅直，但 A(3,0)、B(−1,2) 横坐标不同，斜率存在，舍；k₂≠0 时 k₁·k₂=−1：(2−m)/(m−4)·(−m/3) = −1 ⇒ m(2−m) = −3(m−4) ⇒ m²−m−12=0 ⇒ m=3 或 −4。m=3：k₁=1,k₂=−1 ✓；m=−4：k₁=−3/4,k₂=4/3，积 −1 ✓。故 m=3 或 −4。

### T15（解答）
【题面】已知在▱ABCD 中，A(1,2)，B(5,0)，C(3,4)．
(1) 求点 D 的坐标；(2) 试判定▱ABCD 是否为菱形？
【题型名】两直线位置关系的判定（平行四边形与菱形）
【难度】0.65（中档）
【归属】成品C卷 2.2.3.3-3
【答案】(1) D(−1,6)；(2) 是菱形
