### 强基Q23（x轴动点＋定比取点·轨迹与面积最大值）

**亲算**：
- **(1)** PE⃗=½EQ⃗ ⟹ E−P=½(Q−E) ⟹ 3E=2P+Q ⟹ P=(3E−Q)/2。设 E=(x,y)、Q=(t,0)。|PO|=3/2 ⟺ |3E−Q|²=9：**(3x−t)²+9y²=9 …(ii)**；|PQ|=3/2 ⟺ |E−Q|²=1：**(x−t)²+y²=1 …(i)**。(ii)−9×(i)：12xt−8t²=0 → t=0 或 t=3x/2。t=0（Q 与 O 重合）：(i) → **x²+y²=1**；t=3x/2：(i) → (x/2)²·… (x−3x/2)²+y²=1 → **x²/4+y²=1**。存在性核对：P 存在 ⟺ 两定圆 (O,3/2)、(Q,3/2) 相交 ⟺ |t|≤3；椭圆支 |t|=3|x|/2≤3 自动满足，圆支 t=0 平凡。故 **Γ: x²+y²=1 ∪ x²/4+y²=1**。
- **(2)** 由 NA⃗=2AM⃗：x₀=2m−2x₀（m 为 M 横标）→ M(3x₀/2,0)；y₀−n=−2y₀ → N(0,3y₀)。故 l: y=−(2y₀/x₀)x+3y₀，斜率 k=−2y₀/x₀；过 O 的平行线与 Γ 同支交于关于 O 对称的 B、D。
  - **A 在椭圆支**（x₀=2cosθ、y₀=sinθ）：k=−tanθ，平行线方向 (cosθ,−sinθ)。弦长：r²(cos²θ/4+sin²θ)=1 → |BD|=4/√(cos²θ+4sin²θ)；距离：d=|2cosθ·(−sinθ)−sinθ·cosθ|=3|sinθcosθ|。S=½|BD|·d=6|sinθcosθ|/√(cos²θ+4sin²θ)，即 S²=36u(1−u)/(1+3u)（u=sin²θ∈(0,1)）。g(u)=u(1−u)/(1+3u)，g′(u)=(1−2u−3u²)/(1+3u)²=0 → u=1/3 → S²max=36·(1/3)(2/3)/2=**4** → **S_max=2**（取 sin²θ=1/3 直接验证：|BD|=2√2、d=√2、S=2 ✓）。
  - **A 在圆支**（x₀=cosθ、y₀=sinθ）：k=−2tanθ；|BD|=2（直径）；d=|sin(θ−α)|（tanα=−2tanθ）。sin²(θ−α)=9v/(4v²+5v+1)（v=tan²θ），在 v=1/2 处取最大 1 → **S_max=1**（几何解释：平行线过 O，A 到它的距离 ≤|OA|=1）。
  - 综合两支：**△ABD 面积的最大值=2**。
- **复核修正**：初稿在本问最大化一步有滑步（曾记 max≈1.954／0.977、sin²θ=(√10−1)/9），写账复核时按上式重推，确认椭圆支 max=2、圆支 max=1，以本账为准。
- **题面张力**：Γ 为双成分（圆∪椭圆），过 O 的平行线一般交 Γ 于四点，「交于 B、D 两点」须按「B、D 与 A 同支」口径读；立为正式题源前须在题面限定（见⑥注记3）。（判定：无源可比。）

### 新1（纯粹性辨析·四选一）难度 0.65（自定）

下列各组方程中，表示同一条曲线的是（　）
A．y=|x| 与 y=√(x²)　　B．y=x 与 y=√(x²)　　C．|y|=x 与 y=√(x²)　　D．x²+y²=0 与 y=0

**亲算**：A：√(x²)=|x|，两方程解集（图象）相同，同一条曲线 ✓。B：y=x 为直线，y=√(x²)=|x| 为折线（x<0 时 y=−x），异。C：|y|=x ⟺ x≥0 且 y=±x，为两条射线；而 y=|x| 还含 x<0 的部分，异。D：x²+y²=0 ⟺ 点 (0,0)，y=0 为整条 x 轴，异。**答案：A**。

### 新2（由方程研究曲线）难度 0.65（自定）

已知曲线 C：x²+y²−2|x|=0。(1) 指出 C 的形状；(2) 写出 C 的对称性、范围、与坐标轴的交点，并求 C 围成的区域的面积。

**亲算**：(1) 按 |x| 分段：x≥0 时 (x−1)²+y²=1，x<0 时 (x+1)²+y²=1 → C 为两个外切于原点的单位圆（「8」字形）。
(2) 对称性：|x| 使 C 关于 y 轴对称；两圆连心线在 x 轴上 → 关于 x 轴对称；由两者 → 关于原点对称。范围：x∈[−2,2]，y∈[−1,1]。与 y 轴交点：x=0 ⟹ y²=0，仅 (0,0)；与 x 轴交点：y=0 ⟹ |x|=2 或 0，即 (±2,0) 与 (0,0)。面积：两圆仅切于一点、无重叠，S=2·π·1²=**2π**。

### 新3（轨迹方程＋纯粹性完备性检验）难度 0.65（自定）

已知 A(−2,0)、B(2,0)，动点 P 满足 k_PA·k_PB=−1/4，求 P 的轨迹方程，并验证轨迹的纯粹性与完备性。

**亲算**：设 P(x,y)。斜率存在要求 x≠±2；y²/(x²−4)=−1/4 ⟹ 4y²=4−x²，即 **x²/4+y²=1（x≠±2）**。此时 y²=(4−x²)/4>0，y≠0 自动满足（y=0 时积为 0≠−1/4，自然排除）。
- 纯粹性：轨迹上任一点满足斜率方程（推导步步可逆）→ 都满足题设 ✓。
- 完备性：满足题设的点都满足 x²/4+y²=1 且 x≠±2 → 都在轨迹上 ✓。
- 轨迹为椭圆 x²/4+y²=1 除去长轴两端点 (±2,0)。

### 新4（存在性·仿C组）难度 0.65（自定）

已知圆 C₁：x²+(y−m)²=9 与圆 C₂：x²+(y+2)²=1 有公共点，求实数 m 的取值范围。

**亲算**：圆心 C₁(0,m)、C₂(0,−2)，半径 3 与 1，圆心距 |m+2|。有公共点 ⟺ |r₁−r₂|≤|C₁C₂|≤r₁+r₂，即 2≤|m+2|≤4 → 2≤m+2≤4 或 −4≤m+2≤−2 → **m∈[−6,−4]∪[0,2]**。

### 新5（含参方程分类）难度 0.65（自定）

就实数 k 的取值，讨论方程 x²+2y²−2x−8y+k=0 表示的曲线形状。

**亲算**：配方 (x−1)²+2(y−2)²=9−k。
- k=9：方程表示**单点 (1,2)**（退化椭圆）；
- k<9：表示**椭圆** (x−1)²/(9−k)+(y−2)²/((9−k)/2)=1；
- k>9：无实解，**不表示任何曲线**（无轨迹）。
