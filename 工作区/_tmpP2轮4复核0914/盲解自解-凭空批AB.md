## 批A（R4K-01~09）

**R4K-01**：比例定义式 φ=E_p/q 两路同值核：φ_M＝(−1.6×10⁻⁸)/(2×10⁻⁹)＝−8V；(−4.0×10⁻⁸)/(5×10⁻⁹)＝−8V ✓ 一致。
(1) φ_M＝**−8 V**；(2) E_p₃＝q₃φ_M＝(−1×10⁻⁹)×(−8)＝**＋8×10⁻⁹ J**（两空）。

**R4K-02**：W＝ΔE_k＝**＋2.4×10⁻¹⁸ J**→静电力做**正**功；ΔE_p＝−W＝−2.4×10⁻¹⁸ J→电势能**减少**；
负电荷 E_p＝qφ：E_pN＜E_pM ⇒ φ_N＞φ_M → 电势较高为 **N** 点；
E_pN＝E_pM＋ΔE_p＝(−3.0×10⁻¹⁸)＋(−2.4×10⁻¹⁸)＝**−5.4×10⁻¹⁸ J**。（五空：正／2.4×10⁻¹⁸／减少／N／−5.4×10⁻¹⁸）

**R4K-03（解答·按给分点）**：
(1) kQ＝φ_A·r_A＝90×0.1＝9 V·m；φ_B＝kQ/r_B＝9/0.3＝**30 V**。
(2) E_pA＝qφ_A＝2×10⁻⁸×90＝**1.8×10⁻⁶ J**；E_pB＝qφ_B＝2×10⁻⁸×30＝**6×10⁻⁷ J**。
(3) W_AB＝E_pA−E_pB＝1.8×10⁻⁶−6×10⁻⁷＝**1.2×10⁻⁶ J**（正功）。路径无关理由：静电场为保守场，W＝qU_AB 只由初末位置（电势差）决定，与路径无关。

**R4K-04（解答·按给分点）**：
(1) φ_A＝E_pA/q＝1.5×10⁻⁵/(3×10⁻⁸)＝**500 V**；φ_B＝6×10⁻⁶/(3×10⁻⁸)＝**200 V**。
(2) W_AB＝E_pA−E_pB＝1.5×10⁻⁵−6×10⁻⁶＝**9×10⁻⁶ J**（正功）。
(3) 改 B 为零点：φ_B′＝0，φ_A′＝φ_A−φ_B＝U_AB＝**300 V**；W_AB′＝q(φ_A′−φ_B′)＝3×10⁻⁸×300＝9×10⁻⁶ J＝W_AB → **不变**（W 由电势差决定，与零点选取无关）。

**R4K-05（多选）**：C＝Q/U 两数据同值：2×10⁻⁵/4＝6×10⁻⁵/12＝**5×10⁻⁶ F** → A✓；
U-Q 图线（U 纵 Q 横）斜率＝ΔU/ΔQ＝1/C＝电容倒数 → B✗；
C 不随带电状态变：15V 时 Q＝CU＝5×10⁻⁶×15＝7.5×10⁻⁵ C → C✓；
完全放电后 Q＝0、U＝0 而 C 不变（构造决定）→ D✗。→ **AC**

**R4K-06（单选）**：C＝ε_rS/(4πkd)∝S/d；C_甲/C_乙＝(2S/2d)/(S/d)＝**1:1** → **A**。

**R4K-07**：Q＝CU＝1×10⁻³×300＝**0.3 C**；E＝½CU²＝½×1×10⁻³×300²＝**45 J**。（两空）

**R4K-08（解答·按给分点）**：
(1) Q₁＝C₁U₁＝2×10⁻⁶×6＝**1.2×10⁻⁵ C**；Q₂＝3×10⁻⁶×4＝**1.2×10⁻⁵ C**（恰好相等）。
(2) E₁＝½C₁U₁²＝½×2×10⁻⁶×36＝**3.6×10⁻⁵ J**；E₂＝½×3×10⁻⁶×16＝**2.4×10⁻⁵ J**；E₁＞E₂。
(3) 半放电：C 不变⇒U′＝U₁/2＝3V；E′＝½C₁U′²＝½×2×10⁻⁶×9＝**9×10⁻⁶ J**（交叉核：＝¼E₁＝3.6×10⁻⁵/4 ✓）。

**R4K-09（解答·按给分点）**：
(1) C＝Q₀/U₀＝2×10⁻³/10＝**2×10⁻⁴ F**。
(2) 三角形面积：E＝½Q₀U₀＝½×2×10⁻³×10＝**1×10⁻² J**。
(3) 另法验证：½CU²＝½×2×10⁻⁴×10²＝1×10⁻² J ✓（或 Q₀²/2C＝(2×10⁻³)²/(2×2×10⁻⁴)＝1×10⁻² J ✓）。

## 批B（R4L-01~09）

**R4L-01（单选）**：U＝Ed 只适用匀强场、d 取沿场强方向距离 → B✓；A「任何静电场」✗；C 非匀强场 U 大可能因 d 大，E 未必大 ✗；D 非匀强不能精确 ✗ → **B**。

**R4L-02（单选）**：场强方向＝电势降落**最快**方向 → C✓；A 等势面方向不降 ✗；B「降低的方向一定是」✗（仅最快方向才是）；D E＝0 处电势未必为零（等量同号电荷中点 E＝0 而 φ≠0）✗ → **C**。

**R4L-03（多选）**：W＝ΔE_k＝**−2.5×10⁻⁷ J** → A✓；ΔE_p＝−W＝＋2.5×10⁻⁷ J⇒E_pA 比 E_pB 小 2.5×10⁻⁷ J → B✓；
ΔE_p＝q(φ_B−φ_A)⇒φ_B−φ_A＝2.5×10⁻⁷/(−5×10⁻¹⁰)＝−500 V⇒U_AB＝**500 V** → C✓；
场线疏密无从判定 → D✗ → **ABC**。

**R4L-04**：U_PQ＝Ed＝2.5×10⁴×0.040＝**1000 V**；W_PQ＝qU_PQ＝2×10⁻⁸×1000＝**＋2×10⁻⁵ J**（正电荷顺场强方向 P→Q，正功）。（两空）

**R4L-05**：E＝ΔU/Δx＝20/0.05＝**400 V/m**；φ(10cm)＝50−2×20＝**10 V**；
电子 E_p＝qφ＝(−1.6×10⁻¹⁹)×10＝**−1.6×10⁻¹⁸ J**。（三空）

**R4L-06**：E₁₂＝ΔU₁₂/d＝(25−15)/0.020＝**500 V/m**；E₂₃＝(15−1)/0.020＝**700 V/m**；
**不是**匀强电场；依据：**等间距电势差应相等而实不等（10V≠14V，平均场强不同）**。（四空）

**R4L-07**：φ_M＝E_p/q＝2×10⁻⁷/(5×10⁻⁹)＝**40 V**；克服静电力做功 3×10⁻⁷ J⇒W_MN＝−3×10⁻⁷ J⇒U_MN＝W_MN/q＝−3×10⁻⁷/(5×10⁻⁹)＝**−60 V**。（两空）

**R4L-08（解答·按给分点）**：
(1) E＝U_AB/d＝60/0.30＝**200 V/m**。
(2) 电子 B→A：W_BA＝qU_BA＝(−e)×(−60V)＝**＋60 eV＝60×1.6×10⁻¹⁹＝9.6×10⁻¹⁸ J**。
(3) φ_A＝φ_B＋U_AB＝−20＋60＝**40 V**；E_pA＝qφ_A＝(−e)×40V＝**−40 eV＝−6.4×10⁻¹⁸ J**。

**R4L-09（解答·按给分点）**：
(1) U_MN＝φ_M−φ_N＝20−(−10)＝**30 V**。
(2) W＝qU_MN＝(−3×10⁻⁹)×30＝**−9×10⁻⁸ J**（负功）。
