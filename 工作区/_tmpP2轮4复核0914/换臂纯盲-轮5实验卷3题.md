## 题一 电容器充放电

### 自解

(1) 不会立即消失。电流减小为 0 只说明充电结束、不再有电荷继续迁上极板；此时两极板分别带有等量异号电荷，极板之间是绝缘介质，正、负电荷相互吸引而又没有导电通路可供中和，电荷被束缚在极板上，电场能仍储存在电容器内部。只有把 S 改接 2、构成放电回路后，两板电荷才会经回路中和而减少。

(2) 充电过程中通过电流表的电荷量就是最终积累在极板上的电荷量（电流归零后电荷量不再变化），故
Q = 1.2×10⁻⁴ C。
由电容定义式 C = Q/U：
C = 1.2×10⁻⁴ C ÷ 6.0 V = 2.0×10⁻⁵ F，即 20 μF。

(3) 充电时电流方向为：电源正极 → 电流表 A → 电容器正极板。放电时电容器相当于电源，电流从正极板出发，经 S、R 流回负极板。所以放电时通过 R 的电流方向与充电时通过电流表的电流方向相反。
放电结束时，两板电荷完全中和：电流表读数为 0，电压表读数为 0。
能量转化：电容器储存的电场能，通过放电电流做功，全部转化为电阻 R（及导线、表内阻）的内能（焦耳热）。

### 复算链

- C = 1.2×10⁻⁴ ÷ 6.0 = 0.2×10⁻⁴ = 2.0×10⁻⁵ F；2.0×10⁻⁵ F × 10⁶ μF/F = 20 μF ✓
- 量纲核：C/V = F ✓；串联支路电荷守恒，Q 与"通过电流表的电荷量"同值 ✓
- 方向逻辑：充电电流经 A 流入正极板，放电时电流自正极板流出经 R 返回，两者方向相反 ✓

（题一完）

## 题二 静电计·影响平行板电容器电容的因素

### 自解

(1) 静电计测量的是电容器两极板间的电势差 U，指针偏角越大表示 U 越大。判断依据：电容器充电后已与电源断开，极板电荷量 Q 保持不变；由定义式 C = Q/U 变形得 U = Q/C，Q 一定时 U 与 C 成反比——U 增大即 C 减小，U 减小即 C 增大。

(2) 平行板电容器 C = εrS/(4πkd)。逐操作分析：
操作一：d₀ 不变，正对面积由 S₀ 减为 S₀/2。C 与 S 成正比，C 减为原来的一半；Q 不变，U = Q/C 增大为 2 倍，偏角增大，与题给现象一致。判断依据 C ∝ S，故 C 减小。
操作二：S₀ 不变，间距由 d₀ 增为 2d₀。C 与 d 成反比，C 减为原来的一半；Q 不变，U 增大为 2 倍，偏角增大。判断依据 C ∝ 1/d，故 C 减小。
操作三：S₀、d₀ 不变，插入有机玻璃板（εr > 1）。C 与 εr 成正比，C 增大；Q 不变，U 由 12 V 减为 4.0 V，偏角减小。判断依据 C ∝ εr，故 C 增大。

(3) Q 不变时 C₁U₁ = C₂U₂，所以
C₁:C₂ = U₂:U₁ = 4.0:12 = 1:3（即插入有机玻璃后电容增为原来的 3 倍）。
增大电容的办法：增大正对面积 S；减小极板间距 d；在极板间插入介电常数更大（εr > 1）的电介质。
三操作共同的研究方法：控制变量法（每次只改变一个因素，其余因素保持不变）。

### 复算链

- 4.0 ÷ 12 = 1/3，故 C₁:C₂ = 1:3 ✓；等效 εr = 3，对有机玻璃数量级合理 ✓
- 操作一：S→S₀/2 ⇒ C→C/2 ⇒ U→2U（偏角增大，与题面相符）✓
- 操作二：d→2d₀ ⇒ C→C/2 ⇒ U→2U ✓
- 操作三：U₁→U₂ = U₁/3 ⇒ C→3C（εr 增大方向正确）✓

（题二完）

## 题三 电容放电 I-t 图象

### 自解

(1) 依据 q = It，I-t 图线下的"电流×时间"即电荷量。故最左端竖立狭长矩形（高 I₀、宽 Δt）的面积表示最初 Δt 时间段内放电释放的电荷量；整条图线与两轴所围的面积表示整个放电过程释放的总电荷量 Q。

(2) 每小格面积 = 0.5 mA × 0.1 s = 0.05 mA·s = 5×10⁻⁵ C。
按"大于半格算一格、小于半格舍去"数得约 32 小格，则
Q ≈ 32 × 5×10⁻⁵ C = 1.6×10⁻³ C。

(3) 充电完毕时极板间电势差 U ≈ 电源电压 8.0 V。由 C = Q/U：
C = 1.6×10⁻³ C ÷ 8.0 V = 2.0×10⁻⁴ F，即 200 μF。
关系：放电进行到底（I 衰减至 0），由电荷守恒，全部放电释放的电荷量等于充电完毕电容器所带的电荷量——即图线与两轴围成的面积就等于电容器初带电荷量 Q = CU。

### 复算链（含 RC 自洽核验）

- 格面积：0.5×10⁻³ A × 0.1 s = 5×10⁻⁵ C/格；32 格：32 × 5×10⁻⁵ = 160×10⁻⁵ = 1.6×10⁻³ C ✓
- C = 1.6×10⁻³ ÷ 8.0 = 0.2×10⁻³ = 2.0×10⁻⁴ F = 200 μF ✓（电解电容器数量级合理）
- RC 自洽①（初值）：放电初始 I₀ = U/R ⇒ R = 8.0 V ÷ 8.0×10⁻³ A = 1.0×10³ Ω
- RC 自洽②（时间常数）：τ = RC = 1.0×10³ Ω × 2.0×10⁻⁴ F = 0.2 s
- RC 自洽③（衰减吻合）：I(t) = I₀e^(−t/τ)；t = 0.8 s = 4τ 时 I = 8.0×e⁻⁴ ≈ 8.0×0.018 ≈ 0.15 mA，不足半格（0.25 mA），图象上判为"接近 0"，与题给"约经 0.8 s 衰减至接近 0"吻合 ✓
- RC 自洽④（面积闭合）：指数衰减曲线下面积 Q = I₀τ = 8.0×10⁻³ A × 0.2 s = 1.6×10⁻³ C，与格数估算 32 格 = 1.6×10⁻³ C 完全一致 ✓
- 自洽结论：图象读数、格数估算、电容值、时间常数四者互相闭合，无矛盾。

（题三完·全链复算通过）
