**题面**：C: x²/9−y²/m=1（m>0），e=√13/3，求渐近线（A ±(2/3)x　B ±(3/2)x　C ±√3x　D ±(√13/3)x）。

### 2.2 样本2＝14-G2（渐近线＋焦轴选方程·命B）——判定：**一致**

**题面**：渐近线 y=±(√2/2)x 且焦点在 x 轴（A x²/4−y²/2=1　B y²/2−x²/4=1　C x²/2−y²/4=1　D y²/4−x²/16=1）。

**对勘**：定稿 A ✓；逐项核两条件（B 与 A 渐近线同、焦轴反）与盲解同构。

### 2.3 样本3＝14-G3（离心率范围定 b/a 范围·命C）——判定：**一致**

### 2.4 样本4＝14-G4（虚轴长＋渐近线定方程·命D）——判定：**一致**

### 2.5 样本5＝14-G5（渐近线相同定参并求离心率·命E）——判定：**一致**

**盲解**：C₂ 渐近线 y=±√7x；C₁（x 轴型）渐近线 y=±√(m/2)x ⟹ m=14；e²=1+14/2=8 ⟹ e=2√2。（歧义排查：两曲线焦点均在 x 轴，「渐近线相同」即 b/a 相等，无共轭互置歧义。）

### 2.6 样本6＝17-G2（3章件12-#12，双曲焦半径弦）——判定：**一致**
