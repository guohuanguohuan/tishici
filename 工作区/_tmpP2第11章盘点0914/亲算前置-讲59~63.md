## 一 讲59 亲算（10/10）

### 59-1 神经细胞跨膜电流
- 题面摘要｜膜视为 C=1×10⁻⁸F 电容器，2ms 内两侧电势差由 −70mV 变为 +30mV，求平均跨膜电流。
- 自解｜ΔU＝30−(−70)＝100mV＝0.100V；ΔQ＝C·ΔU＝1×10⁻⁸×0.100＝1×10⁻⁹C；I＝ΔQ/Δt＝1×10⁻⁹/(2×10⁻³)＝5×10⁻⁷A。
- 读数｜I＝5×10⁻⁷A → 选 D。
- 坑点｜ΔU 取变化量（跨零共 100mV），不是末值 30mV、也不是 70mV。

### 59-5 橡胶棒匀速运动的等效电流
- 题面摘要｜均匀带负电橡胶棒每米带电 q，沿轴向以 v 匀速运动，求等效电流。
- 自解｜t 秒内棒前进 vt，过某固定截面的电荷量 ΔQ＝q·(vt)；I＝ΔQ/t＝qv，与横截面积 S 无关。
- 读数｜I＝qv → 选 A。
- 坑点｜「每米电荷量」已是线密度，勿再乘 S（D 陷阱）；负电荷运动的等效电流方向与运动反向（选项只问大小）。
- 注｜同族链：教材B1←落选Q5←本块（△同槽取一，轮1§3.1-2/§四-③）。

### 59-6 电解池双向离子电流
- 题面摘要｜t 秒内 n₁ 个一价正离子、n₂ 个一价负离子反向通过截面 S，判断电流。
- 自解｜正离子沿 A→B 移动，其电流方向 A→B；负离子沿 B→A 移动，负电荷反向运动的等效电流方向仍为 A→B。两股贡献同向相加：I＝(n₁+n₂)e/t，方向恒为 A→B，与 n₁、n₂ 相对大小无关。
- 读数｜I＝(n₁+n₂)e/t、方向 A→B → 选 D。
- 坑点｜两类离子对电流的贡献永远同向相加——A「n₁=n₂ 时电流为零」与 B、C 的相减式全错。

### 59-7 导线微观表达式正误
- 题面摘要｜均匀导线（S、n、e）四个说法判断。
- 自解｜A：t 内过截面电荷量 Q＝neSv·t，非 et，错。B：I=neSv → v＝I/(neS)，对。C：均匀拉长到 2 倍，体积不变 → L×2、S÷2 → R＝ρL/S 变 4 倍，错。D：金属温度升高电阻增大，错。
- 读数｜选 B。
- 坑点｜「拉长到 2 倍」体积守恒联动 S 减半，电阻变 4 倍不是 2 倍。

### 59-8 串联两导体（Sa:Sb=1:2）
- 题面摘要｜a、b 同料等长，Sa:Sb=1:2，流经 a 的电流 0.16A，判断四项。
- 自解｜由 B 项数值反推接法为串联（Ib=Ia=0.16A）。R=ρL/S → Ra:Rb=Sb:Sa=2:1，A 错（说 1:2）。B：5s 过 b 截面电荷量 Q=0.16×5=0.8C，N=Q/e=0.8/(1.6×10⁻¹⁹)=5×10¹⁸，对。C：v=I/(neS)，同 I 同 n → va:vb=Sb:Sa=2:1，错（说 1:2）。D：串联 Q=I²Rt → Qa:Qb=2:1，错（说 4:1）。
- 读数｜选 B。
- 坑点｜电阻比是 S 的反比 2:1；电子数按串联同流 0.16A 计（若按并联 0.32A 会算成 1×10¹⁹ 落空）。

### 59-9 电阻定律×微观式求电子速率
- 题面摘要｜金属棒（L、r、ρ、n、e）加电压 U，求自由电子定向运动平均速率。
- 自解｜R＝ρL/(πr²)；I＝U/R＝Uπr²/(ρL)；v＝I/(neS)＝Uπr²/(ρL·ne·πr²)＝U/(ρLne)。
- 读数｜v＝U/(ρLne) → 选 A。
- 坑点｜πr² 在两步中相消——选 B（分子残留 πr²）是漏除一步的典型错。

### 59-10 电子绕核等效环形电流
- 题面摘要｜电子（e、速率 v、半径 r）顺时针匀速圆周运动，求等效电流大小与方向。
- 自解｜T＝2πr/v；I＝e/T＝ev/(2πr)。电子带负电，等效电流方向与运动方向相反 → 逆时针。
- 读数｜I＝ev/(2πr)、逆时针 → 选 C。
- 坑点｜方向按「负电荷运动的反方向」定；B、D 的 ev/r 漏了周期中的 2π。

### 59-11 稳态电子的平均阻力
- 题面摘要｜圆柱棒（L、r、ρ、n、m、e）加恒压后电子匀速定向运动，求所受平均阻力。
- 自解｜稳态匀速 → 电场力与阻力平衡：f＝eE。E＝U/L；又 I＝U/R＝Uπr²/(ρL) 且 I=neπr²v → U＝neρvL → E＝U/L＝neρv → f＝eE＝ne²ρv。
- 读数｜f＝ne²ρv → 选 C。
- 坑点｜平衡式中阻力与 S、L 均无关（宏观量消尽）——D 项 ρe²v/(πr²L) 是把 S、L 塞回分母的陷阱。量纲核验：C²Ω/(m·s)＝N ✓。

### 59-12 质子流单位体积质子数
- 题面摘要｜质子（初速零）经电压 U 加速成细柱形质子流（S、I），求单位体积质子数 n。
- 自解｜动能定理 ½mv²＝eU → v＝√(2eU/m)；I＝neSv → n＝I/(eSv)＝(I/eS)·√(m/(2eU))。
- 读数｜n＝(I/eS)√(m/(2eU)) → 选 D。
- 坑点｜n 与 v 成反比——根号内 m 在分子、2eU 在分母，A 项把根式倒置是最常见错。

### 59-13 洛伦兹力与安培力的关系
- 题面摘要｜导线中带电粒子（n、q、v、S）在磁场 B 中，判断四说法。
- 自解｜A：t 内过截面电荷量 Q＝nSvt·q → I＝nqvS，由已知可算，对。B：安培力方向用左手定则判断（安培定则判的是电流的磁场），错。C：F洛=qvB 对，但 F安=BIL=B·(nqvS)·L＝nSLqvB，选项 nqvB 缺 SL 因子，错。D：依题干恒等式「洛伦兹力矢量和＝安培力」，无论改 v、换电荷号或反 B，个体洛伦兹力与整体安培力必同变同向，不可能只反其一，错。
- 读数｜选 A。
- 坑点｜F安=BIL 代入 I=nqvS 后多出导线长度因子 L——nqvB 是单位体积粒子受力，不是导线受的安培力。

### 60-1 盐水柱拉伸 1.2 倍
- 题面摘要｜食盐水柱（体积不变）水平均匀拉伸至原长 1.2 倍后接恒定电源（E、r 恒定），判断四项。
- 自解｜体积不变：L×1.2、S÷1.2 → R=ρL/S 变 1.44 倍（C✗）。I=E/(R+r) 随 R 增而减（A✗）。盐水柱两端电压＝路端量 U_R=ER/(R+r)，R 增则 U_R 增（B✓）。P=I²R=E²R/(R+r)²：R 增 P 确增，但增幅＝1.44(R+r)²/(1.44R+r)²≠1.44（r>0 时恒小于 1.44）（D✗）。
- 读数｜选 B。
- 坑点｜「拉长」体积守恒联动 S 缩——阻值是 1.44 倍不是 1.2 倍；若 r=0 则 B 也不成立（U 恒为 E），题给「内阻恒定」暗含 r>0。

### 60-2 I-U 图像 α=45°
- 题面摘要｜电阻 R 的 I-U 图像为过原点直线、倾角 α=45°，判断四项。
- 自解｜过原点直线 → I∝U，线性元件（A✓）。R=U/I 须按两轴物理标尺度量：tanα 仅当纵横标尺 1A:1V 等权时才等于 1/R，通行图况纵轴为 mA 标度，几何角与物理斜率不等权 → R=1/tanα=1.0Ω 不成立（C✗）。B 0.5Ω 陷阱：纵轴 mA 未换算成 A（读图 R 为数百欧量级，✗）。D：6V 时每秒电荷量 Q=U/R，按图读 R 代入≠3.0C（✗）。
- 读数｜选 A。备核通式：R=U₀/I₀（线上任一标点，mA→A 换算）；每秒电量 Q=U/R。
- 坑点｜几何角 α≠物理斜率——两轴标尺不等权时 1/tanα 无物理意义，C 是本块主设的陷阱。
- 注｜图依赖块，实图启用前按备核通式取线上标点秒核 R。

### 60-3 三种元件伏安特性曲线
- 题面摘要｜甲乙丙三条伏安特性曲线，判断导电性能随电压/温度、正反向对称性与反向击穿的说法。
- 自解｜通行读图：甲＝过原点直线（阻值恒定）→「导电性能随电压增大而增强」不成立（A✗）。乙＝曲线仅示 I 随 U 关系，横轴是电压非温度，「随温度升高而减弱」无从由图读出（B✗）。丙＝二极管完整特性：正向导通、反向截止、约 −40V 处反向击穿段 →「正反向导电性能一样」（C✗）；「反向电压大于 40V 时反向电流急剧变大」与击穿段吻合（D✓）。
- 读数｜选 D。
- 坑点｜B 的偷换：伏安曲线自变量是电压，把结论偷成「随温度」即错。

### 60-4 正方形薄片方块电阻
- 题面摘要｜同料同厚、表面正方形的导体 R₁（尺寸大）、R₂，加相同电压，判断电流与自由电荷速率。
- 自解｜沿正方形对边通电：R=ρL/(L·d)=ρ/d，边长 L 消去（方块电阻只由材料与厚度决定）→ R₁=R₂。同压 → I₁=I₂（B✓A✗）。v=I/(neS⊥)，S⊥=边长×厚：R₁ 大 → S⊥₁>S⊥₂ → v₁<v₂（C✓D✗）。
- 读数｜选 BC（多选）。
- 坑点｜「大电阻大电流」直觉陷阱：方块电阻与边长无关只看厚度；大板截面大，电子速率反而小。

### 60-5 两长方体两种通电方向电阻率比
- 题面摘要｜甲乙尺寸同（a×b×c，a>b>c）、材料异，按图沿不同方向接入同一电源、回路电流相同，求电阻率比。
- 自解｜电流相同 → 阻值相同。R甲=ρ甲·a/(bc)（甲沿长 a 通电，S=bc）；R乙=ρ乙·c/(ab)（乙沿高 c 通电，S=ab）。令相等：ρ甲 a/(bc)=ρ乙 c/(ab) → ρ甲/ρ乙=(c·bc)/(a·ab)=c²/a²。
- 读数｜ρ甲:ρ乙=c²:a² → 选 A。
- 坑点｜两块通电方向不同，各自的 L 与 S 要各取各的——按同一方向列式只能得错误比值（a²/c² 不在选项，自证图况为甲沿 a、乙沿 c）。

### 60-6 φ-x 图求电阻率比

### 60-8 传感器说法正误

### 60-12 φ-x 折线求横截面积比
- 题面摘要｜同料均匀导体柱 a（长 l）、b（长 2l）串联，φ-x 图像如图乙（x=3l 处电势取零），求 Sₐ:S_b。
- 自解｜串联同流 → R∝ΔU：Ra/Rb=ΔUa/ΔUb。又 R=ρL/S → (l/Sₐ)/(2l/S_b)=S_b/(2Sₐ) → Sₐ/S_b=ΔUb/(2ΔUa)。通行读图：折线过 (0, 6V)、(l, 2V)、(3l, 0)——a 段降 4V、b 段降 2V → Sₐ/S_b=2/(2×4)=1/4。
- 读数｜选 C（1/4）。备核通式：Sₐ/S_b=ΔUb/(2ΔUa)，实图启用时读两段电势降秒代。
- 坑点｜b 长是 a 的 2 倍——只比 ΔU 得 2:1、忘折长度因子是最常见错解。
- 注｜图依赖块，通行读图口径备核；若实图两段电势降相等（如 4V→2V→0），通式给出 1/2→B，启用前务必秒核。

### 60-13 热敏电阻水温计
- 题面摘要｜热敏电阻 Rt 与 R₀=100Ω 串接恒压源（内阻不计），电压表（0~3V）并 R₀，量程 0~100℃ 且 100℃ 满偏，判断四项。
- 自解｜通行读图：R-t 曲线读得 Rt(100℃)=50Ω、Rt(55℃)=87.5Ω。100℃ 满偏：U_R0=IR₀=3V → I=0.03A → E=0.03×(50+100)=4.5V（A「输出 3V」✗）。水温高 → Rt 减小 → I 增大 → U_R0=IR₀ 增大，示数越大（B「越小」✗）。0℃ 时 Rt 为有限值 → I>0 → 示数>0，0 刻度不对应 0℃（C✗）。55℃：U=4.5×100/(87.5+100)=450/187.5=2.40V（D✓）。
- 读数｜选 D。
- 坑点｜满偏 3V 是 R₀ 上的电压不是电源电动势——E 须用全回路欧姆定律另求。
- 注｜图依赖块：Rt 两读数为通行版图值；实图启用前按 D 项 2.40V 自洽性秒核（通式 U=E·R₀/(Rt+R₀)，E=0.03×(Rt100+R₀)）。

### 60-14 方块导体串联比较
- 题面摘要｜同料、上下面为正方形的长方体导体 P₁（上下面大）、P₂ 按图接电源，判断体积相同／厚度相同两种情形下的电流、功率、速率、电压。
- 自解｜通行读图：P₁ 与 P₂ 串联。方块电阻 R=ρ/d（d 为厚度）。体积同（V=L²d）：L₁>L₂ → d₁=V/L₁²<d₂ → R₁=ρ/d₁>R₂。串联同流 → 电流相等（A✗）；P=I²R → P₁>P₂（B✓）。厚度同 → R₁=R₂=ρ/d → 串联分压相等（D「P₁ 电压大」✗）；v=I/(neS⊥)，S⊥=dL₁>dL₂ → v₁<v₂，非相等（C✗）。
- 读数｜选 B。
- 坑点｜体积相同推出的是「大板更薄」——方块电阻只看厚度这把钥匙要联动用。
- 注｜图依赖块，串并联读向备核：若实图为并联，则 D 亦错（等压）且无正确项，故串联为唯一自洽读向。

### 63-3 滑变上移电容器动态
- 题面摘要｜R₁、R₂ 定值电阻，C 电容器，闭合 S 后滑变 R 滑片上滑，判断 R₂ 电流方向、R₁ 电流、R 电压与 C 电荷量。

### 63-4 二极管＋磁敏电阻＋电容器
- 题面摘要｜D 二极管、R₀ 滑变、磁敏电阻 R′（磁场越强阻值越大），水平平行板电容器上板接地，板间 P 点固定负电荷，判断四项。
- 自解｜通行读图：R′ 在主回路，电容器经 D 并于 R′ 两端（D 只允许充电方向）→ U_C=U_R′ 且只增不降。A：R₀ 滑片下移，无论接入增（U_R′↓→C 冻结不变）或接入减（U_R′↑→C 增）两种读向均无「减小」（A✗）。B：磁铁靠近 → 磁场增强 → R′↑ → I↓ → U_R′=E−I(R₀+内)↑ → C 充电、U_C↑ → P 处场强 E=U_C/d 变大（B「不变」✗）。C：上板左移 → d 不变、S↓ → 电容 C↓，电路侧 U_R′ 未变 → 本应放电但 D 阻断 → U_C 不变（C✗）。D：上板下移 → d↓ → C=εS/(4πkd)↑ → 需继续充电、D 允许 → U_C 维持 =U_R′ 不变；场强 E_f=U_C/d↑；下板电位高（+U_C 侧）、上板接地 0，P 点电势 φ_P=U_C(1−y/d)（y 为 P 离下板高度，下板未动、P 固定 → y 不变；d↓ → y/d↑ → φ_P↓）→ 负电荷电势能 E_p=qφ_P（q<0）随 φ_P 降而增大（D✓）。

- 坑点｜二极管的记忆性：U_R′ 想降时 U_C 冻结在峰值——每项都要按 D 的导通方向过一遍。
- 注｜图依赖块，通行读图口径备核（含下板接高电位端极板极性）；实图启用前若极性相反，D 项结论反转，务必秒核。

### 63-6 理想二极管＋双电容＋带电粒子
- 题面摘要｜D 理想二极管、R 滑动变阻器（分压）、等容电容器 C₁C₂，P、Q 带电粒子初始均静止，判断电荷量与滑片上／下滑后的运动。
- 自解｜通行读图：R 分压接电源；C₁ 直接并在输出端，C₂ 经 D 并在同一输出端（D 方向只允许充电电流节点→板）；P 在 C₁ 内、Q 在 C₂ 内，初始电场力各自平衡重力。A：初始两电容并同一节点 → U₁=U₂、C 相等 → Q₁=Q₂（A「不相等」✗）。滑片上滑 → 输出电压↓：C₁ 放电跟随 → U₁↓ → P 处场强↓ → 电场力小于重力 → P 加速向下；C₂ 欲放电但 D 阻断（只进不出）→ U₂ 冻结不变 → Q 仍静止 → C✓。滑片下滑 → 输出电压↑：C₁ 充电 U₁↑ → P 加速向上；C₂ 也充电 U₂↑ → Q 向上动，「Q 仍静止」不成立（B✗）；D 的「Q 也加速向下」与 U₂ 冻结矛盾（✗）。

- 坑点｜C₂ 电压「只升不降」——下滑时 P、Q 同向上动，B 专钓只盯 C₁ 的读法；上滑时冻结的恰是 Q。
