# 高中数学解题大招（二级结论）荟萃：项目整理改进方案

> 状态：待讨论，尚未执行  
> 本文仅记录整理思路，不代表已经调整目录、文件名、总索引或讲义内容。

## 一、整理目标

在保留现有十个知识模块的基础上，增加统一的横向分类，使每个专题不仅能按教材模块查找，还能按内容性质、核心题型和解题语言查找。

不建议把全部资料直接重分为“几何法、向量法、坐标法”三个目录。知识模块适合承担文件存放和教学顺序，方法分类更适合作为索引标签。

## 二、总体结构：知识模块与方法标签并存

### 1. 纵向目录：知识模块

继续沿用当前模块体系：

- 集合、逻辑与不等式
- 函数
- 导数
- 三角函数与解三角形
- 平面向量与复数
- 数列
- 立体几何
- 解析几何
- 计数原理
- 概率与统计

知识模块回答的是：**这个专题属于哪一部分高中数学知识？**

### 2. 横向标签：专题属性

建议为每个专题增加以下三组标签。

#### 内容性质

| 类型 | 含义 |
|---|---|
| 定理 | 有明确条件和结论、可以证明的命题 |
| 二级结论 | 由教材知识进一步推导出的快捷结论 |
| 模型 | 具有稳定图形或代数结构的识别模板 |
| 方法 | 能迁移到一类问题的完整求解路径 |
| 技巧 | 某个局部步骤中的简化计算或操作手段 |
| 题型策略 | 面向某类题目的识别与处理流程 |
| 解题思想 | 比具体方法更上位的思考方式，如数形结合、寻找不变量 |

#### 核心题型

记录专题主要解决的问题，例如：

- 求二面角
- 求空间距离
- 外接球与内切球
- 翻折问题
- 动点轨迹
- 圆锥曲线弦中点
- 定点、定值与最值
- 函数零点与恒成立

一个专题可以对应多个题型，一个题型也可以关联多个专题。

#### 解题语言

主要用于平面几何、立体几何和解析几何：

- 几何性质
- 向量
- 坐标代数
- 混合

解题语言回答的是：**这个方法主要用什么语言完成推理和计算？**

### “求二面角”题型入口示例

同一个题型可以关联多个现有专题：

```text
求二面角
├─ 几何性质法
│  ├─ 定义法：作二面角的平面角
│  ├─ 三余弦定理
│  └─ 投影法
├─ 向量法
│  ├─ 求两个平面的法向量
│  └─ 计算法向量夹角
└─ 建系坐标法
   ├─ 建立空间直角坐标系
   ├─ 计算法向量
   └─ 判断二面角的锐钝
```

现有“大招”在该题型中的位置：

| 现有专题 | 所起作用 |
|---|---|
| 三余弦定理 | 几何性质法中的一种求角方法 |
| 投影法求二面角 | 几何性质法中的一种求角方法 |
| 叉乘法快速求法向量 | 向量或坐标法中的计算工具 |
| 判断二面角的锐钝 | 得到法向量夹角后确定实际二面角 |

## 五、总索引建议字段

在现有 Excel 总索引基础上，后续可考虑形成以下字段：

| 字段 | 用途 |
|---|---|
| 编号 | 专题的稳定唯一标识 |
| 知识模块 | 确定教学归属与存放目录 |
| 专题名称 | 统一后的标准名称 |
| 内容性质 | 定理、结论、模型、方法、技巧等 |
| 核心题型 | 该专题主要解决什么问题 |
| 解题语言 | 几何性质、向量、坐标代数或混合 |
| 前置知识 | 学习该专题前需要掌握的内容 |
| 适用阶段 | 同步基础、一轮复习、二轮专题等 |
| 建议课时 | 教学时间建议 |
| 考试适用性 | 通用、选择填空、解答题、探究拓展等 |
| 证明要求 | 可直接使用、考场需简证、仅作思路、超纲慎用等 |
| 风险等级 | 使用该结论或方法的风险提示 |
| 复核状态 | 待整理、待复核、已复核等 |
| 源文件 | 教师母稿或原始资料路径 |
| 学生版 | 学生讲义路径 |
| 备注 | 其他说明 |

“无法证明”不宜继续作为笼统的文件名后缀。后续应区分：

- 尚未补充证明；
- 在高中知识范围内不便证明；
- 结论本身尚待核验；
- 结论正确但考试中不能直接使用。

## 六、单篇讲义建议模板

后续若统一讲义结构，可采用：

```text
1. 一句话识别：看到什么特征时想到本专题
2. 适用条件：结论成立需要满足什么条件
3. 核心结论或操作步骤
4. 原理与证明
5. 标准例题
6. 方法选择：与其他方法相比何时优先使用
7. 易错点与失效边界
8. 可迁移题型
9. 同类方法比较
10. 练习与答案
```

其中“适用条件”“方法选择”和“失效边界”是二级结论类资料最需要统一补充的部分。

## 七、文件与目录的后续建议

可考虑逐步形成：

```text
00_项目说明
01_总索引
02_教师母稿
03_学生讲义
04_原始资料
05_导出PDF
06_脚本与校验
```

教师母稿仍按十个知识模块分目录。专题文件建议使用稳定编号，例如：

```text
M07-013_翻折问题平面化_教师母稿.docx
M08-006_弦中点与点差法_教师母稿.docx
```

稳定编号不应因中间增加新专题而整体改变。

## 八、建议实施顺序

本方案目前不执行。若以后开始实施，建议按以下顺序进行：

1. 以实际存在的文件为准，修复 Markdown 和 Excel 中的文件路径。
2. 统一专题名称和稳定编号，处理历史命名差异。
3. 先在总索引增加“内容性质、核心题型、解题语言”等标签，不移动原稿。
4. 人工复核专题分类、结论正确性和考试适用性。
5. 按统一模板逐篇整理教师母稿。
6. 最后再考虑自动生成学生版、PDF 和快速索引。

## 九、当前阶段的原则

- 保留知识模块作为主要目录。
- 不把方法标签直接变成互斥的文件夹。
- 一个专题允许有多个题型标签和多种解题语言。
- 区分定理、二级结论、模型、方法、技巧和题型策略。
- 先建立可靠索引，再大规模调整文件和讲义。
- 所有结论在正式进入学生版前，应核验适用条件与考试可用性。
