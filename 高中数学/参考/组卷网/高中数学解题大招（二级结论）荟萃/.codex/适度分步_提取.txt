大招5 三角换元

[@@@78a9ed66e33d4e6b9a1172b56cce3774]

$1 + \tan^{2}\alpha = \frac{1}{\cos^{2}\alpha}$；$1 + \frac{1}{\tan^{2}\alpha} = \frac{1}{\sin^{2}\alpha}$

【类型一：根号内是“常数平方减变量平方”】若出现
$\sqrt{k^{2} - u^{2}}(k > 0)$，则由根式有意义可知 −k ≤ u ≤ k。令
$u = k\sin\theta,\theta \in \lbrack - \frac{\pi}{2},\frac{\pi}{2}\rbrack$，此时
cos θ ≥ 0，所以$\sqrt{k^{2} - u^{2}} = \sqrt{k^{2}(1 - \sin^{2}\theta)} = k\cos\theta$。这种换元既覆盖了
u
的全部取值，又能直接去掉根号。（令u = kcos θ也可以，但是取值范围需要改变）

【类型二：根号内是“常数平方加变量平方”】若出现
$\sqrt{k^{2} + u^{2}}(k > 0)$，令
$u = k\tan\theta,\theta \in ( - \frac{\pi}{2},\frac{\pi}{2})$。该区间内
cos θ > 0，因此
$\sqrt{k^{2} + u^{2}} = \sqrt{k^{2}(1 + \tan^{2}\theta)} = \frac{k}{\cos\theta}$。这里
tan θ 可以取遍所有实数，所以不会遗漏原变量的取值。

【类型三：根号内是“变量平方减常数平方”】若出现
$\sqrt{u^{2} - k^{2}}(k > 0)$，定义域分为 u ≥ k 与 u ≤ −k
两个分支。正分支可令
$u = \frac{k}{\cos\theta},\theta \in \lbrack 0,\frac{\pi}{2})$；负分支可令
$u = - \frac{k}{\cos\theta},\theta \in \lbrack 0,\frac{\pi}{2})$。两种情况下均有$\sqrt{u^{2} - k^{2}} = k\tan\theta$。若题目已给出
u
的正负，只需选取对应分支。（也可以$u = \frac{k}{\cos\theta},\theta \in \lbrack 0,\pi)$，但是得到的结果是k|tan θ|，依然需要分类讨论）

【类型四：圆约束】若 x² + y² = a(a > 0)，可令
$x = \sqrt{a}\cos\theta,y = \sqrt{a}\sin\theta,\theta \in \lbrack 0,2\pi)$。代入后恒有
x² + y² = a，并且该参数范围能够覆盖整个圆，因此二元约束被化为一个角变量。

【类型五：椭圆约束】若
$\frac{x^{2}}{m} + \frac{y^{2}}{n} = 1(m > 0,n > 0)$，可令
$x = \sqrt{m}\cos\theta,y = \sqrt{n}\sin\theta$。因为
$\frac{x^{2}}{m} = \cos^{2}\theta$、$\frac{y^{2}}{n} = \sin^{2}\theta$，所以约束自动成立。与圆相比，两个坐标只是在不同方向上进行了伸缩。

【二次约束怎样用于求最值】设 p, q 为给定实数。例如在 x² + y² = a(a > 0)
的条件下求 px + qy 的最值。换元后
$px + qy = \sqrt{a}(p\cos\theta + q\sin\theta)$，由辅助角公式可得
$- \sqrt{a(p^{2} + q^{2})} \leq px + qy \leq \sqrt{a(p^{2} + q^{2})}$。这说明三角换元的作用是把二元化成一个角变量，而不是单纯改变写法。

【含交叉项：先配方，再换元】例如
x² − xy + y² = 1，先配方：${(x - \frac{y}{2})}^{2} + {(\frac{\sqrt{3}y}{2})}^{2} = 1$。于是可令
$x - \frac{y}{2} = \cos\theta,\frac{\sqrt{3}y}{2} = \sin\theta$，其中
θ ∈ [0, 2π)。解得$y = \frac{2\sqrt{3}}{3}\sin\theta,x = \cos\theta + \frac{\sqrt{3}}{3}\sin\theta$。这样既自动满足原约束，又把
x, y 都表示成了一个角的函数。

【一般二次式：先配方，再换元】例如 $\sqrt{2x^{2} + 4x + 5}$，先配方得
$\sqrt{2(x + 1)^{2} + 3}$。令
$x + 1 = \sqrt{\frac{3}{2}}\tan\theta,\theta \in ( - \frac{\pi}{2},\frac{\pi}{2})$，则
$\sqrt{2x^{2} + 4x + 5} = \frac{\sqrt{3}}{\cos\theta}$。因此，配方后应把整体
x + 1 作为换元对象，不能只替换单独的 x。

【拓展一（不用学）：三维球面约束】对于
x² + y² + z² = a(a > 0)，一个角只能描述圆，不能覆盖整个球面。若需要完整表示球面，可使用两个角参数：$x = \sqrt{a}\sin\varphi\cos\theta,y = \sqrt{a}\sin\varphi\sin\theta,z = \sqrt{a}\cos\varphi$，其中
φ ∈ [0, π], θ ∈ [0, 2π)。这一内容用于理解二维圆参数化向三维的推广，正文解题时应根据目标式判断是否真的需要两个角。

【拓展二（不用学）：双曲型约束】对于 x² − y² = 1，应匹配恒等式
$\frac{1}{\cos^{2}\theta} - \tan^{2}\theta = 1$。当
$\theta \in ( - \frac{\pi}{2},\frac{\pi}{2})$ 时，右支 x ≥ 1 可令
$x = \frac{1}{\cos\theta},y = \tan\theta$；左支 x ≤ −1 可令
$x = - \frac{1}{\cos\theta},y = \tan\theta$。两支必须分别表示，否则会遗漏一半图象。

【典例1】求函数$y = 3x + \sqrt{1 - x^{2}}$的值域.

第一步　完成三角换元

解析：由根式有意义可知 x ∈ [−1, 1]。令 x = cos θ, θ ∈ [0, π]，则
sin θ ≥ 0，从而 $\sqrt{1 - x^{2}} = \sin\theta$。取
$\varphi \in (0,\frac{\pi}{2})$，使
$\sin\varphi = \frac{3}{\sqrt{10}},\cos\varphi = \frac{1}{\sqrt{10}}$，于是
$y = 3\cos\theta + \sin\theta = \sqrt{10}\sin(\theta + \varphi)$。

第二步　利用角度范围求值域

因为 θ + φ ∈ [φ, π + φ]，且
$\frac{\pi}{2} \in \lbrack\varphi,\pi + \varphi\rbrack$，所以当
$\theta = \frac{\pi}{2} - \varphi$ 时，y 取得最大值 $\sqrt{10}$；当
θ = π 时，y 取得最小值 −3。

$$\therefore f(\theta)的值域为\left\lbrack - 3,\sqrt{10} \right\rbrack$$

【温馨提醒】

本题令 x = cos θ, θ ∈ [0, π]，是因为 cos θ 在该区间可取遍 [−1, 1]，且
sin θ ≥ 0，故
$\sqrt{1 - x^{2}} = \sqrt{1 - \cos^{2}\theta} = |\sin\theta| = \sin\theta$。

【举一反三】

1．求函数$y = \sqrt{3x + 6} + \sqrt{8 - x}$的值域.

【答案】$\left\lbrack \sqrt{10},2\sqrt{10} \right\rbrack$【难度】0.65【知识点】求含sinx(型)函数的值域和最值、辅助角公式

【详解】$y = \sqrt{3x + 6} + \sqrt{8 - x}$可化为
$y = \sqrt{3} \cdot \sqrt{x + 2} + \sqrt{10 - (x + 2)}$，令$x + 2 = 10\sin^{2}\alpha,0 \leq \alpha \leq \frac{\text{π}}{2}$，

则$y = \sqrt{30}\sin\alpha + \sqrt{10}\cos\alpha$
$= 2\sqrt{10}\left( \frac{\sqrt{3}}{2}\sin\alpha + \frac{1}{2}\cos\alpha \right) = 2\sqrt{10}\sin(\alpha + \frac{\text{π}}{6})$，
$\because 0 \leq \alpha \leq \frac{\text{π}}{2},\therefore\frac{\text{π}}{6} \leq \alpha + \frac{\text{π}}{6} \leq \frac{\text{2π}}{3}$，

$\therefore\frac{1}{2} \leq \sin(\alpha + \frac{\text{π}}{6}) \leq 1$，∴$y \in \left\lbrack \sqrt{10},2\sqrt{10} \right\rbrack$,故函数的值域为$\left\lbrack \sqrt{10},2\sqrt{10} \right\rbrack$.

2．若对任意x ≥ 0，$k\sqrt{1 + x} \geqslant \text{1} + \sqrt{x}$恒成立，则实数k的取值范围是______.

【答案】$\lbrack\sqrt{2}, + \infty)$【难度】0.65【知识点】基本不等式求和的最小值、基本不等式的恒成立问题

【详解】法一（三角换元）令
$\sqrt{x} = \tan\theta\left( 0 \leq \theta < \frac{\pi}{2} \right)$，则
$x = \tan^{2}\theta,\sqrt{1 + x} = \frac{1}{\cos\theta}$。原不等式可化为
$k \geq \frac{1 + \sqrt{x}}{\sqrt{1 + x}} = \left( 1 + \tan\theta \right)\cos\theta$

 = sin θ + cos θ。因为 $\sin\theta + \cos\theta \leq \sqrt{2}$，当且仅当
$\theta = \frac{\pi}{4}$，即 x = 1 时取等号，所以 $k \geq \sqrt{2}$。

法二（基本不等式）因为x ≥ 0，所以$\sqrt{1 + x} > 0$，所以不等式可化为$k \geq \frac{1 + \sqrt{x}}{\sqrt{1 + x}}$，设$\mu = \frac{1 + \sqrt{x}}{\sqrt{1 + x}}$，x ≥ 0，则μ > 0，

则$\mu^{2} = \frac{1 + x + 2\sqrt{x}}{1 + x} = 1 + \frac{2\sqrt{x}}{1 + x}$，因为x ≥ 0，所以$1 + x \geqslant 2\sqrt{x}$，当且仅当x = 1时取等号，所以$\mu^{2} = 1 + \frac{2\sqrt{x}}{1 + x} \leqslant 1 + \frac{1 + x}{1 + x} = 2$，

即$0 < \mu \leqslant \sqrt{2}$，所以$k \in \lbrack\sqrt{2}, + \infty)$，故答案为：$\lbrack\sqrt{2}, + \infty)$

【典例2】已知a⃗, b⃗, c⃗满足|a⃗| = 1，|b⃗| = 2，|c⃗| = 3，且a⃗ ⋅ (b⃗ + c⃗) = b⃗ ⋅ c⃗ + 1，则|b⃗ − c⃗|的取值范围      .

解析：

法一（辅助角公式）

第一步　建立坐标与参数方程

不妨令
$\overset{\rightarrow}{c} = (3,0),\overset{\rightarrow}{b} = (2\cos\theta,2\sin\theta),\overset{\rightarrow}{a} = (\cos\alpha,\sin\alpha)$，其中
α, θ ∈ [0, 2π)。

由题设
$\overset{\rightarrow}{a} \cdot (\overset{\rightarrow}{b} + \overset{\rightarrow}{c}) = \overset{\rightarrow}{b} \cdot \overset{\rightarrow}{c} + 1$，可得

2sin θsin α + (2cos θ + 3)cos α = 6cos θ + 1。

当 θ 固定时，由辅助角公式，左边关于 α 的取值范围为

$\lbrack - \sqrt{(2\sin\theta)^{2} + (2\cos\theta + 3)^{2}},\text{ }\sqrt{(2\sin\theta)^{2} + (2\cos\theta + 3)^{2}}\rbrack = \lbrack - \sqrt{13 + 12\cos\theta},\text{ }\sqrt{13 + 12\cos\theta}\rbrack$。

第二步　求参数的可行范围

因此原等式有解的充要条件为
$|6\cos\theta + 1| \leq \sqrt{13 + 12\cos\theta}$。

令 t = cos θ，则 (6t + 1)² ≤ 13 + 12t，即 36t² ≤ 12，所以
$- \frac{\sqrt{3}}{3} \leq t \leq \frac{\sqrt{3}}{3}$。

第三步　表示目标式并求范围

${|\overset{\rightarrow}{b} - \overset{\rightarrow}{c}|}^{2} = (2\cos\theta - 3)^{2} + (2\sin\theta)^{2} = 13 - 12\cos\theta = 13 - 12t$。

由 $- \frac{\sqrt{3}}{3} \leq t \leq \frac{\sqrt{3}}{3}$，得
$13 - 4\sqrt{3} \leq {|\overset{\rightarrow}{b} - \overset{\rightarrow}{c}|}^{2} \leq 13 + 4\sqrt{3}$。

又
$13 - 4\sqrt{3} = (2\sqrt{3} - 1)^{2},13 + 4\sqrt{3} = (2\sqrt{3} + 1)^{2}$，所以
$|\overset{\rightarrow}{b} - \overset{\rightarrow}{c}| \in \lbrack 2\sqrt{3} - 1,2\sqrt{3} + 1\rbrack$。

法二（柯西不等式）

第一步　建立坐标模型

同法一建立平面直角坐标系，不妨令
$\overset{\rightarrow}{c} = (3,0),\overset{\rightarrow}{b} = (2\cos\theta,2\sin\theta),\overset{\rightarrow}{a} = (\cos\alpha,\sin\alpha)$，其中
α, θ ∈ [0, 2π)。

由题设可得 2sin θsin α + (2cos θ + 3)cos α = 6cos θ + 1。

第二步　应用柯西不等式

先证明二维柯西不等式。设
u⃗ = (x₁, x₂), v⃗ = (y₁, y₂)。若其中一个为零向量，则不等式两边均为
0；若二者均为非零向量，设其夹角为 β。

根据向量数量积的定义，$x_{1}y_{1} + x_{2}y_{2} = \overset{\rightarrow}{u} \cdot \overset{\rightarrow}{v} = |\overset{\rightarrow}{u}||\overset{\rightarrow}{v}|\cos\beta$。

因为 |cos β| ≤ 1，所以
$|x_{1}y_{1} + x_{2}y_{2}| \leq \sqrt{x_{1}^{2} + x_{2}^{2}}\sqrt{y_{1}^{2} + y_{2}^{2}}$，这就是二维柯西不等式。

在本题中，取
$\overset{\rightarrow}{u} = (2\sin\theta,2\cos\theta + 3),\overset{\rightarrow}{v} = (\sin\alpha,\cos\alpha)$，则

$\overset{\rightarrow}{u} \cdot \overset{\rightarrow}{v} = 2\sin\theta\sin\alpha + (2\cos\theta + 3)\cos\alpha = 6\cos\theta + 1$，

$|\overset{\rightarrow}{u}| = \sqrt{13 + 12\cos\theta},|\overset{\rightarrow}{v}| = \sqrt{\sin^{2}\alpha + \cos^{2}\alpha} = 1$。

由柯西不等式，$|6\cos\theta + 1| \leq \sqrt{13 + 12\cos\theta}$。两边平方，得
(6cos θ + 1)² ≤ 13 + 12cos θ。

展开并整理，得 36cos²θ + 12cos θ + 1 ≤ 13 + 12cos θ，即
36cos²θ ≤ 12，所以
$- \frac{\sqrt{3}}{3} \leq \cos\theta \leq \frac{\sqrt{3}}{3}$。

第三步　验证可取性并回到目标式

由于 $\overset{\rightarrow}{v} = (\sin\alpha,\cos\alpha)$
可以表示任意单位向量，所以对上述区间内的每个 cos θ，均可选取适当的 α
使原等式成立，故该区间可以取遍。

最后，${|\overset{\rightarrow}{b} - \overset{\rightarrow}{c}|}^{2} = (2\cos\theta - 3)^{2} + 4\sin^{2}\theta = 13 - 12\cos\theta$，从而
$13 - 4\sqrt{3} \leq {|\overset{\rightarrow}{b} - \overset{\rightarrow}{c}|}^{2} \leq 13 + 4\sqrt{3}$。

因此
$|\overset{\rightarrow}{b} - \overset{\rightarrow}{c}| \in \lbrack 2\sqrt{3} - 1,2\sqrt{3} + 1\rbrack$。

法三（直接向量法）

第一步　引入数量积参数

令 $t = \overset{\rightarrow}{b} \cdot \overset{\rightarrow}{c}$，并设
$\overset{\rightarrow}{b}$ 与 $\overset{\rightarrow}{c}$ 的夹角为 γ。则
$t = |\overset{\rightarrow}{b}||\overset{\rightarrow}{c}|\cos\gamma = 6\cos\gamma$，故
−6 ≤ t ≤ 6。

由题设
$\overset{\rightarrow}{a} \cdot (\overset{\rightarrow}{b} + \overset{\rightarrow}{c}) = \overset{\rightarrow}{b} \cdot \overset{\rightarrow}{c} + 1$，可得
$\overset{\rightarrow}{a} \cdot (\overset{\rightarrow}{b} + \overset{\rightarrow}{c}) = t + 1$。

又
${|\overset{\rightarrow}{b} + \overset{\rightarrow}{c}|}^{2} = {|\overset{\rightarrow}{b}|}^{2} + {|\overset{\rightarrow}{c}|}^{2} + 2\overset{\rightarrow}{b} \cdot \overset{\rightarrow}{c} = 4 + 9 + 2t = 13 + 2t$，所以
$|\overset{\rightarrow}{b} + \overset{\rightarrow}{c}| = \sqrt{13 + 2t}$。

设 $\overset{\rightarrow}{a}$ 与
$\overset{\rightarrow}{b} + \overset{\rightarrow}{c}$ 的夹角为 β。因为
$|\overset{\rightarrow}{a}| = 1$，由数量积的定义得
$t + 1 = \overset{\rightarrow}{a} \cdot (\overset{\rightarrow}{b} + \overset{\rightarrow}{c}) = |\overset{\rightarrow}{a}||\overset{\rightarrow}{b} + \overset{\rightarrow}{c}|\cos\beta = \sqrt{13 + 2t}\cos\beta$。

第二步　求参数范围并验证充分性

因为 0 ≤ cos²β ≤ 1，所以 (t + 1)² = (13 + 2t)cos²β ≤ 13 + 2t。整理得
t² + 2t + 1 ≤ 13 + 2t，即 t² ≤ 12，故
$- 2\sqrt{3} \leq t \leq 2\sqrt{3}$。

反之，对任意 $t \in \lbrack - 2\sqrt{3},2\sqrt{3}\rbrack$，可先取
$\cos\gamma = \frac{t}{6}$，再取
$\cos\beta = \frac{t + 1}{\sqrt{13 + 2t}}$，因此该区间内的每个 t
均可取得。

第三步　回到目标式

由向量减法的模长公式，${|\overset{\rightarrow}{b} - \overset{\rightarrow}{c}|}^{2} = {|\overset{\rightarrow}{b}|}^{2} + {|\overset{\rightarrow}{c}|}^{2} - 2\overset{\rightarrow}{b} \cdot \overset{\rightarrow}{c} = 13 - 2t$。因为
$- 2\sqrt{3} \leq t \leq 2\sqrt{3}$，所以
$13 - 4\sqrt{3} \leq {|\overset{\rightarrow}{b} - \overset{\rightarrow}{c}|}^{2} \leq 13 + 4\sqrt{3}$。

注意到
$13 - 4\sqrt{3} = (2\sqrt{3} - 1)^{2},13 + 4\sqrt{3} = (2\sqrt{3} + 1)^{2}$，且
$|\overset{\rightarrow}{b} - \overset{\rightarrow}{c}| \geq 0$，故
$|\overset{\rightarrow}{b} - \overset{\rightarrow}{c}| \in \lbrack 2\sqrt{3} - 1,2\sqrt{3} + 1\rbrack$。

由于$- \frac{\text{π}}{2} < \theta < \frac{\text{π}}{2}$，$\therefore - \frac{5\text{π}}{6} < \theta - \frac{\text{π}}{3} < \frac{\text{π}}{6}$．

而当$- \frac{5\text{π}}{6} < \theta - \frac{\text{π}}{3} < - \frac{\text{π}}{2}$时，y为减函数，此时−2 < y < −1，

当$- \frac{\text{π}}{2} \leq \theta - \frac{\text{π}}{3} < \frac{\text{π}}{6}$时，y为增函数，此时−2 ≤ y < 1．

故函数的值域为[−2, 1)．

（3）法一（三角换元）：

第一步　配方并完成三角换元

∵2x² − 4x + 6 = 2(x − 1)² + 4，∴可设$x - 1 = \sqrt{2}\tan\theta\left( |\theta| < \frac{\text{π}}{2} \right)$．

则$y = \sqrt{2}\tan\theta + 1 + \frac{2}{\cos\theta} = \frac{\sqrt{2}(\sqrt{2} + \sin\theta)}{\cos\theta} + 1$．

第二步　转化为方程有解问题

设 $u = \frac{\sqrt{2} + \sin\theta}{\cos\theta}$，其中
$|\theta| < \frac{\pi}{2}$。由于 cos θ > 0 且
$\sqrt{2} + \sin\theta > 0$，所以 u > 0，并且
$u\cos\theta - \sin\theta = \sqrt{2}$。

对固定的 u > 0，令 g_(u)(θ) = ucos θ − sin θ。在
$( - \frac{\pi}{2},\frac{\pi}{2})$ 内，g_(u) 的最大值为
$\sqrt{u^{2} + 1}$，且当 $\theta \rightarrow - \frac{\pi}{2}^{+}$ 时
$g_{u}(\theta) \rightarrow 1 < \sqrt{2}$。

因此，方程 $g_{u}(\theta) = \sqrt{2}$ 在该区间有解的充要条件为
$\sqrt{u^{2} + 1} \geq \sqrt{2}$，即 u ≥ 1。这同时说明所有 u ∈ [1, +∞)
均可取得。

第三步　回到原函数值域

由 $y = \sqrt{2}u + 1$，得函数的值域为
$\lbrack\sqrt{2} + 1, + \infty)$；当 $u = 1,\theta = - \frac{\pi}{4}$
时取得左端点。

法二（几何法）：

第一步　建立右半圆斜率模型

设 $u = \frac{\sqrt{2} + \sin\theta}{\cos\theta}$，其中
$|\theta| < \frac{\pi}{2}$。令 P(cos θ, sin θ)，则 P 在右半圆
x² + y² = 1 (x > 0) 上，且 u 是点 $A(0, - \sqrt{2})$ 与点 P 连线的斜率。
