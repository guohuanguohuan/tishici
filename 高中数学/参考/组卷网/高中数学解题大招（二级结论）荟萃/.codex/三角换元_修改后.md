$`1 + \tan^{2}\alpha = \frac{1}{\cos^{2}\alpha}`$；$`1 + \frac{1}{\tan^{2}\alpha} = \frac{1}{\sin^{2}\alpha}`$

**【类型一：根号内是“常数平方减变量平方”】**若出现 $`\sqrt{k^{2} - u^{2}}(k > 0)`$，则由根式有意义可知 $`- k \leq u \leq k`$。令 $`u = k\sin\theta,\theta \in \lbrack - \frac{\pi}{2},\frac{\pi}{2}\rbrack`$，此时 $`\cos\theta \geq 0`$，所以$`\sqrt{k^{2} - u^{2}} = \sqrt{k^{2}(1 - \sin^{2}\theta)} = k\cos\theta`$。这种换元既覆盖了 $`u`$ 的全部取值，又能直接去掉根号。（令$`u = k\cos\theta`$也可以，但是取值范围需要改变）

**【类型二：根号内是“常数平方加变量平方”】**若出现 $`\sqrt{k^{2} + u^{2}}(k > 0)`$，令 $`u = k\tan\theta,\theta \in ( - \frac{\pi}{2},\frac{\pi}{2})`$。该区间内 $`\cos\theta > 0`$，因此\
$`\sqrt{k^{2} + u^{2}} = \sqrt{k^{2}(1 + \tan^{2}\theta)} = \frac{k}{\cos\theta}`$。这里 $`\tan\theta`$ 可以取遍所有实数，所以不会遗漏原变量的取值。

**【类型三：根号内是“变量平方减常数平方”】**若出现 $`\sqrt{u^{2} - k^{2}}(k > 0)`$，定义域分为 $`u \geq k`$ 与 $`u \leq - k`$ 两个分支。正分支可令 $`u = \frac{k}{\cos\theta},\theta \in \lbrack 0,\frac{\pi}{2})`$；负分支可令 $`u = - \frac{k}{\cos\theta},\theta \in \lbrack 0,\frac{\pi}{2})`$。两种情况下均有$`\sqrt{u^{2} - k^{2}} = k\tan\theta`$。若题目已给出 $`u`$ 的正负，只需选取对应分支。（也可以$`u = \frac{k}{\cos\theta},\theta \in \lbrack 0,\pi)`$，但是得到的结果是$`k|\tan\theta|`$，依然需要分类讨论）

**【类型四：圆约束】**若 $`x^{2} + y^{2} = a(a > 0)`$，可令 $`x = \sqrt{a}\cos\theta,y = \sqrt{a}\sin\theta,\theta \in \lbrack 0,2\pi)`$。代入后恒有 $`x^{2} + y^{2} = a`$，并且该参数范围能够覆盖整个圆，因此二元约束被化为一个角变量。

**【类型五：椭圆约束】**若 $`\frac{x^{2}}{m} + \frac{y^{2}}{n} = 1(m > 0,n > 0)`$，可令 $`x = \sqrt{m}\cos\theta,y = \sqrt{n}\sin\theta`$。因为 $`\frac{x^{2}}{m} = \cos^{2}\theta`$、$`\frac{y^{2}}{n} = \sin^{2}\theta`$，所以约束自动成立。与圆相比，两个坐标只是在不同方向上进行了伸缩。

**【二次约束怎样用于求最值】**设 $`p,q`$ 为给定实数。例如在 $`x^{2} + y^{2} = a(a > 0)`$ 的条件下求 $`px + qy`$ 的最值。换元后\
$`px + qy = \sqrt{a}(p\cos\theta + q\sin\theta)`$，由辅助角公式可得 $`- \sqrt{a(p^{2} + q^{2})} \leq px + qy \leq \sqrt{a(p^{2} + q^{2})}`$。这说明三角换元的作用是把二元化成一个角变量，而不是单纯改变写法。

**【含交叉项：先配方，再换元】**例如 $`x^{2} - xy + y^{2} = 1`$，先配方：$`{(x - \frac{y}{2})}^{2} + {(\frac{\sqrt{3}y}{2})}^{2} = 1`$。于是可令 $`x - \frac{y}{2} = \cos\theta,\frac{\sqrt{3}y}{2} = \sin\theta`$，其中 $`\theta \in \lbrack 0,2\pi)`$。解得$`y = \frac{2\sqrt{3}}{3}\sin\theta,x = \cos\theta + \frac{\sqrt{3}}{3}\sin\theta`$。这样既自动满足原约束，又把 $`x,y`$ 都表示成了一个角的函数。

**【一般二次式：先配方，再换元】**例如 $`\sqrt{2x^{2} + 4x + 5}`$，先配方得 $`\sqrt{2(x + 1)^{2} + 3}`$。令 $`x + 1 = \sqrt{\frac{3}{2}}\tan\theta,\theta \in ( - \frac{\pi}{2},\frac{\pi}{2})`$，则\
$`\sqrt{2x^{2} + 4x + 5} = \frac{\sqrt{3}}{\cos\theta}`$。因此，配方后应把整体 $`x + 1`$ 作为换元对象，不能只替换单独的 $`x`$。

**【拓展一**（不用学）**：三维球面约束】**对于 $`x^{2} + y^{2} + z^{2} = a(a > 0)`$，一个角只能描述圆，不能覆盖整个球面。若需要完整表示球面，可使用两个角参数：$`x = \sqrt{a}\sin\varphi\cos\theta,y = \sqrt{a}\sin\varphi\sin\theta,z = \sqrt{a}\cos\varphi`$，其中 $`\varphi \in \lbrack 0,\pi\rbrack,\theta \in \lbrack 0,2\pi)`$。这一内容用于理解二维圆参数化向三维的推广，正文解题时应根据目标式判断是否真的需要两个角。

**【拓展二**（不用学）**：双曲型约束】**对于 $`x^{2} - y^{2} = 1`$，应匹配恒等式 $`\frac{1}{\cos^{2}\theta} - \tan^{2}\theta = 1`$。当 $`\theta \in ( - \frac{\pi}{2},\frac{\pi}{2})`$ 时，右支 $`x \geq 1`$ 可令 $`x = \frac{1}{\cos\theta},y = \tan\theta`$；左支 $`x \leq - 1`$ 可令 $`x = - \frac{1}{\cos\theta},y = \tan\theta`$。两支必须分别表示，否则会遗漏一半图象。

因为 $`\theta + \varphi \in \lbrack\varphi,\pi + \varphi\rbrack`$，且 $`\frac{\pi}{2} \in \lbrack\varphi,\pi + \varphi\rbrack`$，所以当 $`\theta = \frac{\pi}{2} - \varphi`$ 时，$`y`$ 取得最大值 $`\sqrt{10}`$；当 $`\theta = \pi`$ 时，$`y`$ 取得最小值 $`- 3`$。

即$`0 < \mu \leqslant \sqrt{2}`$，所以$`k \in \lbrack\sqrt{2}, + \infty)`$，故答案为：$`\lbrack\sqrt{2}, + \infty)`$

【典例2】已知$`\overrightarrow{a},\overrightarrow{b},\overrightarrow{c}满足\left| \overrightarrow{a} \right| = 1，\left| \overrightarrow{b} \right| = 2，\left| \overrightarrow{c} \right| = 3，且\overrightarrow{a} \cdot (\overrightarrow{b} + \overrightarrow{c}) = \overrightarrow{b} \cdot \overrightarrow{c} + 1`$，则$`\left| \overrightarrow{b} - \overrightarrow{c} \right|`$的取值范围      .

**解析：**

**法一（辅助角公式）**

**第一步：建立坐标，转化已知条件**

不妨令 $`\overset{\rightarrow}{c} = (3,0),\overset{\rightarrow}{b} = (2\cos\theta,2\sin\theta),\overset{\rightarrow}{a} = (\cos\alpha,\sin\alpha)`$，其中 $`\alpha,\theta \in \lbrack 0,2\pi)`$。

由题设 $`\overset{\rightarrow}{a} \cdot (\overset{\rightarrow}{b} + \overset{\rightarrow}{c}) = \overset{\rightarrow}{b} \cdot \overset{\rightarrow}{c} + 1`$，可得

$`2\sin\theta\sin\alpha + (2\cos\theta + 3)\cos\alpha = 6\cos\theta + 1`$。

**第二步：利用辅助角公式求参数范围**

当 $`\theta`$ 固定时，由辅助角公式，左边关于 $`\alpha`$ 的取值范围为

$`\lbrack - \sqrt{(2\sin\theta)^{2} + (2\cos\theta + 3)^{2}},\text{ }\sqrt{(2\sin\theta)^{2} + (2\cos\theta + 3)^{2}}\rbrack = \lbrack - \sqrt{13 + 12\cos\theta},\text{ }\sqrt{13 + 12\cos\theta}\rbrack`$。

因此原等式有解的充要条件为 $`|6\cos\theta + 1| \leq \sqrt{13 + 12\cos\theta}`$。

令 $`t = \cos\theta`$，则 $`(6t + 1)^{2} \leq 13 + 12t`$，即 $`36t^{2} \leq 12`$，所以 $`- \frac{\sqrt{3}}{3} \leq t \leq \frac{\sqrt{3}}{3}`$。

**第三步：用参数表示目标式**

$`{|\overset{\rightarrow}{b} - \overset{\rightarrow}{c}|}^{2} = (2\cos\theta - 3)^{2} + (2\sin\theta)^{2} = 13 - 12\cos\theta = 13 - 12t`$。

**第四步：确定目标式的取值范围**

由 $`- \frac{\sqrt{3}}{3} \leq t \leq \frac{\sqrt{3}}{3}`$，得 $`13 - 4\sqrt{3} \leq {|\overset{\rightarrow}{b} - \overset{\rightarrow}{c}|}^{2} \leq 13 + 4\sqrt{3}`$。

又 $`13 - 4\sqrt{3} = (2\sqrt{3} - 1)^{2},13 + 4\sqrt{3} = (2\sqrt{3} + 1)^{2}`$，所以 $`|\overset{\rightarrow}{b} - \overset{\rightarrow}{c}| \in \lbrack 2\sqrt{3} - 1,2\sqrt{3} + 1\rbrack`$。

**法二（柯西不等式）**

**第一步  同法一建立坐标系，取 u=(2sinθ,2cosθ+3)，v=(sinα,cosα)**

同法一建立平面直角坐标系，不妨令 $`\overset{\rightarrow}{c} = (3,0),\overset{\rightarrow}{b} = (2\cos\theta,2\sin\theta),\overset{\rightarrow}{a} = (\cos\alpha,\sin\alpha)`$，其中 $`\alpha,\theta \in \lbrack 0,2\pi)`$。

由题设可得 $`2\sin\theta\sin\alpha + (2\cos\theta + 3)\cos\alpha = 6\cos\theta + 1`$。

**第二步  由柯西不等式 \|u·v\|≤\|u\|\|v\| 得到 cosθ 的范围（注：此处柯西即法一中辅助角的等价写法）**

先证明二维柯西不等式。设 $`\overrightarrow{u} = (x_{1},x_{2}),\overrightarrow{v} = (y_{1},y_{2})`$。若其中一个为零向量，则不等式两边均为 $`0`$；若二者均为非零向量，设其夹角为 $`\beta`$。

根据向量数量积的定义，$`x_{1}y_{1} + x_{2}y_{2} = \overset{\rightarrow}{u} \cdot \overset{\rightarrow}{v} = |\overset{\rightarrow}{u}||\overset{\rightarrow}{v}|\cos\beta`$。

因为 $`|\cos\beta| \leq 1`$，所以 $`|x_{1}y_{1} + x_{2}y_{2}| \leq \sqrt{x_{1}^{2} + x_{2}^{2}}\sqrt{y_{1}^{2} + y_{2}^{2}}`$，这就是二维柯西不等式。

在本题中，取 $`\overset{\rightarrow}{u} = (2\sin\theta,2\cos\theta + 3),\overset{\rightarrow}{v} = (\sin\alpha,\cos\alpha)`$，则

$`\overset{\rightarrow}{u} \cdot \overset{\rightarrow}{v} = 2\sin\theta\sin\alpha + (2\cos\theta + 3)\cos\alpha = 6\cos\theta + 1`$，

$`|\overset{\rightarrow}{u}| = \sqrt{13 + 12\cos\theta},|\overset{\rightarrow}{v}| = \sqrt{\sin^{2}\alpha + \cos^{2}\alpha} = 1`$。

由柯西不等式，$`|6\cos\theta + 1| \leq \sqrt{13 + 12\cos\theta}`$。两边平方，得 $`(6\cos\theta + 1)^{2} \leq 13 + 12\cos\theta`$。

展开并整理，得 $`36\cos^{2}\theta + 12\cos\theta + 1 \leq 13 + 12\cos\theta`$，即 $`36\cos^{2}\theta \leq 12`$，所以 $`- \frac{\sqrt{3}}{3} \leq \cos\theta \leq \frac{\sqrt{3}}{3}`$。

由于 $`\overset{\rightarrow}{v} = (\sin\alpha,\cos\alpha)`$ 可以表示任意单位向量，所以对上述区间内的每个 $`\cos\theta`$，均可选取适当的 $`\alpha`$ 使原等式成立，故该区间可以取遍。

最后，$`{|\overset{\rightarrow}{b} - \overset{\rightarrow}{c}|}^{2} = (2\cos\theta - 3)^{2} + 4\sin^{2}\theta = 13 - 12\cos\theta`$，从而 $`13 - 4\sqrt{3} \leq {|\overset{\rightarrow}{b} - \overset{\rightarrow}{c}|}^{2} \leq 13 + 4\sqrt{3}`$。

因此 $`|\overset{\rightarrow}{b} - \overset{\rightarrow}{c}| \in \lbrack 2\sqrt{3} - 1,2\sqrt{3} + 1\rbrack`$。

**法三（直接向量法）**

**第一步  令 t=b·c，由向量夹角得 t=6cosγ，故 t∈\[-6,6\]**

令 $`t = \overset{\rightarrow}{b} \cdot \overset{\rightarrow}{c}`$，并设 $`\overset{\rightarrow}{b}`$ 与 $`\overset{\rightarrow}{c}`$ 的夹角为 $`\gamma`$。则 $`t = |\overset{\rightarrow}{b}||\overset{\rightarrow}{c}|\cos\gamma = 6\cos\gamma`$，故 $`- 6 \leq t \leq 6`$。

由题设 $`\overset{\rightarrow}{a} \cdot (\overset{\rightarrow}{b} + \overset{\rightarrow}{c}) = \overset{\rightarrow}{b} \cdot \overset{\rightarrow}{c} + 1`$，可得 $`\overset{\rightarrow}{a} \cdot (\overset{\rightarrow}{b} + \overset{\rightarrow}{c}) = t + 1`$。

**第二步  利用 \|a\|=1 及余弦有界性缩小 t 的范围为 \[-2√3,2√3\]**

又 $`{|\overset{\rightarrow}{b} + \overset{\rightarrow}{c}|}^{2} = {|\overset{\rightarrow}{b}|}^{2} + {|\overset{\rightarrow}{c}|}^{2} + 2\overset{\rightarrow}{b} \cdot \overset{\rightarrow}{c} = 4 + 9 + 2t = 13 + 2t`$，所以 $`|\overset{\rightarrow}{b} + \overset{\rightarrow}{c}| = \sqrt{13 + 2t}`$。

设 $`\overset{\rightarrow}{a}`$ 与 $`\overset{\rightarrow}{b} + \overset{\rightarrow}{c}`$ 的夹角为 $`\beta`$。因为 $`|\overset{\rightarrow}{a}| = 1`$，由数量积的定义得 $`t + 1 = \overset{\rightarrow}{a} \cdot (\overset{\rightarrow}{b} + \overset{\rightarrow}{c}) = |\overset{\rightarrow}{a}||\overset{\rightarrow}{b} + \overset{\rightarrow}{c}|\cos\beta = \sqrt{13 + 2t}\cos\beta`$。

因为 $`0 \leq \cos^{2}\beta \leq 1`$，所以 $`(t + 1)^{2} = (13 + 2t)\cos^{2}\beta \leq 13 + 2t`$。整理得 $`t^{2} + 2t + 1 \leq 13 + 2t`$，即 $`t^{2} \leq 12`$，故 $`- 2\sqrt{3} \leq t \leq 2\sqrt{3}`$。

反之，对任意 $`t \in \lbrack - 2\sqrt{3},2\sqrt{3}\rbrack`$，可先取 $`\cos\gamma = \frac{t}{6}`$，再取 $`\cos\beta = \frac{t + 1}{\sqrt{13 + 2t}}`$，因此该区间内的每个 $`t`$ 均可取得。

由向量减法的模长公式，$`{|\overset{\rightarrow}{b} - \overset{\rightarrow}{c}|}^{2} = {|\overset{\rightarrow}{b}|}^{2} + {|\overset{\rightarrow}{c}|}^{2} - 2\overset{\rightarrow}{b} \cdot \overset{\rightarrow}{c} = 13 - 2t`$。因为 $`- 2\sqrt{3} \leq t \leq 2\sqrt{3}`$，所以 $`13 - 4\sqrt{3} \leq {|\overset{\rightarrow}{b} - \overset{\rightarrow}{c}|}^{2} \leq 13 + 4\sqrt{3}`$。

**第三步  用 t 表示 \|b-c\|²=13-2t，得到取值范围**

注意到 $`13 - 4\sqrt{3} = (2\sqrt{3} - 1)^{2},13 + 4\sqrt{3} = (2\sqrt{3} + 1)^{2}`$，且 $`|\overset{\rightarrow}{b} - \overset{\rightarrow}{c}| \geq 0`$，故 $`|\overset{\rightarrow}{b} - \overset{\rightarrow}{c}| \in \lbrack 2\sqrt{3} - 1,2\sqrt{3} + 1\rbrack`$。
